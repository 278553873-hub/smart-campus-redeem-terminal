# 家长手机端设计规范

版本：2026-11-03。适用：家长微信小程序及其网页演示。

本规范依据教师手机端通用设计规范建立。字号、字重、间距、圆角、触控、图标语义、交互状态与动效继承教师端；家长成长页方案二仅提供颜色、透明度与渐变配色。两端共享基础组件，家长业务通过独立适配层调用。

## 1. 来源、范围与优先级

| 内容 | 唯一来源 | 继承方式 |
|---|---|---|
| 教师令牌基线 | `mobile-app/styles/teacherMobileTokens.ts` | 全量变量复制为 `--pm-*`，内部引用同步更名 |
| 教师通用规范 | `design-system/teacher-mobile/TEACHER_MOBILE_UI_GUIDELINES.md` | 本规范第2至10节按家长使用场景承接 |
| 家长颜色 | `components/parent-app/parentMobileColors.ts` | 提取当前成长页方案二的颜色、透明度和填色配方 |
| 家长令牌 | `components/parent-app/parentMobileTokens.ts` | 教师基线、颜色差异、兼容别名集中组装 |
| 组件样式适配 | `components/parent-app/ParentStyleTokens.tsx` | 仅提供组件类名，不重复定义数值 |
| 交付快照 | `design-system/parent-mobile/parent-mobile.tokens.json` | 从代码生成，包含来源摘要，不手工编辑 |

执行优先级：用户当前明确要求 → 本规范的家长颜色与业务映射 → 教师通用规范 → 旧页面实现。旧根目录规范已归档，根文件只保留规范导航。教师基线中班级管理、值周、教师发展等业务的令牌保留在完整镜像中，但不表示家长获得这些功能，也不要求家长页面采用其业务布局。

### 1.1 三层令牌

1. 基础值：教师同源色板、字号、字重、尺寸和时长。仅在令牌文件内组装。
2. 用途语义：品牌、文字、页面、表面、边界、状态、分值。
3. 组件语义：按钮、输入、选择、卡片、导航、浮层、图表及成长页填色。

家长业务优先引用 `--pm-*`。共享教师组件仍读取 `--tm-*`，由家长根容器桥接到对应 `--pm-*`；不得修改全局教师主题。所有别名必须可解析，禁止循环引用或在业务页再造同值令牌。

### 1.2 只继承方案二的颜色

允许提取：文字色、品牌红、辅助橙、正向绿、浅色表面、边框色、透明度、渐变颜色与色标、阴影颜色。

不提取：成长页的字号、插画与头像尺寸、学生信息区高度、首页间距、28px卡片圆角、圆环大小与层数、阴影偏移/模糊/扩散、按钮胶囊形态、卡片排列方式。

成长页已有局部样式保留为当前演示实现，不自动升级为全端规范。本次建立令牌与规范，不表示所有存量页面已完成迁移；存量页面下一次改版时按本规范核对。方案一仅为历史预览方案，不是家长通用设计系统的默认来源。

### 2.3 背景分类

- 成长首页允许使用方案二氛围背景，背景固定在屏幕层，滚动内容透明，不随内容高度拉伸。
- 手机外的演示预览画布独立使用原有浅灰色 `#F8FAFC`，不消费手机页面主题变量；切换家长配色或进入子页均不得改变外层画布。成长页的红橙底色不得写入通用 `--pm-bg-page` 系列令牌。
- 记录录入、记录明细、报告列表、档案、问卷、银行、设置等查看与操作页面采用白色标题栏、浅暖灰内容区与白卡。成长页颜色不意味着所有页面都铺设渐变。
- 报告封面、图表、五育分类与微信标识继续使用教师端对应的专用语义，不随背景主题整体重着色。
- 普通表单禁止默认灰底；只读、禁用、错误分别使用相应组件令牌。

## 3. 字体和数字

字体族继承教师手机端公共样式，不新增展示字体。下表完整沿用教师字号角色，不从成长页当前32px总分、28px余额或16px卡片标题反推全局字号。

| 角色 | 字号 | 建议字重 | 令牌后缀 |
|---|---:|---:|---|
| 导航栏标题 | 17px | 700 | `font-size-nav-title`（别名指向section-title） |
| 页面内容主标题 | 22px | 700 | `font-size-page-title` |
| 分区/弹层标题 | 17px | 600 | `font-size-section-title` |
| 重要对象/分组标题 | 18px | 600 | `font-size-group-title` |
| 卡片/记录标题 | 15px | 600 | `font-size-card-title` |
| 普通正文 | 14px | 500 | `font-size-body` |
| 表单分组标签 | 14px | 600 | `font-size-form-group-label` |
| 紧凑正文 | 13px | 500 | `font-size-compact` |
| 时间/辅助信息 | 12px | 500 | `font-size-meta` |
| 徽标数字 | 11px | 700 | `font-size-badge` |
| 通用核心统计 | 24px | 700 | `font-size-metric` |
| 可编辑文档标题 | 26px | 700 | `font-size-document-title` |

所有可见文字最低450字重；常规正文和辅助信息统一500，强调600，标题及关键数字700。800仅用于已经明确指定的专用组件，不作为家长卡片默认字重。正文建议1.5～1.6倍行高，多行记录约1.6倍；单行数字使用紧凑行高和等宽数字。正文、操作名称不使用徽标字号。字段分组标题不得与弹窗标题同级。

## 4. 尺寸、间距、圆角和阴影

### 4.1 教师同源尺寸

| 用途 | 标准 | 家长令牌 |
|---|---|---|
| 最小触控区域 | 44×44px | `--pm-size-touch` |
| 独立卡片圆角 | 12px | `--pm-radius-card-compact` |
| 普通按钮、输入、分段轨道圆角 | 8px | `--pm-radius-control-compact` |
| 卡片间距 | 12px | `--pm-layout-card-gap` |
| 密集条目间距 | 8px | `--pm-layout-list-gap-compact` |
| 普通卡片内边距 | 16px | `--pm-space-4` |
| 普通页面水平边距 | 20px | `--pm-space-5`，专用公共布局按其规则 |
| 弹层顶部圆角 | 28px | `--pm-radius-sheet` |
| 普通分段选中块圆角 | 4px | `--pm-form-segment-active-radius` |
| 紧凑分段选中块圆角 | 6px | `--pm-form-segment-compact-active-radius` |

间距阶梯为4、8、12、16、20、24、32px。可见尺寸与触控尺寸分开，缩小圆角不能缩小热区。头像、开关和圆形图标保持各自公共组件形态。旧card/inner/control的20/16/12px仅保留兼容，新页面优先使用compact与form语义；不删除旧值造成存量页面突然改变。

### 4.2 阴影

阴影的层数、偏移、模糊和扩散继承教师端；家长方案二只提供阴影颜色：卡片 `#BA352E10`，主操作 `#E0272720`，头像 `#BA352E12`。通用卡片、控件与头像的完整阴影从教师基线着色得到，不能把成长页的 `0 8px 22px` 等局部形态复制成全局规则。浮层、底栏等无对应方案二颜色的类别保留教师基线。

完整阴影变量使用 `[box-shadow:var(--pm-shadow-card)]` 等写法，不使用不能正确展开完整阴影的 `shadow-[var(...)]`。输入默认与聚焦的边界保持统一，不叠加装饰阴影。

## 5. 组件和状态

### 5.1 按钮与图标

- 同一局部任务保留一个主要操作；主按钮使用品牌红与白字。次级按钮使用白底和品牌文字，辅助操作为文字/图标。
- 默认、按下、禁用、进行中、成功和错误状态按教师端同一职责表达；进行中防重复提交，失败保留输入。
- 线性图标复用现有 Lucide 与公共图标组件，同一图标只表达一种含义。普通图标约18～20px，导航按公共组件22px；触控区独立保持44px。
- 纯图标必须提供可理解的读屏名称。铃铛可不显示“消息”文字，但读屏说明未读数量；角标不覆盖图标主体。
- 密码显隐统一使用 `PasswordRevealButton`：掩码状态显示闭眼、明文显示睁眼；读屏名称表达“查看密码／隐藏密码”。

### 5.2 输入和下拉

- 白色输入底、主文字、浅边界。默认与聚焦边框等值，普通聚焦外环透明，错误时才使用错误边界与说明。
- 聚焦通过光标、键盘和内容反馈；按钮、菜单保留可辨识的键盘焦点。
- 筛选型下拉使用透明底、无边界、无阴影和无轮廓的 `--pm-filter-*`。不要把筛选样式套到可编辑输入框。
- 标签、错误与输入建立程序化关联；只读与禁用分开。占位文字不替代标签。

### 5.3 选择控件

| 控件 | 选中态 | 未选态 | 形态 |
|---|---|---|---|
| 一级分段切换 | 白色滑块、品牌文字、教师中性轻阴影 | 暖灰轨道 `#F1EEEC`、次级文字 `#6D6764` | 轨道/触控44px高，轨道圆角8px；滑块36px高、圆角4px |
| 二级文字选择 | 品牌文字、半粗字重 | 次级文字 | 无底色、边框、阴影 |
| 开放式页签 | 主文字强调、品牌短线 | 次级文字 | 短线24×3px |
| 胶囊条件筛选 | 品牌实底、反白字 | 白底、浅边界、次级字 | 可见32px，至少60px宽，圆角8px |
| 说明型选项卡 | 白底、品牌边框与勾选 | 白底、浅边框 | 不用灰底表示未选 |

多层切换逐层减弱，不出现多个相邻强色块。旧家长端“白轨道＋红色实心滑块”的分段样式停止作为标准；通过 `--pm-selection-*` 同步教师状态规则。选中态不能只靠颜色表达，还需选中语义及必要字重或标记。

一级来源/状态切换统一使用 `ParentSegmentedControl`，直接复用教师“问卷采集”的 `CompactSegmentedControl`：`shape="subtle"`、`motion="sliding"`、默认密度、等宽铺满，文字13px/600。不得使用紧凑密度替代此场景，紧凑密度的36px轨道是另一种组件形态。家长适配层只将滑块阴影映射为 `--pm-content-control-shadow`；其余颜色、尺寸和动效引用教师同源令牌。

滑块使用同一个持续挂载的元素，以220ms及 `cubic-bezier(0.22,1,0.36,1)` 平移到目标位置；禁止通过两块按钮瞬间换色、淡入淡出或重新挂载伪装滑动。页签组件定义在页面函数之外，切换来源时仅替换下方内容。左右方向键及Home/End可切换并保持焦点；减少动态效果时立即切换。

### 5.4 弹层、整页和提示

- 通用浮层复用 `MobileBottomSheet`、`MobileConfirmSheet` 或家长适配组件，不在页面写新的遮罩、入场动画与通用圆角。
- 短任务使用底部弹层；长表单、记录录入和详情使用独立页面。页面返回保留已输入草稿。
- 弹层开启不改变背景页滚动位置，不在入场时自动拉起键盘。聚焦恢复使用不滚动的方式；关闭后焦点回到触发入口。
- 普通设置行不增加按压矩形底色、涟漪、缩放和装饰阴影；以打开目标页面或弹层反馈。
- 轻提示位于顶部安全区下方、宽度随内容变化；短暂出现后消失。失败说明下一步操作，不只写“失败”。

## 6. 页面结构与微信安全区

- 固定顶部区域、滚动正文、底部导航/操作区职责分离。长内容必须可以滚动访问到底，不能靠裁切保持首屏。
- 手机内部所有纵向/横向滚动区域隐藏原生滚动条，但保留触摸、鼠标滚轮及键盘滚动。公共 `parentMobile.css` 在 `.parent-mobile-app` 作用域内消费 `--pm-scrollbar-width: none` 与 `--pm-scrollbar-size: 0px`，同时覆盖标准与WebKit浏览器；仅写 `no-scrollbar` 类名不能作为验收依据。不得扩散到浏览器、后台及外部预览控件。
- 页面正文使用 `min-height: 0` 的独立纵向滚动容器，固定标题栏不随正文离开屏幕；普通正文禁止横向溢出，确需横滑的内容在自身容器处理，不裁掉关键内容。
- 状态栏、胶囊、安全区从公共手机容器或真实小程序环境读取，业务页面不写死设备型号高度。
- 顶部若与胶囊同排，仅局部预留胶囊占位，优先使用左侧空间；空间不足才调整局部分组，不一律把整页下推。
- 关闭手机模拟时，状态栏和胶囊避让同步归零；底部按钮避开系统指示条。
- 正常手机按真实内容宽度布局。长姓名、长班级、较大金额允许合理换行；资金与关键业务内容不静默截断。
- 预览工具属于手机外部区域，靠顶排列且必要时独立滚动，不占家长业务页面。设计备注、配置说明和实现逻辑禁止进入真实页面。

## 7. 记录与内容

### 7.1 录入

复用教师端 `MobileInputComposer` 与 `useHoldToTalk`，由家长适配层提供当前孩子和保存回调。基础输入组件不得直接读取家长权限、发币规则或学生信息。

语音、文字和图片各用现有公共能力；按住说话、松手完成、上移取消、失败回退文字、键盘访问和减少动态效果遵循教师规范。语音反馈按公共组件渲染；平台/语音的专用语义不应为了红橙主题整体重着色。输入条不能遮住最后一条内容，底部安全区统一计算。

### 7.2 内容呈现

- 原始描述、记录来源、发生日期、处理状态各自清晰。来源与状态不得只由颜色区分。
- 学校评价与家长记录使用来源字段区分；记录内容不自动等同于已审核分数。未经规则确认，不把家长录入显示为教师已确认评价。
- 人工智能生成内容明确标识；用户原话与生成结果分开。没有生成结果时不放置假解读或假成功状态。
- 列表仅展示完成任务所需内容，历史时间和辅助来源降一级呈现，金额和分值使用等宽数字。
- 空状态说明当前情况并提供可执行的下一步，错误状态提供重试与输入保留。

### 7.3 成长记录页实施基准

- 状态栏/标题栏纯白、内容区浅暖灰，固定标题栏44px；手机外的预览底色保持独立。来源切换与正文滚动，左右统一20px，顶部16px。
- “学校评价／家长记录”采用第5.3节同源滑块。“日／周／月／学期”使用等宽 `ParentUnderlineTabs`：14px文字、44px触控，选中品牌色/600、未选次级色/500；底部24×3px品牌短线随选项平移，时长与缓动复用分段令牌，减少动态效果时直接切换。
- 学校评价仅承载查看与筛选，不展示“记录表现”新增入口；家长新增记录入口保留在家长记录及成长首页。
- 日历、统计、学校记录、家长记录及空态卡均显式使用 `ParentCard shape="subtle"`：12px圆角、16px内距、12px同级间距、白底及 `--pm-content-card-shadow` 中性阴影。旧页面默认形态保留兼容，不全局改动成长首页。
- 周/月/学期选项采用8px圆角，白底保持不变，未选浅边框/次级文字，选中品牌边框/品牌文字并具备选中语义；不缩放、不使用整块粉色或额外阴影。`--pm-date-option-min-height` 为教师日期行高48px加8px间距，允许文本换行增高。
- 日期圆点保留圆形；选中品牌底反白字，今天未选中时使用品牌浅底，避免用正向绿色表示日期状态。日期前后切换和“今天／本周／本月／本学期”触控至少44px。
- 统计内块采用8px圆角与专属浅色：总分浅蓝 `#EDF5FD` / 深蓝字 `#326EA0`，表扬薄荷绿 `#EAF8F2` / 深绿字 `#18775D`，待改进浅杏橙 `#FFF3E7` / 深橙字 `#A45D2E`。使用 `--pm-record-summary-total-bg` / `--pm-record-summary-total-text`、`--pm-record-summary-praise-bg` / `--pm-record-summary-praise-text`、`--pm-record-summary-improve-bg` / `--pm-record-summary-improve-text`；仅用于成长记录统计，不覆盖通用品牌、状态或页面底色。待改进次数的提示色与明细中真实扣分的鲜莓红分别定义。
- 统计标题15px/600，标签及元信息12px/500，记录正文15px/500，核心数值24px/700；浅底搭配深色文字，保证辅助标签可读。
- 学校和家庭两种记录的卡片形态、图片8px圆角及文字层级保持一致；来源、日期、权限、统计口径与记录数据按原业务规则执行。

新增内容令牌只承接必要差异：`--pm-content-card-shadow` / `--pm-content-control-shadow` 保留教师中性阴影，`--pm-date-option-min-height` 表达带状态标记的日期选项高度。圆角、字体、间距和分段动效继续复用现有教师同源令牌，不另建同值参数。

### 7.4 成长币明细页

- 使用公共 `ParentPageHeader`，固定44px纯白标题栏，标题17px/700，返回触控区44×44px；正文独立滚动，内容底色为 `--pm-page-plain-content-bg`，不使用成长首页渐变或半透明标题栏。
- 正文左右20px、顶部16px；筛选卡、月份流水卡及空态卡使用 `ParentCard shape="subtle"`，12px圆角、16px内距和中性内容阴影。月份标题15px/600，分组间距12px，标题与卡片间距8px。
- 收入/支出使用持续挂载的 `ParentSegmentedControl`；来源分类复用公共 `TextSelectionControl` 的文字选择形态，选中为品牌文字、未选为次级文字，不铺浅红底。来源较多时在自身区域横滑，不挤压字号或减小44px触控区。
- 年份使用透明筛选型下拉及 `--pm-filter-*`，保留读屏名称。收入/支出切换后来源重置为“全部”，年份保持不变。
- 流水分类和金额15px/600，说明13px/500、约1.6倍行高，状态及时间12px/500。收入金额采用奖励深色，支出采用主文字色，并保留正负号。图标使用20px线性图标与32px辅助底；撤回与退还使用不同图标，并以文字标签表达原记录状态。
- 金额放在条目首行右侧，过长时允许换行；说明占据首行下方完整可用宽度，完整指标、分值及时间不裁切。流水分类、原金额与时间、状态关联及家长查看权限继续使用共用业务规则，不因视觉调整重算或改写。

## 8. 底部导航及家长场景映射

| 家长场景 | 规范使用方式 |
|---|---|
| 成长首页 | 当前孩子、成长概况、记录主操作、成长币；允许方案二氛围底 |
| 学校评价/家长记录 | 来源切换遵循分段层级；学校权限与本人记录权限分开 |
| 记录表现 | 独立整页，默认当前孩子，日期和内容清晰，保留草稿 |
| 成长币 | 使用学校配置的货币名称及原图；资产与预计可得以正文和数字角色区分 |
| 银行 | 仅开放时展示已存、入口与存取；明细页按普通分层背景 |
| 报告 | 列表负责识别与进入，不堆叠正文摘要；具体报告用对应内容规则 |
| 消息 | 列表展示实际待办及状态；入口为铃铛及未读角标 |
| 我的/设置 | 账号、绑定孩子与个人设置；紧凑设置行，不使用大装饰卡 |

底部维持成长、报告、我的三个入口，复用教师端尺寸、选中/未选状态和安全区。未选导航仍可操作，不能使用禁用色。导航只负责页面切换，不把新建操作伪装成一个底部页签。

成长币开放和银行开放为两级业务配置；家长录入是独立能力。完整业务规则见家长端需求文档，本设计规范不代替权限和计分规则。

## 9. 动效与无障碍

- 时长继承教师令牌：快速150ms、常规200ms、面板300ms、上下文背景320ms；分段滑块220ms，弹层进入350ms、退出220ms。各自服务对应组件，不混为一个全局动画。
- 普通交互使用指定属性过渡，禁止 `transition: all`。移动和透明度优先，避免按帧修改布局尺寸。
- 页签切换内容稳定呈现，滑块和背景按公共规则变化。系统减少动态效果时直接切换。
- 普通文本目标对比度至少4.5:1；大号文本与必要非文本标记至少3:1。透明填色需与实际背景合成后核验，不能仅看原始十六进制色。
- 小字号的正向/橙色/奖励文字使用深色语义，不把亮色图标色直接用于小字。
- 触控至少44×44px；键盘可达、焦点可见、读屏名称清晰。颜色不能独立承载含义。
- 无障碍数值为设计验收目标；令牌检查通过不代表所有存量页面已完成无障碍验收。

## 10. 实施、验证与维护

### 10.1 当前接入边界

`ParentStyleTokens.tsx` 已转为新令牌源的兼容出口。成长页方案二通过 `parentMobileColors.ts` 取色，避免配色维护两份。教师端源码不因家长主题变更而修改。

本次没有全量改写成长页的局部尺寸或各业务页的硬编码类名；这些是后续逐页迁移项。不得把旧页面存在的400字重、局部大数字、胶囊大圆角或旧冷蓝灰背景重新抄回规范。

### 10.2 更新步骤

1. 通用非颜色规则先改教师基线，家长端自动继承相同参数。
2. 家长配色只改 `parentMobileColors.ts`；确有相对教师的颜色差异时加入显式白名单。
3. 修改颜色时检查默认、按下、选中、禁用、只读、错误及焦点状态。
4. 执行 `node scripts/audit-parent-mobile-tokens.mjs`，检查完整继承、颜色边界、引用解析与导出一致性。
5. 需要更新交付清单时执行 `node scripts/export-parent-mobile-design-tokens.mjs`；再构建验证。
6. 页面改动另做对应组件运行时渲染检查。真机、浏览器截图或自动交互验证按项目授权规则执行。

### 家长表现录入

成长页“记录表现”跳转成长记录并选中“家长记录”，同时打开公共 MobileBottomSheet。弹窗上半部为可编辑的转写整理内容及图片附件，下半部复用 MobileInputComposer。语音与文字只补充草稿，不直接保存；右上角“保存记录”确认生成记录，空内容且无图片时禁用。保存成功关闭弹窗并刷新家长记录；关闭或失败保留草稿。默认当前孩子与今天，不展示对象、日期、指标、分数、AI评语或单独录入历史。拍照受学校开关控制，作为附件保留。语音转写复用公共语音能力，AI纠错服务尚未接入时保留原文，不伪造整理结果。

录入弹窗标题固定为“记录表现”。记录内容默认只读，采用3行紧凑文本区；标签右侧使用18像素编辑图标及44像素触控区，点击进入编辑并聚焦，完成图标结束编辑。下方输入整理后追加到上方内容区，手工编辑内容不再自动纠错。当前演示使用有限本地词语纠错，正式AI纠错服务待接入。

### 手机端记录内容编辑状态

记录内容默认只读，编辑图标激活后仅显示光标并将输入背景切为白色，不增加红色边框、描边或焦点光圈。编辑图标保留独立键盘焦点提示与44像素触控区。家长录入面板不设保存按钮，录入整理完成自动保存，连续补充更新同一条记录；内容编辑结束自动保存。家长记录卡仅展示内容、发生日期及更多操作，修改、删除收纳于公共底部操作面板。

录入弹窗空状态隐藏预览标题、文本框和编辑图标，仅用轻提示引导操作下方公共录入控件；有内容后展示预览区及编辑入口。保存成功显示“已自动保存”，失败保留内容并提示重试。正在编辑时不显示已保存提示。

学校评价明细与家长记录统一使用 ParentRecordCard：共用16像素内距、15像素正文、中性白卡、12像素正文与底部信息间距及12像素时间文字。学校评价右侧显示分数，家长记录右侧显示更多操作；更多按钮44像素热区不撑高底部行。

家长记录卡与学校评价明细共用 ParentRecordCard 和 ImageGallery：先正文、有图片时展示三列缩略图并支持大图预览，底部依次显示评价人及日期时间，右侧显示更多操作，不展示分数。此条替代此前“仅内容和时间、不展示图片”的精简规则。

家长记录的更多操作固定于卡片右上角，正文右侧预留空间防止遮挡，触控区保持44像素；底部仅显示评价人及时间。

### 家长记录月份聚合

按事件发生日期分组为“YYYY年M月”，月份与组内记录倒序排列，不展示空月份。首次展示最新有记录的月份，向下滚动逐月追加更早记录，保留“查看更早记录”按钮作为键盘和无自动加载时的替代操作。月份标题沿用15像素半粗主文字色，卡片、图片、评价人、时间和右上角操作保持本端现有样式，不引用参考图的配色。

月份标题整行支持展开与收起，默认展开，使用方向箭头提示状态。点击仅控制对应月份，已加载的其他月份不受影响；滚动加载仍可用。标题触控高度至少44像素，提供 aria-expanded 与内容区域关联，支持键盘操作。

### 家长记录列表紧凑布局

家长记录的“记录表现”入口置于顶部标题栏右侧，使用轻量文字按钮，仅家长记录页签可见，列表不再单独占用操作行。月份标题保留44像素触控高度，月份标题与首张卡片间距8像素，卡片间距8像素，月份组之间16像素；卡片内部16像素留白及正文、图片、评价人时间排版保持原样。本条覆盖此前家长列表统一12像素间距的规则，不影响学校评价及其他模块。

小程序胶囊避让：家长记录的“记录表现”最终放在最新月份标题右侧，与月份共用一行，不放顶部导航栏右侧，避免微信原生胶囊遮挡；月份折叠与录入为独立按钮。空列表沿用空态录入入口。本条替代此前标题栏右侧入口位置。
