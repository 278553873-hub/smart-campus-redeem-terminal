# 教师手机端亮黄主色试点

2026 年 11 月 27 日 · 学生个人详情首页

教师在手机上先核对学生、查看学期总分，再切换指标看趋势。黄色用于顶部氛围、选中态和重点标记。资料与图表内容以白色卡面、深色文字为主，保留奖章的浅金和报告的浅蓝入口。

以用户提供的《心田花开 V8.0 平台融合项目总结》设计稿为准。色彩、字体和组件尺寸从设计稿提取，学生详情页需要的悬停、按压、焦点和趋势色从原主色补齐。[站酷原项目](https://www.zcool.com.cn/work/ZNTQxMjc1NjA=.html)

## 参考稿提取

| 项目 | 参考值 |
| --- | --- |
| 主色 | `#FFD700` |
| 辅助色 | `#FF8600`、`#FF4D07` |
| 中性色截图取样，按深至浅排列 | `#2B3136`、`#69717C`、`#AEB1B9`、`#C4C7D1`、`#ECEEF2`、`#F8FAFB` |
| 字体 | 中文用苹方（PingFang SC），展示数字参考 Bebas Neue |
| 间距与行高 | 以 4 像素为基准，常用间距为 8、12、16、20、24 像素，行高为字号的 1.2–1.5 倍 |
| 组件圆角 | 外层卡片 12 像素，内层组件 8 像素 |
| 图标 | 业务入口采用圆润磨砂玻璃质感，操作图标用简单线条 |

试点中文优先使用系统苹方，统计和图表继续使用等宽数字。Bebas Neue 作为展示数字的后续字体候选。4 像素间距和 12／8 像素通用圆角沿用教师端现有令牌，学生资料的异形玻璃卡和标题飘带沿用各自轮廓。

## 首页用色

- 顶部黄 400 → 黄 300 → 黄 200，向下以浅黄过渡到页面底色。资料卡使用半透明白底，成长币、档案、问卷数字与「动态」短线使用黄 400，编辑文字使用黄 800。
- 「我的奖章」使用黄 50 → 黄 100，搭配现有透明奖章浮雕。「我的报告」使用浅蓝，作为辅助色。
- 曲线标题飘带单行基准高 32 像素，两侧微斜，右侧小圆角收边，左下露出三角形折角。背景从黄 400 经过黄 300 提亮至黄 200，白色标题配轻字影。未选中指标使用 `#FFFBE5` 底色和 `#D0941B` 指标名称，选中指标使用 `#FFD700` 实底和 `#694019` 指标名称。分数统一用主文字色，选中标签加粗。手机端颜色随实际选项切换，触摸过程维持当前配色。
- 「按周／按月」选中文字使用 `#FFD700` 并带白色滑块，未选中文字使用 `#9B9B9B`。折线和面积均使用黄 400 → 黄 300 提亮渐变，数据点和最新值提示底色使用黄 400。此页单独给通用图表提供渐变令牌。
- 系统高对比模式采用深色统计数字和标题。周期选中态和未选中指标名称使用黄 800，未选中周期文字使用主文字色，趋势线使用黄 700。强制色彩模式下，选中指标提供系统高亮描边。
- 正向、待改进、学籍和危险操作使用各自的业务语义色，品牌色只用于品牌相关样式。

## 对比度与发布范围

| 核对组合 | 对比度 |
| --- | --- |
| 主文字色 / 黄 400 选中底 | 9.39:1 |
| 黄 800 / 白底 | 6.57:1 |
| 黄 800 / 黄 50 浅底 | 6.31:1 |
| 次级文字色 / 白底 | 4.94:1 |
| 高对比模式黄 700 折线 / 白底 | 3.28:1 |
| 高对比模式图表提示数字 `#171513` / 黄 700 | 5.55:1 |

普通文字按 4.5:1 核对。表示状态的图形和焦点按 3:1 核对。常规模式的亮黄文字、亮黄折线和白色飘带标题采用试点确认的色值，可读性由高对比模式补充。上表为色值组合测试，透明图层及真机环境还需逐项看效果。[W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [W3C 非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

黄色由学生个人详情首页根元素的 `data-color-theme="yellow"` 和对应变量启用。现有红色令牌继续作为教师端默认主题，试点可通过撤回首页绑定回到原配色。推广阶段在试点确认后，再逐模块把品牌色用法接入新主题，先核对主色实底前景和各状态的读法。
