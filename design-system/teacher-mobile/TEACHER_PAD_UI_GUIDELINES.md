# 教师 Pad 端适配规范

## 产品关系

教师 Pad 是教师微信小程序的平板尺寸适配版本，不是独立网页管理后台。功能、数据口径、权限与手机端一致；首期只移植班级评价，后续补齐其余功能，不重新组织成另一套产品。

## 规范与令牌继承

继承同目录 TEACHER_MOBILE_UI_GUIDELINES.md。颜色、字体、图标、语义状态、圆角、阴影、触控尺寸和组件样式均读取 mobile-app/styles/teacherMobileTokens.ts 的 teacherBrandCssVariables。Pad 不维护第二套品牌和视觉基础值。

components/teacher-pad/teacherPadTokens.ts 仅增加平板布局值：页面边距32、窄屏24、最大内容宽1120、分栏间距24、窄屏16、主导航高度64。基础规范改变时通过共用令牌源同步。组件仍使用手机端原字号，不因设备扩大而整页等比放大字号。

## 板块与功能

- 主导航直接复用 TeacherBottomNavigation：「记录 / 班级 / 我的」，图标、名称和选中态与手机端相同。
- 记录：班级记录卡片、原文、分析、编辑与输入直接复用手机端组件；横屏内容宽不小于1000时双列，竖屏单列。录入条直接复用 TeacherRecordInputBar、MobileInputComposer 和 useHoldToTalk：保留左侧拍照、中央按住说话、右侧键盘切换，文字在原位输入并发送。禁止在Pad改成三个等宽按钮或独立文字输入页。默认首次记录引导与手机一致。Pad仅将悬浮条最大宽度调整为640，并保持距主导航上方16的间距。
- 班级：手机与 Pad 共用 TeacherClassListToolbar 和 TeacherClassListCard，保留原年级弹层、任教筛选及身份、科目、年级、人数信息。横屏三列、竖屏两列。首期隐藏学生列表、班级报告和排行榜，禁止把整卡点击改为评价明细。
- 我的：直接复用完整 MeView，保留个人信息、设置、学校来源和更多工具。首期不展示管理工具区块和值周安排，更多工具保留建议反馈。指标仅保留记录页原入口。
- 资料、设置、来源与登录：复用手机端页面及学校、教师初始资料源；首期学校来源只提供已开通班级评价的学校。未迁移工具隐藏，后续通过原菜单回调接通。
- 登录：Pad 第一期保留最近登录与手机号登录入口，不展示一键登录；第二期展示手机端同款“一键登录”，复用其授权弹窗、隐私确认与取消逻辑。演示中的授权和登录为模拟流程，正式小程序仍需接入认证。
- 次级页面隐藏底部主导航，返回原板块；进入次级页面不卸载记录页，避免丢失临时记录。

## 设备预览

预览控件在设备外，不进入教师操作页面。支持模拟真实Pad开关、横竖屏切换、11英寸1194×834及10.2英寸1080×810尺寸。关闭外壳保留固定设备尺寸预览。

实体外壳包括窄黑边框、摄像头、屏幕圆角、系统状态栏、小程序胶囊和底部安全区。预览按可用空间缩放；缩放仅作用于设备展示，不改变业务视口。弹层约束在设备内。

响应式以设备屏幕容器查询为准，禁止按浏览器窗口宽度误判模拟Pad横竖屏。浏览器窗口缩小只缩小预览，设备内部布局保持所选尺寸。

## 一致性验收补充（2026-11-03）

- 共用组件不等于整页验收通过；需同时核查入口语义、可用范围、教师资料、权限、返回路径、浮层根节点和背景交互隔离。
- 公共浮层必须挂载在设备内的 `teacher-mobile-overlay-root`，继承同一教师主题；拍照全屏状态隐藏主导航，记录弹层覆盖主导航。
- 次级页面按进入顺序逐层返回。不能用“回到所属底栏首页”代替返回上一页。
- 记录顶部由共用 ClassRecordLogView 的可用范围控制：只有一种记录类型时隐藏切换栏及替代标题；班级页首期也不展示单项“班级”分类；班级卡片/筛选共用，个人区使用完整 MeView。详细验证状态和待迁移页面见 `docs/演示项目/教师Pad端/逐页一致性审查.md`。

## 屏幕边界与单一类型（2026-11-03补充）

- 渐变背景与公共遮罩覆盖完整设备屏幕，包含状态栏和底部安全区；安全留白只作用于页面内容，不缩小背景容器。
- 主导航背景固定贴齐设备底边，高度为64像素操作区加底部安全区；安全区通过导航内部留白实现，禁止上移整个导航条形成底部空隙。页面内容预留相同总高度，横竖屏与外壳开关共用此规则。
- 公共底部弹窗通过布局令牌 `--tm-sheet-max-width` 适配尺寸，Pad 取消手机宽度上限并铺满设备宽度，遮罩覆盖全屏；仍沿用手机的底部弹出结构。
- 手机端与 Pad 端只在多个记录对象可用时显示对象切换，单一对象不展示切换或替代标题。切换学校后自动选中仍可用的记录对象。
- Pad 班级页顶部直接显示年级与任教筛选，不展示排行榜和单项“班级”分类；工具栏避让小程序胶囊。
- 演示环境切换中教师 Pad 使用平板图标，与教师手机端保持同样的22像素图标、文字字号/字重、按钮尺寸和选中样式。

## 我的工具布局（2026-11-03补充）

Pad 的更多工具继续复用 TeacherMeTools，使用104像素入口列宽和24像素列间距，左对齐并随可用宽度自动换行；图标大小、文字与垂直间距保持手机端原值。布局值由 Pad Token 管理，不改变手机端默认四列。更多工具保留建议反馈，复用手机端 SuggestionFeedbackView，支持文字、最多5张演示图片、移除、空内容禁用提交和提交后返回我的；图片与提交沿用现有演示机制，未接入生产上传或反馈服务。

## 首期精简范围（2026-11-04）

Pad 班级页不展示排行榜；我的页不展示管理工具区块及值周安排，更多工具保留建议反馈。原手机端页面和功能不受影响。分期入口由 `components/teacher-pad/teacherPadFeatures.ts` 集中配置，首期默认关闭；后续按功能分别开启，沿用现有页面、跳转和学校权限，不需要重新实现。已实现的演示数据和模拟识别仍不代表生产服务已接通，开放前应按实际需求验证。

设备外右侧提供“功能预览”卡片，距 Pad 外壳26像素，与手机端配色方案卡片间距一致；卡片仅展示第一期和第二期选择，不附加说明。默认第一期。第二期在第一期基础上开放一键登录、管理工具、值周安排和班级排行榜，工具仍按学校权限显示。切回第一期时，若正在查看被隐藏的页面，返回对应主导航页；如授权弹窗打开则关闭并取消未完成的模拟登录。窄窗口将卡片紧邻设备预览上方，避免遮挡设备；卡片仅属于演示预览，不进入教师操作界面。
