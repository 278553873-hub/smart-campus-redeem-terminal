# 班级报告图表可执行解释规则

> 适用范围：教师手机端班级报告中的“评价记录分布”“五育得分分布”“五育事件分布”。
>
> 规则版本：1.0
>
> 更新日期：2026-08-06

本文是三张图表解释的唯一业务规则源。规则必须先转成确定的数据输入，再按本文规定的优先级计算；禁止根据页面文案临时拼接结论。

每张图表固定输出两个字段：

- `summary`（总结）：只陈述图表能够直接证明的主要数据事实，不推断学生表现、教师动机或变化原因。
- `supplement`（补充）：提供参照结论或核查方向，不重复图中已经展示的数字。

## 统一执行规则

### 1.1 周期与来源口径

1. 本周期和上周期必须使用相同的数据来源、统计字段、学生范围和时区。
2. 日期边界按北京时间自然日计算，开始日和结束日均计入统计。
3. 上周期是紧邻本周期之前、自然日数量完全相同的一段时间。例如本周期为 8 月 4 日至 8 月 6 日，上周期为 8 月 1 日至 8 月 3 日。
4. “全班汇总”只能与上周期的“全班汇总”比较；“我的记录”或某位老师只能与上周期同一位老师的记录比较。
5. 任一数据来源在上周期不存在、口径发生变化或无法取得完整数据时，不生成周期趋势结论。

### 1.2 记录方向

记录方向按单条评价的积分变化确定：

| 条件 | 方向 |
| --- | --- |
| 积分变化大于 0 | 正向记录 |
| 积分变化小于 0 | 负向记录 |
| 积分变化等于 0 | 中性记录 |

“评价记录分布”只解释有明确方向的记录，分母为“正向记录数 + 负向记录数”；中性记录不进入该图的分子、分母、最低记录量和学生覆盖率计算。

“五育事件分布”统计全部已归入指标的评价事件，正向、负向和中性记录均计入事件数。

“五育得分分布”只统计积分变化不为 0 的得分记录；中性记录不计入得分记录数。

### 1.3 有效输入与异常兜底

输入必须同时满足以下条件：

- 数量为有限的非负整数；分值为有限数值。
- 正向、负向和中性记录之间互不重复。
- 每个指标使用稳定且唯一的指标标识，展示名称允许修改但不得作为计算主键。
- 每条评价事件只能归入一条有效的三级指标路径；一级指标事件数之和必须等于进入五育图表的事件总数。
- 扣分使用非负绝对值存储；净分必须满足“加分 - 扣分 = 净分”。
- 一级指标必须读取学校在统计周期内启用的完整配置，不得固定为德智体美劳五项。
- 进入五育图表的启用维度至少为 1 个；没有启用维度属于配置异常，不按“暂无记录”处理。

任一关键输入缺失、重复、不是有效数值或违反汇总关系时，该图固定输出：

- `summary`：`图表数据暂不可用`
- `supplement`：`数据口径校验未通过，请稍后再查看`

系统同时记录异常，禁止用 `0` 替代错误数据后继续生成业务结论。

### 1.4 固定阈值

首版统一使用以下阈值，代码必须集中维护，不得散落在页面组件中：

| 参数 | 数值 | 用途 |
| --- | ---: | --- |
| 最低可比较记录数 | 30 条 | 30 条时单条记录影响不超过 3.34 个百分点，低于基本变化阈值 |
| 五育单维度基础记录数 | 5 条 | 防止启用维度增加后，固定 30 条被过度摊薄 |
| 最低学生覆盖率 | 50% | 避免少数学生的记录代表全班 |
| 基本变化阈值 | 5 个百分点 | 区分“变化不大”与“上升/下降” |
| 明显变化阈值 | 10 个百分点 | 区分普通变化与明显变化 |
| 得分接近比例 | 5% | 结合学校分值最小单位计算净分和扣分容差 |
| 最低年级参照班级数 | 3 个 | 避免极少班级形成不稳定参照 |

阈值只使用未四舍五入的原始比例计算。页面百分比可四舍五入为整数，但不得使用展示值反推结论。

### 1.5 判断优先级与并列

1. 每张图必须严格按对应决策表从上到下判断，命中第一条后停止，不得同时输出多条总结。
2. 数值完全相同才属于并列；“处于容差内”只用于判断整体是否接近，不用于制造并列名次。
3. 一个结论最多直接展示两个并列名称；超过两个时输出“`{前两个名称}等多个维度`”。
4. 指标名称超过 8 个中文字符时，总结中使用前 7 个字符加省略号；图表和下钻明细仍展示完整名称。
5. 不同名称缩写后相同时，只展示第一个缩写名称并追加“等多个维度”，不得把缩写结果去重后当成单一维度。
6. 总结不超过 30 个中文字符，补充不超过 80 个中文字符。名称替换后仍超长时，减少直接展示的并列名称；仍然超长时改用不点名的“多个维度”固定文案，不得截断固定结论文案。
7. 没有数据、样本不足和不可比较是正式结果，不得继续回退到“均衡”“较高”或“较低”等结论。

## 评价记录分布

### 2.1 解释目标

本图回答“正向与负向记录的构成是否发生变化”，不回答“班级表现是否改善”。禁止使用“班级评价改善”“班级表现回落”“达到或优于年级”等超出数据证据的表述。

### 2.2 输入与公式

每个周期至少提供：

- 正向记录数、负向记录数。
- 至少有一条正向或负向记录的去重学生数。
- 该周期班级在校学生数。
- 数据来源标识。

计算公式：

```text
有方向记录数 = 正向记录数 + 负向记录数
正向占比 = 正向记录数 / 有方向记录数
学生覆盖率 = 有方向记录覆盖学生数 / 该周期班级在校学生数
周期变化值 = 本周期正向占比 - 上周期正向占比
```

班级在校学生数使用对应周期结束日的有效在校名单；正负向记录数和覆盖学生数必须限定在同一份名单内。人数为 0、覆盖学生数大于在校学生数、覆盖学生数大于有方向记录数，或记录学生不在该名单内时，视为数据异常。

### 2.3 总结决策表

| 优先级 | 条件 | `summary` |
| ---: | --- | --- |
| 1 | 本周期有方向记录数为 0 | 本周期暂无正负向评价记录 |
| 2 | 本周期有方向记录数少于 30 | 当前记录较少，暂不判断趋势 |
| 3 | 本周期学生覆盖率低于 50% | 当前覆盖范围有限，暂不判断趋势 |
| 4 | 两周期日期长度、来源或统计口径不一致 | 上周期口径不同，暂不比较趋势 |
| 5 | 上周期有方向记录数为 0 | 上周期暂无可比记录 |
| 6 | 上周期有方向记录数少于 30 | 上周期记录较少，暂不比较趋势 |
| 7 | 上周期学生覆盖率低于 50% | 上周期覆盖有限，暂不比较趋势 |
| 8 | 周期变化值大于或等于 10 个百分点 | 正向记录占比较上周期明显上升 |
| 9 | 周期变化值大于或等于 5 且小于 10 个百分点 | 正向记录占比较上周期上升 |
| 10 | 周期变化值大于 -5 且小于 5 个百分点 | 正负向记录构成变化不大 |
| 11 | 周期变化值小于或等于 -5 且大于 -10 个百分点 | 正向记录占比较上周期下降 |
| 12 | 周期变化值小于或等于 -10 个百分点 | 正向记录占比较上周期明显下降 |

边界归属固定为：`+5` 属于上升，`+10` 属于明显上升，`-5` 属于下降，`-10` 属于明显下降；只有 `-5 < 变化值 < +5` 才属于变化不大。

### 2.4 年级参照

年级参照只用于生成 `supplement`，不得改变周期总结。

有效参照班级必须同时满足：

1. 与本班属于同一年级、同一周期、同一统计口径。
2. 排除当前班级。
3. 有方向记录数不少于 30，学生覆盖率不低于 50%。
4. “全班汇总”使用其他班级的全班汇总；某位老师的数据只使用同一老师在其他班级的数据。
5. 有效的其他班级不少于 3 个；不足 3 个时不生成高低比较。

年级参照正向占比采用各有效班级正向占比的等权平均，禁止先合并所有记录再计算，以免记录量大的班级支配结果。

```text
年级参照正向占比 = 各有效班级正向占比之和 / 有效班级数
年级差值 = 本班正向占比 - 年级参照正向占比
```

### 2.5 补充决策表

| 优先级 | 条件 | `supplement` |
| ---: | --- | --- |
| 1 | 本周期有方向记录数为 0 | 建议积累有方向的评价记录后再查看分布 |
| 2 | 本周期记录数或覆盖率未达到比较门槛 | 当前样本不足，不进行年级比较 |
| 3 | 有效参照班级少于 3 个 | 暂无稳定的年级参照 |
| 4 | 年级差值大于或等于 10 个百分点 | 正向记录占比明显高于年级参照 |
| 5 | 年级差值大于或等于 5 且小于 10 个百分点 | 正向记录占比高于年级参照 |
| 6 | 年级差值大于 -5 且小于 5 个百分点 | 正负向记录构成与年级参照接近 |
| 7 | 年级差值小于或等于 -5 且大于 -10 个百分点 | 正向记录占比低于年级参照 |
| 8 | 年级差值小于或等于 -10 个百分点 | 正向记录占比明显低于年级参照 |

### 2.6 必测反例

- 本班 `375 / 447` 条为正向、年级参照 `396 / 483` 条为正向时，本班正向占比更高，禁止因为正向原始条数更少而输出“低于年级参照”。
- 本周期正向和负向条数都增加，但正向占比下降时，必须输出占比下降，不能输出“变化不一致”。
- 两周期条数不同但正向占比相差不足 5 个百分点时，必须输出“构成变化不大”。
- 中性记录数量变化不得影响正向占比、最低记录量和本图学生覆盖率。

## 五育得分分布

> “五育”为固定业务名称；参与计算的维度读取学校当前启用的一级指标配置，不限定为五项。二级、三级指标下钻时沿用本节规则，并只比较当前父级下的直接子级。

### 3.1 解释目标

本图展示各维度的累计加分、累计扣分和累计净分，只回答“累计分值如何分布”。累计分值同时受记录数量和单次分值影响，因此禁止把“累计净分最高”改写成“表现最好”“发展最强”等能力判断。

### 3.2 输入与公式

每个启用维度必须提供：

- 稳定且唯一的指标标识、展示名称。
- 得分记录数，即积分变化不为 0 的事件数。
- 累计加分、累计扣分绝对值、累计净分。

```text
累计净分 = 累计加分 - 累计扣分
得分记录总数 = 各维度得分记录数之和
净分跨度 = 最高累计净分 - 最低累计净分
```

分值最小单位读取本次统计所涉及评价指标中绝对值最小的非零积分步长，加分和扣分都参与计算；无法取得时首版按 `1` 分处理。

```text
最大净分绝对值 = 各维度 |累计净分| 的最大值
净分容差 = 分值最小单位 与 [向上取整（最大净分绝对值 × 5% / 分值最小单位）× 分值最小单位] 中的较大值
五育得分最低记录数 = 30 与（启用维度数 × 5）中的较大值
```

例如分值最小单位为 1、最大净分绝对值为 148 时，净分容差为 8 分。

### 3.3 总结决策表

| 优先级 | 条件 | `summary` |
| ---: | --- | --- |
| 1 | 得分记录总数为 0 | 本周期暂无五育得分记录 |
| 2 | 当前只启用一个一级指标 | 当前仅有一个维度，无需比较得分 |
| 3 | 得分记录总数少于五育得分最低记录数 | 当前得分记录较少，暂不比较维度 |
| 4 | 存在得分记录数为 0 的维度 | `{零记录维度}本周期暂无得分记录` |
| 5 | 净分跨度小于或等于净分容差 | 各维度累计净分接近 |
| 6 | 净分跨度大于净分容差 | `{最高维度}累计净分最高，{最低维度}最低` |

最高或最低累计净分完全相同时按并列规则输出。净分为负数时仍按数值大小判断，较接近 0 的负数高于绝对值更大的负数。

### 3.4 补充决策表

扣分容差使用与净分容差相同的公式，但把“最大净分绝对值”替换为“最大累计扣分”。

| 优先级 | 条件 | `supplement` |
| ---: | --- | --- |
| 1 | 得分记录总数为 0 | 建议积累得分记录后再查看分布 |
| 2 | 当前只启用一个一级指标 | 当前仅展示该维度的累计得分 |
| 3 | 得分记录总数少于五育得分最低记录数 | 当前样本不足，不生成维度判断 |
| 4 | 存在得分记录数为 0 的维度 | 可先查看未产生得分记录的维度 |
| 5 | 所有维度累计扣分均为 0 | 各维度暂无扣分记录 |
| 6 | 最高与最低累计扣分之差小于或等于扣分容差 | 各维度累计扣分接近 |
| 7 | 最高与最低累计扣分之差大于扣分容差 | `{最高扣分维度}累计扣分最多，可查看对应评价事件` |

### 3.5 必测反例

- 学校已启用多个维度但所有维度得分记录数均为 0 时，必须输出“暂无记录”，不得输出“净分接近”。
- 某维度只有更多记录导致累计净分最高时，只能输出“累计净分最高”，不得输出“表现最好”。
- 所有累计净分均为负数时，必须按真实数值确定最高和最低，不得按绝对值排序。
- 最低净分维度与最高扣分维度不一致时，不推断两者之间存在因果关系。

## 五育事件分布

> “五育”为固定业务名称；参与计算的维度读取学校当前启用的一级指标配置，不限定为五项。二级、三级指标下钻时按当前父级的直接子级重新计算事件占比。

### 4.1 解释目标

本图回答“评价事件在各维度之间如何分布”，不判断各维度是否应该获得相同数量的记录，也不把记录较多解释为学生表现更好。

### 4.2 输入与公式

每个启用维度必须提供稳定指标标识、展示名称和事件数。事件数包含已归入该指标的正向、负向和中性评价记录。

```text
事件总数 = 各维度事件数之和
维度事件占比 = 该维度事件数 / 事件总数
占比跨度 = 最高维度事件占比 - 最低维度事件占比
五育事件最低记录数 = 30 与（启用维度数 × 5）中的较大值
```

占比跨度使用未四舍五入的比例计算。最高或最低事件数完全相同时按并列规则输出。

### 4.3 总结与补充决策表

| 优先级 | 条件 | `summary` | `supplement` |
| ---: | --- | --- | --- |
| 1 | 事件总数为 0 | 本周期暂无五育评价记录 | 建议积累评价记录后再查看分布 |
| 2 | 当前只启用一个一级指标 | 当前仅有一个维度，无需比较分布 | 当前仅展示该维度的事件数量 |
| 3 | 事件总数少于五育事件最低记录数 | 当前记录较少，暂不判断分布 | 当前样本不足，不生成维度判断 |
| 4 | 存在事件数为 0 的维度 | 本周期记录尚未覆盖`{零记录维度}` | 可查看相关维度是否存在应记录但未记录的场景 |
| 5 | 占比跨度小于或等于 5 个百分点 | 各维度记录占比较接近 | 可继续观察后续记录分布 |
| 6 | 占比跨度大于 5 且小于或等于 10 个百分点 | `{最多维度}记录较多，{最少维度}较少` | 可查看不同维度的评价场景与记录机会 |
| 7 | 占比跨度大于 10 个百分点 | `{最多维度}记录占比较高，{最少维度}较低` | 建议优先核查记录较少维度的实际评价事件 |

“占比较高”只描述相对关系，禁止替换为“主要集中在”。例如最高维度占 25.7% 时，即使它与最低维度相差超过 10 个百分点，也不能称为“大部分记录集中在该维度”。

### 4.4 必测反例

- 只有 1 条记录时，即使全部落在同一维度，也必须输出“记录较少”，不得输出“占比较高”。
- 事件数为 0 的维度必须优先输出“尚未覆盖”，不得被“占比跨度较大”覆盖。
- 学校启用 2、5、6 或更多一级指标时，均按实际启用维度计算，不得补齐或截断为固定五项。
- 中性评价已经归入某一指标时必须计入该维度事件数，不得因为没有积分变化而丢弃。

## 落地与验收要求

1. 规则计算必须位于班级报告领域层；页面只接收 `summary` 和 `supplement`，不得复制判断条件。
2. 所有阈值使用命名常量集中维护，文档、代码和测试中的数值必须一致。
3. 每条决策分支至少有一个测试；`0、29、30` 条，维度数乘以 `5` 的前后边界，`49.99%、50%` 覆盖率，`-10、-5、0、5、10` 个百分点必须单独测试。
