# 班级报告图表简单解析规则

每张图表的简单解析固定输出两个部分，不再拼接为一段完整句子：

- **总结**：概括图表中最重要的趋势或差异，使用较强字重展示。只陈述数据表现，不推断原因。
- **补充**：提供对比观察、核查方向或后续建议，使用常规字重和次级文字展示。

界面字段对应关系：`summary` 为总结，`supplement` 为补充。

## 评价记录分布

### 总结

总结由本周期与上周期的正向、负向事件变化共同决定：

| 条件 | 总结 |
| --- | --- |
| 正向增加且负向减少 | 班级评价较上周期改善 |
| 正向减少且负向增加 | 班级评价较上周期回落 |
| 正向、负向均持平 | 班级评价与上周期基本持平 |
| 其他组合 | 正向和负向事件的变化不一致，暂时不判断整体趋势 |

### 补充

补充由本周期与年级平均的差异决定：

| 条件 | 补充 |
| --- | --- |
| 正向偏低、负向不高 | 正向评价仍低于年级平均，可检查记录是否充分、是否集中于少数学生 |
| 正向偏低、负向偏高 | 正向偏低且负向偏高，可先检查记录是否充分，再结合具体事件判断原因 |
| 正向不低、负向偏高 | 负向事件高于年级平均，可查看是否集中在特定学生、场景或指标 |
| 正向、负向均持平 | 整体与年级平均持平，可继续观察后续变化 |
| 其余情况 | 整体达到或优于年级平均，可继续观察趋势是否稳定 |

## 五育得分分布

> “五育”为固定业务名称；参与计算的维度读取学校当前启用的一级指标配置，不限定为五项。二级、三级指标只在下钻明细中展示，并沿用同一套总结规则。

### 总结

| 条件 | 总结 |
| --- | --- |
| 各维度总分存在差异 | `{总分最高维度}总分相对较高` |
| 各维度总分相同 | 五育总分较为均衡 |
| 总分相同且各维度扣分也相同 | 五育总分和扣分均较为均衡 |
| 暂无数据 | 本周期数据较少 |

### 补充

| 条件 | 补充 |
| --- | --- |
| 最低总分与最高扣分不是同一维度 | `建议结合具体记录看看{总分最低维度}得分偏低、{扣分最高维度}扣分较多的原因` |
| 最低总分与最高扣分是同一维度 | `{维度}总分较低且扣分较多，建议结合具体事件看看原因` |
| 各维度总分相同，但部分维度扣分较多 | `{扣分最高维度}扣分相对较多，建议结合具体事件看看原因` |
| 各维度均无扣分 | 各维度暂无扣分，可以继续观察后续表现 |
| 总分和扣分均较为均衡 | 可以继续观察各维度后续表现 |
| 暂无数据 | 建议再积累一些记录后判断五育表现 |

## 五育事件分布

> “五育”为固定业务名称；参与计算的维度读取学校当前启用的一级指标配置，不限定为五项。二级、三级指标只在下钻明细中展示，并按当前父级重新计算占比。

### 总结

| 条件 | 总结 |
| --- | --- |
| 最高与最低占比差不超过 5 个百分点 | 五育评价记录分布较均衡 |
| 占比差大于 5 且不超过 10 个百分点 | `{最多维度}记录相对较多，{最少维度}相对较少` |
| 占比差大于 10 个百分点 | `评价记录主要集中在{最多维度}，{最少维度}相对较少` |
| 暂无数据 | 本周期记录较少 |

### 补充

| 条件 | 补充 |
| --- | --- |
| 分布较均衡 | 可以继续观察各维度的记录情况 |
| 占比差大于 5 且不超过 10 个百分点 | 建议看看是否与评价场景或记录习惯有关 |
| 占比差大于 10 个百分点 | 建议看看是否有些场景或维度记录得比较少 |
| 暂无数据 | 建议再积累一些记录后判断五育评价情况 |
