# 乐途AI智慧教育运营后台设计规范

适用范围：`components/operations-pc/`。基础规范继承项目 `PC_UI_GUIDELINES.md`，基础组件使用 Arco Design React，不修改学校 PC 后台。

## 设计评审与取舍

- 使用 ui-ux-pro-max 的极简企业后台方向、语义颜色、渐进披露、表单校验和返回状态保留规则。
- 设计系统检索匹配到的官网转化布局不适用于本项目，不采用其首屏宣传、功能卡片和外部字体建议。
- PC 数据配置场景保留项目 14px 正文和 Arco 默认控件尺寸，不套用移动端 44px 触控热区及通用 16px 正文建议。
- 学校列表按个人用户、合作学校、组织分别组织字段。组织是独立实体，学校通过关联关系加入，不复制学校及其业务数据。
- 学校可关联任意多个组织；本期各组织内部完全统一指标，冲突必须明确确认统一范围后再关联。共同管理学校的多个组织需要传递计算连带影响范围。

## 视觉语言

单一白色内容容器、浅灰画布、蓝色操作和选中态。使用标题、间距、分割线形成层级，不使用宣传头图、装饰性渐变、统计卡片墙或重复说明。

保持学校管理侧栏及学校列表入口；页内以「个人版 / 学校版 / 组织版」标准 Tabs 切换。每个版本有自己的筛选和列表状态。当前版本只有一个页面级新增主操作，个人版由用户自行注册，不提供运营新建个人用户入口。

## 页面与交互

- 页面结构：面包屑 → 页面标题 → 版本页签 → 高频筛选 → 分割线 → 列表操作区 → 表格 → 分页。
- 版本页签必须承载实际列表面板，不使用空 TabPane 配合外置筛选。页签、标题和内容共用页面内边距；页签底线至筛选区为24px，筛选项通过16px行距、24px列距稳定换行，不叠加 Form.Item 默认外边距。
- 列表默认左对齐；数值可右对齐；操作列固定，最多直接展示两个操作。
- 个人版使用 Arco 原生分组表格，全部表头与内容左对齐，包括「统计信息」总表头、三项统计和操作。列宽令牌位于 `operationsTableTokens.ts`：账号152、姓名96、学校192、注册日期176、操作88px；三项统计由原生固定布局等分剩余宽度，每列至少112px，最小表宽由令牌计算为1040px。学校列不伸展，禁止以居中表头或百分比列宽将统计区推向日期列。个人版不重复显示列表副标题，筛选分割线上下各16px；详情统计使用 Arco Descriptions 原生垂直布局，名称与数值左对齐，宽屏三列、窄屏两列，不另写统计卡片样式。
- 学校版使用 Arco Table 原生左右固定列与横向滚动，学校名称固定左侧240px、操作固定右侧88px；其余列按「编号、已关联组织、类型、管理员姓名、管理员手机、教师数、班级数、学生数、授权状态、授权起止时间、等级、省／市／区」排列。全部表头与内容左对齐，列宽统一读取 `operationsTableTokens.ts`，表宽由列宽合计，不挤压字段或手写固定列样式。等级使用「1星」至「5星」的简洁文字；授权状态使用原生 Badge，合作中为成功色、未开始为警告色、已到期为中性色，均保留状态文字。
- 详情以抽屉承载；多步骤开通使用页内独立流程，保留后台导航，不把主要流程塞进多层弹窗。
- 多步骤流程始终显示步骤和上一步／取消。未保存离开时确认，校验失败保留输入并定位错误。
- 只有选择了会影响数据范围或评价指标的操作后，才展示对应影响提示和确认。
- 切换页签、详情返回后保留筛选和分页。空结果有清空筛选入口。
- 标准键盘操作、清晰焦点、具名图标按钮、字段标签、错误播报沿用 Arco 能力。减少动态偏好下关闭非必要动画。

## 边界

本期为运营端 Demo 的设计与交互，不代表真实账号、跨校数据权限或指标迁移服务已接入。不得调用学校／教师端存储来模拟运营成功，不把设计说明和内部实现文案放到实际页面。
