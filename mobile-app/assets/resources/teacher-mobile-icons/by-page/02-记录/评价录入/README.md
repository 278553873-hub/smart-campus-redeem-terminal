# 评价录入图标

这里列出“评价录入”页面及其弹窗、抽屉和复用子组件实际使用的图标。公共图标只在公共目录保存一份。

| 资源路径 | 页面用途 | 存放位置 | 类型 |
| --- | --- | --- | --- |
| `../../00-公共图标/camera.svg` | 拍照或修改头像 | 公共图标 | Lucide SVG |
| `../../00-公共图标/chevron-right.svg` | 进入下一级 | 公共图标 | Lucide SVG |
| `../../00-公共图标/image.svg` | 图片 | 公共图标 | Lucide SVG |
| `keyboard-delete.svg` | 虚拟键盘删除 | 本页面 | 页面专用 SVG |
| `keyboard-shift.svg` | 虚拟键盘大写切换 | 本页面 | 页面专用 SVG |
| `../../00-公共图标/keyboard.svg` | 键盘输入 | 公共图标 | Lucide SVG |
| `../../00-公共图标/mic.svg` | 语音录入 | 公共图标 | Lucide SVG |
