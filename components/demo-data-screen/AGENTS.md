# Demo 独立大屏方案

- 本目录属于 Demo 独立项目「数据大屏」，入口 `?app=data-screen`。
- 用户要求此方案与学校 PC 顶部「育人大屏」并行保留不同风格，最后再决定取舍。
- 保留本任务「学生评价 · 成长全景」的三列六面板设计，评价播报及学生加减分联动在本目录维护。
- 组件、样式、统计适配与播放状态均在本目录独立维护；不要从 `../data-screen/` 导入展示实现，也不要修改该目录来修复 Demo 方案。
- 样式类及动画使用 `demo-` 前缀；底层报表服务可只读复用。
- 设计与数据口径见 `../../docs/演示项目/数据大屏/Demo独立方案.md`。
