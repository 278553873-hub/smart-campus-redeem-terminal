# Demo 独立大屏方案

- 本目录属于 Demo 独立项目「数据大屏」，入口 `?app=data-screen`。
- 用户要求此方案与学校 PC 顶部「育人大屏」并行保留不同风格，最后再决定取舍。
- 当前方案按用户 2026-11-06 新要求采用「AI素养评价系统」标题栏、中央五育事件环图和左／右／下方信息面板。中央环图自动轮播悬停效果；无周月筛选和播放暂停按钮。评价播报及学生加减分联动在本目录维护。
- 按用户最新要求，大屏铺满浏览器窗口，去掉固定16:9导致的四周留白；以1920×1080为最小排布空间，字号与图形等比缩放，网格延展以适应实际宽高。环图保持正圆，禁止直接拉伸整个界面。
- 动态背景位于数据层底部并铺满窗口，采用用户偏好的暖橙金光纤与高密度粒子；2026-11-09试用金黄／淡金白配色后用户反馈不如前版，已恢复暖橙金色。所有数据卡片（包含中央环图）统一通透的深色半透明底、背景模糊、细高光边框与柔和阴影，透出背景光色，避免回到不透明蓝色面板。
- 按2026-11-09参考图追加要求，卡片采用6%–14%底色、10像素背景模糊和更明亮的完整细边框；中央下方暖金光晕统一放在背景层，贯穿各卡片，不单独染色面板、不继续增加粒子数量。
- 大屏整体配色参考同图：炭黑为底色，米白承担标题、常规数值、普通图标与基础进度条，暖灰承担辅助文字；暖橙金只强调核心的评价次数、排行前三、标题栏局部光效与背景暖光，禁止将所有数值和进度条统一染金。五育采用暖金／玉绿／柔蓝／紫色／米白，加减分采用玉绿／莓红。颜色集中在Demo样式变量中，环图、图例与动态记录读取同一类别色，禁止恢复原冷蓝主题。
- 中央环图直接使用 React 矢量图形渲染，避免异步图表初始化空白；教师排行同时展示前10名，最新评价及学生积分变化每条单行。背景采用局部封装的 React Bits Ghost Fibers，禁止将背景样式或状态传入学校 PC 方案。
- 2026-11-09新增板块布局：中央高大环图为主视觉，左侧四项概况及教师排行，右侧年级评价数及年级评价覆盖率；底部依次为指标使用、最新评价、学生积分变化、五育加减分。指标使用采用并排的270度双仪表盘，二级米白、三级暖金，中央显示百分比，不显示已使用／总指标及数量。禁止恢复顶部横排概况挤压主图。移除评价次数与成长记录条数下方的说明。年级评价数使用学生记录条数，Demo服务独立校准年级和班级分项与总记录条数一致，不修改共享报表服务。
- 最新评价仅显示时间、评价人、真实匹配的三级指标路径和每人赋分；学生动态仅显示时间、星号脱敏姓名、一级指标和赋分。两组动态各显示5条，数据不足时按实际数量显示；禁止在标题、辅助阅读文本中泄露完整学生姓名。指标覆盖按当前周期实际有使用次数的三级指标统计，二级指标下任一三级使用即视为覆盖；模拟新评价同步更新对应指标的使用量。
- 组件、样式、统计适配与播放状态均在本目录独立维护；不要从 `../data-screen/` 导入展示实现，也不要修改该目录来修复 Demo 方案。
- 样式类及动画使用 `demo-` 前缀；底层报表服务可只读复用。
- 设计与数据口径见 `../../docs/演示项目/数据大屏/Demo独立方案.md`。

- 最新精简要求：教师排行不显示“前10位·评价次数”，仍展示前十名并使用完整演示姓名；指标仪表盘标签为“二级指标”“三级指标”；最新评价无实时演示标签；年级覆盖率仅年级、进度条、百分比，无周期说明或覆盖人数；页面不显示底部口径及演示标签，中央环图无周期与已归类总条数副标题。两组年级图各自按全校数据排名选前三名暖金强调，不按当前页重新排名。

- 2026-11-09主图专项方案经用户确认：中央采用收薄放大的金白圆环，米白为基础，暖金表示当前轮播／交互焦点；五育类别色保留在外沿细线及底部小色点，明确区别于焦点色。移除外侧引导线和重复标签，底部五项直接显示类别及占比；中心米白大数字、浅金类别、暖灰条数。扇区角度仍按真实占比，100%整环及无记录状态必须正常，保持键盘操作与减少动态效果支持。
