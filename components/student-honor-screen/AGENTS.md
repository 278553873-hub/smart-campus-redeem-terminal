# 学生荣誉榜

- 2026-11-18最新定位：班主任在课堂一体机上展示给学生观看的独立亮色、趣味、多彩荣誉榜，地址`?app=student-honor-screen`。从学校PC顶部独立新窗口打开，不属于学校驾驶舱页签。
- 总分沿用完整学期有效加减分净值，先筛选完整年级名册再排名，同分同名次，展示真实总分，不换算100分、不编造荣誉或进步结论。
- 前三名使用教师手机端同一学生头像库及稳定分配规则，独立头像、皇冠和阶梯领奖台；同分保留真实并列名次，不能按视觉站位改写名次。名次统一01、02格式。
- 使用本目录独立样式，不导入学校驾驶舱或旧学生看板的展示组件及业务样式；可以复用纯数据聚合和底层报表服务。页面只保留全屏核心操作，触控热区至少56像素，支持键盘和可见焦点。
- 独立页面的`.honor-viewport`必须直接占满窗口高度（`100vh`回退、`100dvh`适配），不能依赖父级`height:100%`。App入口外层没有显式高度，绝对定位画布不撑开父级，会导致容器高度为0、缩放为0并持续隐藏；静态渲染和构建成功不能证明画布可见。
- 验证数据筛选、总分排名、并列、少于三人、空榜、六至十二年级、真实页面静态渲染及构建。未经授权不启动浏览器自动化。

- 新版以六年级浅冰蓝视觉稿为准，使用浅磨砂年级面板、青蓝／柠檬黄／杏橙领奖台与浅黄名次区白卡。姓名、完整班级、名次和总分均使用真实文字。
- 学校演示环境读取教师手机端班级详情共用名册、头像和学期净分计算。教师页面内存中的临时编辑由共享服务接入后方可跨设备同步。

- 最新展示小学六个年级同屏，初中与高中合并同屏，每屏最多六个年级、三列两行。多屏每30秒自动轮播，浏览器隐藏时暂停，单屏静止。
- 页首标题合并学校对外名称和“学生荣誉榜”。领奖台为头像、姓名、名次、完整班级、总分分别预留空间。
