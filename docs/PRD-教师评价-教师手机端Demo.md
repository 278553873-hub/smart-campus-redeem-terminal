# 教师评价（教师手机端）Demo 方案

> 版本：V2.0
> 更新日期：2026-10-12
> 阶段：Demo 验证（客户方案确认）
> 入口：Demo 环境切换面板 → 教师评价
> 适用对象：产品经理、前端开发、设计、演示同学

## 1. 我们要做什么、不做什么

产品矩阵从「学生评价、班级评价」扩展到「教师评价」。首版只做教师手机端，先在 Demo 环境跑通
**「AI 录入 → 成长档案 → 数据维度呈现」**这条主线。

本产品的差异点不是"填表更快"，而是**老师根本不用填表**：一句口述、一张证书照片，AI（人工智能）
把它变成一条结构化、可计分的成长记录。所以第一屏就是**录入页**，数据维度的呈现放在第二屏。

本版不做：学校管理端（Web 后台、评价任务、考核算分、年度报告）；不与现有「教师-手机端」合并
（那条产品线已有几十所学校在用，教师评价还在验证阶段，独立入口、互不影响），只共用设计 Token
（设计令牌）与公共控件。

## 2. 入口与呈现

| 项目 | 约定 |
| --- | --- |
| 入口位置 | Demo 环境切换浮层，紧跟「教师-手机端」之后，常驻显示 |

## 3. 信息架构

底部三个入口，录入能力单独占一屏（这是与竞品最大的结构差异）：

| 入口 | 页面职责 | 页面常驻内容 |
| --- | --- | --- |
| 录入 | 用 AI 把一件事变成一条记录 | 指标弱入口、内容由 AI 生成声明、记录流（原始输入区 + AI 智能解读区）、悬浮录入条 |
| 成长 | 看自己的数据维度 | 本学期/累计积分、六大维度分布、时光轴 / 按类别 / 证书墙、分类筛选 |
| 我的 | 身份、积分账与设置 | 老师信息、本学期/累计积分与记录总数、积分规则、填报与审核记录、重置演示数据 |

录入页直接沿用我们自己教师手机端的成熟范式：

- 《记录页信息结构》：顶部工具行 → 全量记录事件流 → 悬浮录入条 → 底部导航；
- 《AI 智能解读卡》：整块卡片可点击进入编辑，字段内不再重复放编辑按钮；
- 《悬浮录入条》：中间「按住 说话」，左右为拍照与键盘，语音在当前页原位完成、不跳独立录音页。

## 4. 业务流程

### 4.1 三种录入方式，落到同一张待确认卡

| 方式 | 操作 | AI 做什么 |
| --- | --- | --- |
| 拍照识别 | 悬浮条左侧相机 → 选证书照片 | 识别事项名称、级别、等次、颁发单位、落款日期，并判断归属类别与分值 |
| 语音口述 | 悬浮条中间「按住 说话」，松开即发送 | 转写口述内容，抽取对象、级别、等次，补齐类别与分值 |
| 手动填报 | 悬浮条右侧键盘，或顶部「指标」 | 预选类别，给出该类别的赋分标准，老师只补必填字段 |

三条路径都会在记录流顶部插入一张**待确认卡**：卡片上半是原始输入（证书缩略图或语音胶囊），
下半是 AI 解读出的字段（事项名称、类别、级别、等次、颁发单位、落款日期）与分值。字段值本身
可点即改（不再出现"修改"文字按钮），卡片底部提示「提交后本学期积分 +N 分」，确认后入档。

### 4.2 状态流转

```
待审核 ──通过──→ 已通过（计入积分）
   │
   └──不通过（带原因）──→ 未通过（不计分，老师可改后重新提交）
```

- 提交后立即计入本学期积分，并在卡片与「我的」上标注待审核条数；
- 审核不通过的记录不计分，原因直接显示在记录卡与详情页；
- 已通过的记录在记录流里显示「已通过」，可在「填报与审核记录」中按状态回溯。

## 5. 成长页（数据维度呈现）

对齐竞品的呈现方式，但只用一行一条的维度条，不做装饰性图表：

- 顶部：本学期积分（大数）+ 累计积分 + 待审核条数；
- 六大维度：师德与育人、教育教学能力、教研与专业成长、学生发展贡献、组织协同与引领、
  创新实践与数字素养，每行「维度名 + 占比条 + 分值」；
- 三种档案视图：时光轴（按月分组）、按类别（按指标聚合）、证书墙（证书照片平铺）；
- 分类筛选：全部 / 荣誉表彰 / 教学比赛 / 论文课题 / 培训进修 / 学生发展 / 示范引领 / 数字素养。

## 6. 积分口径与依据

### 6.1 建模依据

1. 中共中央、国务院《深化新时代教育评价改革总体方案》（2020-10-13，中国政府网
   `www.gov.cn/zhengce/2020-10/13/content_5551032.htm`）：
   改进结果评价、强化过程评价、探索增值评价、健全综合评价；坚持把师德师风作为第一标准，
   突出教育教学实绩。
2. 兰陵县思源实验学校教师专业发展赋分办法（兰陵县人民政府官网公开，
   `www.lanling.gov.cn/info/3519/56542.htm`）：按「级别 × 等次」分档赋分；同类奖项依最高
   级别计分，各项合计封顶；以证书颁发单位和落款时间为准，按学年度两学期统计。
3. 云和县教育局《关于实行积分制管理促进教师发展的实施意见（试行）》(2020)：建立县、校级
   赋分项目库，每学年初可按重点工作调整赋分项目。
4. 临沂沭河学校教师专业发展评价办法：单项设置累计上限，避免同类重复刷分。

### 6.2 计分规则

- 同类取最高：同一类别在同一学年只计入分值最高的一条记录，不重复累计；
- 学年合计封顶：每学年成长积分合计不超过 30 分；
- 认定凭证：以证书上的颁发单位与落款时间为准，须为教育行政部门或其直属单位主办；
- 师德第一标准：师德表现单独记录，不参与积分；
- 统计周期：按学年统计，页面同时展示本学期积分；累计积分按学年分别封顶后相加。

完整分值表维护在 `teacher-eval-app/domain/scoringTable.ts`，页面在「我的 → 积分规则」同步展示。

### 6.3 与绩效的关系（重要口径）

客户端只讲「成长积分用于教师成长档案与发展性评价参考」，不出现绩效分配、考核结果应用的任何
表述，是否纳入绩效考核由学校端配置决定。该口径由测试守住：绩效、考核分配、一票否决等字样
不得出现在教师端页面。

## 7. 演示脚本（3 分钟）

1. 右侧环境切换 → 点「教师评价」，直接进录入页：玉林中学张岚老师的 13 条成长记录。
2. 按住「按住 说话」并松开 → 顶部出现待确认卡：语音胶囊 + AI 解读出的「学生发展与辅导 · 省级 ·
   一等奖」，底部提示本学期 +4 分 → 直接把等次点开改成「二等奖」，看分值实时变化 → 确认入档。
3. 点左下角相机 → 选「四川省高中语文优质课展评」证书 → 待确认卡识别出「教学比赛 · 省级 · 一等奖」，
   提示需要 6 分、本学期同类已有 3 分 → 确认入档，本学期积分从 4 分变成 7 分。
4. 切到「成长」：六大维度条、时光轴里的新记录、切「证书墙」看刚上传的证书照片。
5. 点任意记录 → 记录详情：积分依据、审核状态；未通过那条能看到原因。
6. 「我的」→ 积分规则讲清「同类取最高 + 学年合计封顶 30 分」；演示结束点「重置演示数据」。

## 8. 技术实现与约束

- 目录：`teacher-eval-app/`（与 `mobile-app/` 平级的独立产品线），入口在根
  `App.tsx` 的 `currentApp === 'teacher-eval'`；
- 录入页：`views/RecordFeedView.tsx`（记录流 + 悬浮录入条 + 待确认卡），
  `components/DraftRecordCard.tsx`（AI 待确认卡），`components/RecordFeedCard.tsx`
  （已入档记录卡），`components/QuickInputBar.tsx`（悬浮录入条）；
- 成长页：`views/GrowthView.tsx`；字段筛选分组与赋分标准分别在
  `domain/growthRecord.ts`、`domain/scoringTable.ts`；
- 演示外壳与 PRD：`TeacherEvalDemo.tsx` 负责顶部页签，PRD 内容在 `prd/prdContent.ts`
  （角色、分角色流程、六个价值维度、字段模型、计分规则、建模依据），由 `prd/PrdView.tsx` 与
  `prd/FlowDiagram.tsx` 渲染；改业务口径只改内容文件，不动渲染逻辑；
- 设计 Token：唯一来源是 `mobile-app/styles/teacherMobileTokens.ts`，只导入不复制，已被
  `mobile-app/views/TeacherMobileTokens.single-source.test.mjs` 纳入约束；
- AI 能力：Demo 阶段是确定性模拟（`domain/aiCapture.ts`），不依赖网络与密钥，接真实模型时
  只替换这一层；
- 演示素材：`public/assets/teacher-eval/` 下的三张样例证书照片；
- 验证命令：`node teacher-eval-app/domain/scoring.test.mjs`、
  `node teacher-eval-app/App.structure.test.mjs`、`node components/AppSwitcher.demo-navigation.test.mjs`、
  `node mobile-app/views/TeacherMobileTokens.single-source.test.mjs`、
  `node scripts/audit-teacher-mobile-render.mjs`（会真实渲染教师评价的 8 个页面，防白屏）。
