# 教师评价 Demo 使用说明

状态：第一版可交互页面，2026-10-14。按用户授权先制作页面并迭代，以候选精简推荐版举例；不代表学校已选定该方案或发布计分制度。

## 打开与体验

在 Demo 右侧“环境切换”中点击“教师评价”，或在当前开发服务地址后加 `?app=teacher-evaluation`。首屏打开教师本人的档案。颜色、字号、圆角、背景、手机壳与弹层复用教师手机端设计令牌和公共组件。

手机右侧通过“教师／管理者”胶囊切换演示身份，分别使用张敏和李岩，不再提供多个管理者入口。右侧“模拟真实手机”开关控制手机壳、状态栏及安全区；配色方案与渐变样式沿用教师手机端，统一影响记录、档案、报表、我的四个页面。管理者默认查看全校，切换“我的”保留教师个人能力；两种查看范围不构成额外角色。数据保存在当前浏览器本地，账号切换、刷新和重新进入模块后保留。右侧独立的“指标演示配置”卡片默认收起，可更改评价角色、是否需审核、是否区分等级；只影响新提交，既有记录保留其处理路径。此控制区用于演示后台配置能力，不是学校管理端页面。

## 已实现页面

| 入口 | 教师 | 管理者 |
| --- | --- | --- |
| 记录 | 本人记录、已通过、待审核、未通过；文本／预置语音／图片入口；详情、撤回、补充重提 | 本人及本人提交的他人记录；选人评价；顶部审核待办、通过／不通过及已处理记录 |
| 档案 | 姓名、学校、学科、年级、职称；基本信息、任职信息、资格证书、工作经历；本期积分、维度概览、成长时光轴、按指标查询 | 全校教师目录；姓名搜索、学科／年级筛选；任意教师完整档案；从档案发起评价 |
| 报表 | 本期积分、生效与待审记录数、指标分布、成果类别及级别分布、记录明细 | 全校人数、有记录人数、生效与待审记录数；相同分布统计、所有教师明细与档案入口 |
| 我的 | 个人身份、我的档案、指标说明、帮助 | 同一结构，保留个人档案入口 |

基本资料包含专业、学历、参加工作和入校时间；任职信息包含岗位、范围与周期；资格证书包含名称、发证机构、取得日期和脱敏编号；工作经历按时间展示单位和岗位。全部人物与资料均为虚构演示数据。第一版资料只读，资料维护入口及人事系统对接另行设计。

记录页按用户的主操作入口设计重做：管理者顶部“记录／审核（待办数）”直接复用原教师手机端滑动胶囊，教师只使用记录功能；依次展示指标、状态标签和AI记录卡。没有周期／查询筛选和“全校／我的”切换，查询在档案完成。录入功能保留公共底部录入条，审核功能隐藏录入条。记录标签为“全部、已通过、待审核（数量）、未通过（数量）”，审核标签为“待审核（数量）、已通过、未通过（数量）”。数量与对应列表一致，包含零值，不受当前标签或档案筛选影响。未通过卡片显示完整原因，提交人可修改重提，仍使用同一个事件编号；管理者可在审核的已处理标签追溯。待办只统计有权处理的记录，跨周期统计，排除自审。信息不足在输入处提示、尚未提交；不新增待补充业务状态。底部与原教师手机端一致：左拍照、中按住说话、右文字。按下显示“松开发送”，上滑显示“松开取消”；直接松开按指标配置免审生效或进入审核。语音使用预置家校沟通内容，重复提交会提示已记录；取消不保存，未连接真实麦克风。四项导航复用公共组件：记录、我的沿用原图，档案、报表通过imagegen生成同系列选中及未选中图。

从记录页“指标”或“我的 → 指标说明”打开全屏思维导图，展示学校当前四个维度及十二项指标；默认展示四个维度，点击维度展开指标，支持拖动、缩放及展开全部。点击指标查看定义、当前计分规则、分数边界、评价角色与审核要求；关闭详情后继续查看原位置，返回时保留来源页状态。右侧修改指标配置后，查阅页同步更新。

记录卡不展示年月分组。原始录入顶部用浅色显示录入时间（年-月-日 时:分）；语音先显示原始语音条，下方显示转写文字。解读区“时间：”为事件发生日期，与录入时间分别保存。输入仅分文本、语音、图片：文本直接展示原话，语音先展示原始语音条、再在下方展示转写文字，图片展示缩略图，不使用附件名称代替输入。本人文本和语音采用“今天，我……”的真实表达，例如“今天，我与刘甜家长沟通学生学习习惯。”。“时间：、对象：、指标：”在卡片内完整展示，对象是当前账号时显示“张敏(本人)”；加分识别采用原教师手机端绿色边框及浅绿底，去掉免审生效、规则说明、查看详情等重复文案。需审核的分值标待审核，未通过不显示为得分，原因直接可见。通用结果与“事项明细”分成两张卡；级别、学时、主办单位、阶段及本人分工按指标配置展示，缺少可选明细则不显示，无明细不生成空卡。研修不再展示“参训教师”。列表与详情使用同一组件，旧记录不改原分数和审核结果。

档案将身份、本期积分、已通过记录及四大维度得分合并展示，封面配书页银杏插画，四类资料入口独立排列、按需展开。成长记录默认按月展示日期与卡片分栏的连续时光轴，保留老师原话及审核状态；切换“按指标”可按四大维度浏览，点击末级指标直接进入对应记录。筛选入口集中选择指标、成果类别和级别，条件标签可一键清除；顶部按学期切换，记录区工具行随滚动吸顶。管理者全校目录同时展示教师身份、周期积分与已通过条数，点击进入同一档案结构，可从“记录表现”发起评价。不区分等级的日常记录显示灰色【个】，仅表示个人记录；报表单列“不区分等级”，开启等级但未识别到的记录另列“未识别等级”。所有报表从已通过事件计算，待审、未通过、撤回不计有效记录；教师目录包含没有提交记录的教师，保留其基础分，不推断优秀或生成质量排名。

## 建议演示路径

1. 教师张敏打开档案，分别查看四类个人资料。
2. 在记录页输入“今天，我完成了校级信息技术研修，共6学时，主办单位：学校教师发展中心。”，按演示免审配置直接生效；第一张卡显示通用结果，第二张卡显示活动级别、学习学时、主办单位，再查看档案和报表。
3. 从拍照入口选择“课题研究”图片，提交后进入待审核；切换管理者李岩，进入顶部“审核”并通过后同步更新记录、档案与报表。
4. 管理者李岩查看全校目录，从教师档案发起评价，核对对象与规则后确认提交。输入“经核实，张敏老师在课堂播放与教学无关的歌星作品并影响教学。”，按演示规则扣3分。只有投诉、尚未核实的事件在输入处提示先核实，尚未提交，不扣分。
5. 李岩的预置带教记录需要审核。李岩可查看、撤回，不能自审；当前Demo只提供一个管理者入口，该记录不出现在李岩的审核待办中。
6. 在外侧把研修学习改为需审核，再以新的内容提交，观察教师和管理者都按同一个审核开关分流。恢复配置或使用外侧重置演示数据；重置前需要再次明确确认。

未通过后修改重提保持同一事件编号及处理历史；免审记录或尚未审核的本人提交可撤回，计分同步恢复。需要审核且已通过的记录不提供直接撤回入口，正式更正流程后续设计。

## 预置演示规则与边界

精简版基础分合计100、上限145、下限25。每个指标分数＝基础分＋本期已通过事件的加减分，再限制在该指标上下限内；一级维度求和，不再叠加权重。两个示例学期用于演示周期隔离，补录按发生日期归属，不加到错误学期。

C06沟通反思、C07研修学习、C08教研改进，本轮预置完成一次加1分，用来展示免审直接生效。这是新增演示数值，不是原始玉林方案或学校已确认的标准；学校正式规则仍待确定。不再拆分过程、心得或反思后交领导另行打分。

其他预置规则从候选方案讨论稿取具体例子：C01已核实不当课堂行为／无故缺课扣3分，C02公开辱骂扣3分，C03冒用证书扣5分，C04分层教学案例加2分，C05个别支持加2分，C09市级主持课题结题加3分，C11完成带教加2分，C12区县级本人执教公开课加2分。C10完成协作只归档，第一版尚未制作任务未完成扣分情境。需审项必须审核后计分；没有命中已配置计分条件则0分归档，不猜分。

文字识别使用可解释的预置关键词和条件匹配；语音入口带入可编辑的预置口述，材料入口提供三份预置材料摘要。未接入实际录音、图片文字识别、大模型、文件上传或证书真伪核验，不应将其描述为真实识别准确率。手机壳外明确说明此限制。原始图片定位、多页归并、批量部分失败、语义去重、阶段筛选、跨学期“全部经历”、学年总评、报告摘要与导出尚待后续迭代；本期页面保留对应方案要求，不宣称已经实现。

指标与资料在数据层，通用计分、权限、周期、审核及修订在领域层，预置识别是独立演示适配器，浏览器保存与界面分别维护。正式接入可替换适配器和数据服务，不能将预置匹配当作真实AI业务实现。

学校仅增加“区分等级”开关，等级固定为校级、区级、市级、省级、国家级；不再要求学校配置明细字段。其余明细采用平台预置提取，记录保存当时的设置和明细。详见[指标明细字段与AI识别方案](指标方案/指标明细字段与AI识别方案.md)。

## 档案视觉重设计（2026-10-15）

结合 Mobile App Design Standards、UI/UX Pro Max 和竞品首页、时光轴的实际体验，采用暖纸成长手册风格。封面突出姓名与周期得分，四类资料入口统一造型；指标按四维度分组，记录保留自然表述与级别。管理者目录共用同一视觉语言，进入教师档案后保留记录表现入口，返回时保留搜索条件。

已检查教师与管理者页面、资料弹层、指标跳转、级别筛选、目录搜索及返回；未新增演示事件或执行审核。新增文字配色对比度最低4.76:1；档案交互热区最小44×44像素，正文15像素，353像素内容宽度下没有横向溢出。构建、模块类型检查、46页渲染检查和14项领域检查通过。

## 等级开关与标签（2026-10-16）

在右侧“指标演示配置”可切换每个指标是否区分等级。默认研修学习、科研成果、示范服务开启，其余关闭。开启后统一使用校、区、市、省、国标签；旧区县级、县级归一为区级。关闭时不识别新记录的等级，显示灰色【个】表示个人记录，不默认显示校级，也不增加等级档位。已开启但未识别等级的记录不显示文字标签，列表保留等宽空位。历史记录保留原认定。

时光轴标题、事项明细和报表明细共用单字标签，样式为实色底、白字、4px 小圆角方块；个灰、校蓝、区绿、市橙、省紫、国红。不会为了显示【个】额外生成空的事项明细卡。档案筛选与报表按同一五档查询；报表将“不区分等级”和“未识别等级”分开。带等级条件的评分规则与关闭状态冲突时，配置区提示，新录入不提交；侧栏未提供评分标准编辑，可恢复等级开关。


本轮验证：构建、模块类型检查、20项业务检查、51个页面渲染检查通过。浏览器确认了等级开关刷新后保留、恢复开关后历史记录不变、区级筛选能查到旧区县级记录；已恢复原配置、清除筛选，未新增或审核记录。

标签样式更新后，浏览器确认个人与等级标签等宽、标题对齐，无页面报错；六种底色与白字的对比度均超过 4.5:1，构建与类型检查通过。

## 报表整合（2026-10-16）

报表页通过开放式文字页签切换“成长看板／统计报表”，选中项以深色加粗文字和底部短线标识。看板包含周期概览、免审与审核通过数量、月度趋势、指标及成果类别／等级分布，点击可查看记录依据。教师的统计报表是十二项指标得分表；管理者可选择记录统计、人员结构、资料登记，按姓名、学科、年级筛选，包含零记录教师。人员结构可按学科、年级、职称、学历展开名单；姓名进入档案后返回保留报表选择。

演示路径：切换管理者 → 报表 → 统计报表 → 记录统计 → 点击“张敏：未通过1条”查看原因；回到统计报表 → 人员结构 → 学历 → 硕士研究生 → 张敏，查看档案再返回。切换教师可看本人指标基础分、范围与当前分。

记录数量按被评价教师归属统计，包含管理者录入的记录，不等同于本人发起评价次数。资料登记只按四类现有内容判断，不是教师能力评分。职称资格判断、年龄统计、缺乏明确口径的全校平均比较与真实 AI 报表解读未接入。
