# 录入审核与通用文案规则

状态：统一业务口径，2026-10-14更新。五套候选方案共用此流程；方案仍待选，逐项审核开关和分值均为待学校确认的演示配置。

## 学校定规则，AI匹配，系统计分

学校预先定义指标、必要证据和加减分规则。教师上传文字、语音或图片即可，无需按固定格式写报告；信息确实不足时AI针对性追问。AI提取对象、发生时间、指标、成果级别及本人贡献，匹配学校规则并展示依据。系统计算分值、累计次数、重复限制和上下限。

心得、反思、证书、过程或成果只作为材料描述与检索标签，不分别设审批路径。每个末级指标统一配置“评价角色”和“是否需审核”，审核开关适用于该指标所有允许提交的角色。不同类别仍可配置不同采集字段和计分条件，但使用该指标统一的审核要求。

## 两个角色，共用审核开关

| 角色 | 能力 |
| --- | --- |
| 教师 | 提交本人材料、补充缺项、查询处理结果和成长档案。 |
| 管理者 | 查看全校教师数据及学校报表、评价有权限的其他教师、审核需审材料；兼任教师时保留本人记录能力。 |

管理者涵盖校长、教研组长及授权评选人，是权限角色。同一账号可兼任；本人需审材料由另一名管理者处理。学校配置权限在后台定义，本期不制作学校管理端页面。

| 指标配置 | 处理方式 | 生效结果 |
| --- | --- | --- |
| 不需审核 | 教师提交本人材料或管理者提交他人评价；AI匹配规则，系统校验及计算 | 直接计分入档 |
| 需审核 | 提交后由AI形成事实、指标、规则依据及分值，管理者一次通过或退回 | 通过后计分入档，不另行打分 |

管理者录入他人评价时确认对象与事实，再提交；是否进入审核由指标开关决定。需审时由另一名管理者处理，录入确认不能替代审核。同一账号兼任教师时，本人材料同样使用指标配置，不能自审。

教师本人录入和管理者评价他人是两个独立入口，不能理解为先录入再由管理者打分。汇报表保留“评价人”列，教师后标注免审／需审核。管理者审核意见关联原记录，不另建一条成果。系统可信归集保留来源和原认定编号，不增加人的角色，不重复计分。

## 自动处理边界与恢复

- 必填缺失、人员或指标匹配歧义：待补充，指出具体问题，不要求重新填写整张表。
- 证据冲突、疑似重复或事实尚未核实：待核实，不自动加减分；经授权人员处理后按指标规则继续，已经完成所需审核时不重复审核。
- 没有发布计分规则：可按审核开关归档，但显示“仅归档”；已发布规则存在歧义时待规则确认，不由AI编造分值。明确不满足加分条件则本次不加分，不转人工自由打分。
- AI可以检查材料内容与规则的一致性，不能仅凭识别成功保证外部证书真实。免审是学校授权的处理方式，学校可将整个指标改为需审核。
- AI不从反思中的困难、探索失败或未经核实投诉推断扣分。负向事实由管理者核实并确认，依据学校已发布规则处理；教师可补充说明、申请纠错。
- 更正及撤销保留原因与历史，按有效事件重算。正式师德等次和处分另按学校制度形成，不由事件分数自动生成。

## 学校配置的核心字段

| 字段 | 配置内容 |
| --- | --- |
| 指标 | 名称、定义、上级、适用范围及必要证据 |
| 评价角色 | 教师、管理者或两者；教师评价本人，管理者评价本校有权限的其他教师 |
| 是否需审核 | 每个末级指标一个开关，适用于允许的提交角色；需审时由另一名管理者承担 |
| 计分规则 | 触发与排除条件、必要证据、级别／阶段／贡献条件、固定分值或明确量规、次数与去重限制 |
| 分数边界 | 基础分、上限分、下限分 |
| 周期与版本 | 学期等周期、规则生效时间、历史版本及更正权限 |

管理者主要确认事实成立、规则适用；系统执行已公布的计算。需要质量量规时，学校先定义可检验标准，AI逐项给出证据及建议，管理者在同一次审核中确认，不再另发质量打分任务。

## 指标命名约定

二、三级指标优先采用四字名称。同一业务含义统一使用同一名称，例如“成长规划”“教学反思”“课题研究”“论文专著”“讲座献课”。阶段性或范围性细分保留差别，如“课题立项／课题实施／课题结题”“校内研修／校外培训”，通用类别仍关联“课题研究”“研修培训”。

复合指标不为凑四字删除业务含义：保留“论文与课程成果”“指导与应急”“师生家校沟通”三个较长名称。精简方案的综合项可用“科研成果”“示范服务”等上位简称，具体包含范围在定义和通用类别中说明。

各方案末尾记录二级领域和末级指标的原名称、简称与稳定编号；HTML同时支持原名和简称搜索。原文对照是来源记录，不随展示名称一并覆盖。

## 计分与演示配置

完整字段和算法见[指标字段与事件计分模型](指标字段与事件计分模型.md)。精简版示范两种审核配置：C06、C07、C08不需审核；C04、C05、C09至C12需审核；C01至C03仅管理者可评价，不需审核。免审指标可以自动计分，不再把免审固定等同于只归档。

五套候选的学校规则均未正式发布。未配置计分的候选仅展示档案，配置后才按规则计分；指标目录、来源依据和选型状态不因流程简化而改变。

手机端结构及全校报表见[教师手机端页面结构方案](../教师手机端页面结构方案.md)。管理者全校查看是账号权限，指标评价角色及审核开关另行判断；不因能查看就拥有修改或自审权限。
