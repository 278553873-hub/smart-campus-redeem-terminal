# 方案B 国家标准转译版

状态：候选，未选定。方案标识：`professional-standard`，草案版本：`0.1`。

依据2012年正式《中学教师专业标准（试行）》的3个维度、14个领域建立三级结构。为便于校本采集，每个领域提出2个观察指标，共28项；它们是本项目转译，不是国家标准原文的28条要求，也不能宣称已经逐条等价替代正式标准的63项基本要求。[正式标准全文](https://zh.ujn.edu.cn/info/1293/12162.htm)

适合重视教师专业培养、学校标准覆盖和发展诊断的学校。相比成果登记，它更关注材料能够证明的专业行为。知识类指标需要通过任务、教案、课堂与评议证据判断，不能仅靠学历或培训证书推断掌握程度。

默认采用分领域发展反馈，不设置总分。若学校需要计分，再按岗位公布评分量规与权重。日常采集、学期反馈、学年形成发展报告；正式师德结论另按适用制度衔接。

目录使用领域展示简称，原标准完整名称见末尾“指标简称对照”；简称不代表修改正式标准。

## 证据与配置建议

专业理念与师德可用自评、规范履职和多方反馈；专业知识可用任务作品及专业评议；专业能力可用课堂观察、学生学习证据、育人活动和实践改进。一次公开课可以关联知识与能力观察项，不要求重复上传，也不据此对全部指标自动定级。

首版若选B，可演示B25、B27及B28统一免审，B17由管理者一次审核。AI按学校规则生成评价依据，系统在通过后计分；未发布计分规则时仅归档。

学校可进一步展开原标准基本要求，或合并相近观察项。正式定稿时逐条检查63项要求的去向，记录增删原因。共用的权限、审核与配置能力见[方案库说明](README.md)。

## 指标释义与加扣分理由（校本讨论稿）

以下逐项释义和理由由本项目补充，均为待学校确认的建议，不是来源文件已发布的评分细则。加分、扣分或质量分调整仅在学校正式启用相应规则后适用；默认归档不产生分数。具体分值、基准、上限和周期待选型后确定。

成果撤销的“回退原分”只是更正已计分，不是再次处罚；同一事实不得重复扣减。质量项按量规评定，未获奖、未上传、不适用岗位、探索失败和未经核实的投诉不得直接扣分。正式师德结论单独处理。
