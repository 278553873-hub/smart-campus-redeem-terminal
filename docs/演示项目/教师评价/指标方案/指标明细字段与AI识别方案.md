# 指标等级与 AI 识别简化方案

更新：2026-10-16。适用范围：教师评价手机 Demo，以精简推荐版举例。替代前一版由学校逐项配置明细字段的方案。

## 1. 学校新增一个开关：是否区分等级

学校维护指标名称、定义、评分标准、评价角色、是否审核、基础分与上下限，并增加“区分等级”开关。学校不再配置字段类型、枚举选项、提取说明或通用明细表单。

| 设置 | 识别与保存 | 手机端展示 |
| --- | --- | --- |
| 区分等级＝是 | 从本次事件的明确依据中识别五档等级之一 | 时光轴标题前显示【校】【区】【市】【省】【国】 |
| 区分等级＝否 | 不为新记录保存等级 | 显示灰色【个】，代表个人记录，不默认成校级 |
| 已开启但无法识别 | 等级留空，不猜测 | 不显示文字标签，列表保留等宽空位；统计单列“未识别等级” |

“不区分等级”和“校级”含义不同。前者表示这个指标不采用等级分类，后者表示事件有校级认定依据；将二者合并会误导档案阅读和报表统计。日常家校沟通等个人记录用【个】保持标题对齐；“个”仅用于展示，不增加第六档等级，不改变计分、筛选或统计口径。

## 2. 平台统一五档

| 等级 | 标签 | 兼容处理 |
| --- | --- | --- |
| 校级 | 校 | 不能仅因事情发生在学校就认定为校级 |
| 区级 | 区 | 县级、旧版区县级统一显示为区级 |
| 市级 | 市 | 不从活动举办地点推定 |
| 省级 | 省 | 不从主办单位行政级别推定 |
| 国家级 | 国 | 以材料明确认定为依据 |

不再提供集团级作为新的可选档位，也不将旧集团级数据映射成校级。原始表述保留；无法归入五档的等级不强行转档。标签统一为 22×22px 实色方标、4px 小圆角、白色粗体字。校蓝、区绿、市橙、省紫、国红，个人记录用灰色【个】；文字与颜色同时辅助识别，读屏名称和悬停说明保留完整含义。

## 3. 精简版示例

| 指标 | 默认区分等级 | 其他明细及计分 |
| --- | --- | --- |
| 沟通反思、教研改进 | 否 | 识别完成事实，沿用完成一次加1分的演示规则 |
| 研修学习 | 是 | 可识别学时、主办单位；完成一次加1分，等级不额外加分，缺等级不阻塞日常记录 |
| 科研成果 | 是 | 可识别成果类别、阶段、本人分工；市级课题结题且本人主持加3分 |
| 示范服务 | 是 | 可识别本人分工；区级公开课且本人执教加2分 |
| 其余指标 | 否 | 沿用既有评分标准 |

学时、主办单位、成果阶段、本人分工等由平台内置提取能力处理，学校无需配置。它们不构成新的指标层级或系统角色。没有依据的明细不展示，不补造“参训教师”等冗余身份。

开关控制等级识别和分类，分值仍由已发布评分标准决定。关闭等级时，如果评分标准仍写有“市级加3分”等条件，必须同步调整评分标准；Demo 会在配置区提示冲突，并在新录入时阻止使用这组矛盾配置，不擅自删掉计分条件。当前侧栏不提供评分标准编辑，需恢复等级开关或由后续学校配置功能调整标准。

## 4. 两张识别卡与时光轴

原始录入继续展示浅色录入时间、原话／图片；语音条下面展示转写内容。

- **AI 智能解读卡**：时间、对象、指标层级和加减分。加分沿用绿色边框，审核开关及两种身份逻辑不变。
- **事项明细卡**：等级及实际识别到的其他明细。有等级时显示对应单字标签，无明细不生成空卡。
- **时光轴**：等级标签紧邻指标标题，不在底部重复等级文字。沟通等不区分等级的记录显示【个】，所有标签等宽，标题对齐。
- **查询与报表**：档案筛选提供统一五档；报表区分“校级”和“不区分等级”，已开启但没识别到等级单列“未识别等级”。统计和明细下钻使用同一口径。

## 5. 历史记录与本期边界

每条记录保留提交时的等级开关、明细及计分依据。修改开关只影响新提交，不改变历史标签、分值或审核结果。旧“区县级”做显示与查询归一，原始文字和历史处理信息保留。

Demo 已实现开关、五档归一、单字标签、统一筛选统计和本地保存，侧栏用于演示学校配置能力。本期仍使用预置的文字／语音／图片识别，不代表已经接入真实 AI；学校管理后台、正式多租户配置服务及评分标准编辑另行实现。
