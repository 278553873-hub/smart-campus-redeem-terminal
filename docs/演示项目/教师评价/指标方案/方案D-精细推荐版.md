# 方案D 精细推荐版

状态：候选，未选定。方案标识：`detailed-development`，草案版本：`0.1`。

这是面向精细化管理的推荐候选，三级结构为6个维度、20个领域、60个观察指标。它综合玉林材料、教师专业标准以及数字素养要求进行产品化设计，分开呈现教研科研、专业成长和数字素养；不是任何一篇论文的原表，也不声称是一套已经验证的标准量表。依据与研究范围见[指标模型研究](../教师发展评价指标模型研究与建议.md)。

适合已有过程数据、专业评价人员及岗位分工，希望按具体短板制定成长目标的学校。与A相比，课题阶段、学习转化和数字实践划分更细；教师仍以提交材料为主，由系统匹配，不能把60项变成60份强制填报任务。

正式师德结论独立形成；本方案将师德观察压缩在9项中，并须保留十项职业行为要求的完整映射，其中政治方向和爱国守法合并在D01观察项。其他指标按岗位适用，不强制所有教师承担班主任、带教或工作室任务。

## 证据和评分建议

每个领域使用与工作相应的材料：师德使用正式评议与核实事实；教育教学使用设计作品、课堂观察和育人案例；科研使用阶段证明及贡献；专业成长使用学习、计划和应用证据；协作引领使用任务、受助反馈和活动证明；数字素养使用真实教学应用、安全与伦理实践证据。

默认先做分领域反馈。若学校需要专业发展综合分，可讨论教育教学40%、教研科研20%、专业成长15%、协作引领10%、数字素养15%的试配，师德保留独立结论及底线约束。该比例只是本项目待评审建议，尚未启用。数字应用案例可以被多个维度引用，但需明确各自观察点与计分贡献，防止同一事实重复累加。

周期建议学期诊断、学年汇总；多年课题按里程碑归期。课堂类质量评价需要量规和观察证据，不能凭上传照片自动定级。首版若选D，可用D26反思免审、D28立项需审、D29阶段成果与D30结题区分，以及D38外部培训审核来展示精细度。

其他权限与审核边界见[方案库说明](README.md)。

## 指标释义与加扣分理由（校本讨论稿）

以下逐项释义和理由由本项目补充，均为待学校确认的建议，不是来源文件已发布的评分细则。加分、扣分或质量分调整仅在学校正式启用相应规则后适用；默认归档不产生分数。具体分值、基准、上限和周期待选型后确定。

成果撤销的“回退原分”只是更正已计分，不是再次处罚；同一事实不得重复扣减。质量项按量规评定，未获奖、未上传、不适用岗位、探索失败和未经核实的投诉不得直接扣分。正式师德结论单独处理。

| D01 | 在教育教学和公共履职中落实教育方针、遵守法律与岗位要求，以核实行为和正式评议为依据。 | 独立评议 | 基本履职作为达标要求；突出事迹另按学校表彰制度认定。 | 经正式程序确认违反相应职业要求时，进入师德评议，不由材料识别直接扣分。 |
| D02 | 考察备课、授课、辅导等岗位职责是否按要求完成，而非仅统计到岗或上传次数。 | 独立评议 | 基础职责达标不额外加分；超出岗位的有效贡献须单独认定。 | 失职事实经核实后按适用制度处理，不能凭单次缺少材料作出结论。 |

| D04 | 关注学生尊严、平等学习机会及合理差异支持，结合行为证据与多方反馈判断。 | 独立评议 | 日常尊重学生属于底线要求；突出关爱事迹可独立认定。 | 经核实的歧视、侮辱等失范事实进入正式评议，不按投诉数量扣分。 |
| D05 | 在本人职责范围内落实风险预防、及时报告、处置与跟进，不以事故是否发生单独归责。 | 独立评议 | 基本安全职责不加分；有依据的突出应急贡献另行认定。 | 经核实未履行本人安全职责时进入正式评议，不能将不可控结果自动归责。 |
| D06 | 考察职业言行、情绪管理、交往方式是否尊重学生并保持恰当边界。 | 独立评议 | 规范交往为基本要求；不按好评数量累计师德分。 | 经核实的越界或不当言行依正式程序评价，不从聊天片段直接定性。 |
| D07 | 考察考试评价、成果署名和材料申报是否公平、真实、可追溯。 | 独立评议 | 诚信履职为基本要求，不因多交证明而加分。 | 造假、冒名或不公事实经正式核实后处理；同时更正相关档案与原得分。 |
| D08 | 考察教育活动中的利益关系及廉洁要求，以核实行为和正式结论为证据。 | 独立评议 | 廉洁达标不加分，表彰与日常考核分开。 | 经核实违反廉洁要求时转正式师德程序，不以猜测或未核实举报扣分。 |
| D09 | 考察兼职、培训及其他从教活动是否符合学校适用的职业要求。 | 独立评议 | 规范从教为底线，不按承诺书数量加分。 | 经核实的不规范从教行为按正式制度处理，不自动推导处分或分值。 |
| D10 | 通过诊断学生已有基础与学习困难，形成明确、可观察且与课程要求一致的学习目标。 | 质量评价 | 有诊断依据，目标适合学生起点，且目标与后续任务一致，可按质量量规提高得分。 | 目标明显脱离学生起点或无法检验，经专业评议可下调质量分。 |
| D11 | 将目标、内容、活动、资源和评价组织成连贯的单元或课时方案。 | 质量评价 | 设计逻辑连贯，学习活动能支持目标，且有试用改进证据，可提高质量分。 | 目标与活动脱节、关键学习环节缺失，经评议可下调质量分。 |
| D12 | 设计与目标一致、负担适当且能回应不同学习需要的作业和学习任务。 | 质量评价 | 任务有明确目的、适当分层，并根据学生反馈优化，可提高质量分。 | 无效重复、负担明显不当或分层与需要不符，经评议可下调质量分。 |
