[打开 HTML：指标思维导图与加扣分明细](指标方案/教师评价指标方案-导图与明细.html)

当前阶段：指标方案仍待正式选定；已按用户授权以精简推荐版制作第一版可交互手机端 Demo。产品支持一校一定制，学校可以基于模板调整层级、名称、数量、证据字段、审核职责、权重和周期。

本期不制作学校管理端页面。方案库和配置要求用于明确后台应支持的定制能力，不能表述为后台已经实现；选定方案后用其学校配置驱动手机端演示。

当前统一流程：学校定规则，AI匹配规则，系统计分。每个末级指标统一配置评价角色与一个审核开关；按指标配置直接生效或一次审核生效，不再单独人工打分。详见[计分模型与精简版规则示例](指标方案/指标字段与事件计分模型.md)。
