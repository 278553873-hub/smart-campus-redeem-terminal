选型后在本文件填写：方案标识及版本、采用与删改的指标、适用岗位、审核职责、免审规则、是否启用计分及其权重、考核周期、演示案例。可以基于某套方案再定制，但需形成一份明确的学校方案后再实施。

学校正式使用时由学校授权人员发布配置；本文件记录的是产品 Demo 的选择，不代替校方制度审批。
