# 玉林中学教师发展评价指标模型研究与建议

研究参考稿，非已选定的 Demo 方案；当前选型见[方案选型记录](方案选型记录.md)。适用范围：中学教师专业发展、教师手机端材料记录与审核，以及未来学校考核方案衔接。检索日期：2026年10月13日。

本文提出的玉林参考候选采用三级校本指标：五个一级维度、二十一个二级领域、四十三个三级观察指标。一级维度保留玉林方案正文的师德师风、专业能力、教学能力、教研能力、社会影响；三级指标是本项目拟议内容，不是玉林已发布的正式考核细则。学校可以裁剪、扩充和版本化。

师德采用独立评议和底线约束；其他维度在具体考核方案中配置权重。专业发展以学年为主周期、学期为反馈节点，日常记录持续积累；人事年度考核采用主管部门规定的周期。

## 1 玉林方案正文和图片的含义

主要依据为[玉林中学平台建设规划方案](参考资料/四川省成都市玉林中学教师专业发展数字化平台建设服务规划方案8.5.docx)。该文件是2025年8月的平台建设和服务规划，包含分期建设指标模型的计划，不能视为一套已经定稿并完成效度检验的学校考核指标表。

正文明确：以《中小学教师专业标准》开展采集、维度建立和分析；采集教学、教研、管理等多源数据；总体评价列举上述五个维度；指标树、目标值、权重、数据来源及评分细则可配置。第二年按学期登记个人计划，第三年支持追踪近一年的变化。三年建设进度、近一年分析窗口，都不是正式考核周期的规定。

文档的十张内嵌图片按媒体编号逐张核对如下。图片编号用于定位原文件中的示例，不是业务指标编码。

| 图片 | 实际内容 | 对本项目的意义 |

| 2 | 平台架构，包含人事、任教、奖惩、科研、培训、学习、考核、评价及模型管理 | 数据采集、评价模型和应用服务应分层，不能只围绕奖证建模 |

图片6的下级原始分也不能直接与上级权重相加。例如基础类列学历5、工龄10、校龄10；专业引领组列课堂展示及赛课80、论文30、课题20等。若用于计算，必须补齐归一化、封顶和计分公式，原图不能推出这些公式。也不建议把学历、工龄、校龄默认变成本学年能力分，避免资历替代实绩。

因此，对于玉林参考版，指标库采用正文五维，画像通过明确的映射生成。未来若学校决定使用图片9的五维画像，可将教学能力中的育人指标单独展示、专业能力中的数字指标单独展示；必须交代其余专业基础、协作引领数据的展示去向，不能直接改标签后声称是同一模型。首版手机端先按指标浏览证据，不制造未经配置的雷达分数。

原规划第一年档案库描述强调审核后入库。本项目已明确采用学校按指标配置免审和人工审核的规则，该业务要求优先；原规划的统一审核表述不照搬。

## 2 标准 论文与成熟框架

### 2.1 国内标准提供内容边界

2012年正式《中学教师专业标准（试行）》为三个维度、十四个领域、六十三项基本要求。网上常见六十一项是2011年征求意见稿的数量。正式版的专业理念与师德、专业知识、专业能力，是本项目检查覆盖范围的底层标准，不要求学校只能用三个展示维度。[2012年正式标准转载全文](https://zh.ujn.edu.cn/info/1293/12162.htm)，[教师〔2012〕1号及附件全文](https://jiaoxue.hgnu.edu.cn/2019/0116/c589a22602/page.htm)。

2022年《教师数字素养》行业标准包含五个一级、十三个二级、三十三个三级维度，适用于培训与评价。数字素养应包含技术应用、责任和发展，不能用打开应用次数、人工智能生成材料次数代替。本模型只选择其与校本工作直接相关的观察项；若开展完整数字素养专项测评，应另建完整标准对应方案。[教育部标准原文](https://www.moe.gov.cn/srcsite/A16/s3342/202302/W020230214594527529113.pdf)。

四川2025年施行的师德办法要求过程记录与年度评议衔接、学期汇总，正式结果经多方评价和工作小组评议形成。师德不合格会影响年度考核等结果；评价要素及权重还须遵循市州或区县规定。本项目不能用人工智能审证书或单人材料审核代替正式师德评议。[四川省中小学教师师德评价考核办法](https://scnj.gov.cn/ztzl/jczwgkzl/gkly/ywjy/jsgl/jsxwgf/14026318.html)，[地方教育局官方解读及施行时间](https://www.jiajiang.gov.cn/jjx/whjy/afec6497ac634a53834212029.html)。

Danielson教学框架的2022版有四个领域和二十二个组成部分，覆盖准备、学习环境、学习经历和专业实践，体现了可观察行为与评价量规的成熟做法。本项目借鉴“指标有行为描述、证据和等级锚点”的方法，不复制其完整商业量规，也不直接移植美国情境的结论。[框架发布机构](https://danielsongroup.org/the-framework-for-teaching/)。

公开校本办法也显示权重没有统一答案。济南市莱芜第一中学对普通文化课教师与音美、体育教师采用不同结构；部分内容按学期汇总，工作成效按学年计算。这证明平台需要岗位方案和多周期支持，不代表其具体考试成绩占比适合玉林。[学校公开考核办法](https://qsy.jinan.gov.cn/col/col8932/art/2026/art_656ab0ba7e7c411eb3c38d60f06b2c80.html)。

成熟做法可以概括为：标准覆盖、多源证据、过程与结果结合、按岗位适配、评价量规、人工认定与申诉。没有可靠依据将某一套平台截图的维度、分数或权重称为全国统一的成熟方案。

## 3 指标层级和边界

| 层级 | 内容 | 示例 |
| --- | --- | --- |
| 一级 | 校本发展维度 | 教研能力 |
| 二级 | 相对独立的工作领域 | 课题与研究成果 |
| 三级 | 可观察、可收集证据的具体指标 | 课题立项与阶段贡献 |
| 指标配置 | 定义、适用岗位、证据要求、审核规则、来源、版本 | 需要立项书及本人角色；由科研职责人员审核 |
| 材料字段 | 某次事件的属性 | 项目名称、批准机构、本人角色、阶段、日期 |

指标配置与材料字段不算第四级指标。“国家级、一等奖、培训时长、证书编号”是属性；“照片、证书、论文”是证据载体。每个三级指标至少有清楚的判定问题和证据要求。

一级维度职责界定：专业能力负责专业基础、学习及数字素养；教学能力负责教学和育人的实际实施；教研能力负责对实践的研究、改进及转化；社会影响负责协作、带教及服务贡献。师德判断行为是否符合职业要求；育人指标判断实际教育工作及效果，两者可引用同一事实但不能机械重复加分。

## 5 审核与自动入库如何执行

本项目当前采用每个末级指标配置评价角色和是否需审核，对允许提交的角色统一作用，不再按心得、反思或成果类型配置审批分支。完整口径见[录入审核与通用文案规则](指标方案/录入审核与通用文案规则.md)。这是产品流程建议，不是对玉林原文或研究结论的改写。

| 来源 | 处理 | 更新结果 |
| --- | --- | --- |
| 教师提交，指标免审 | AI提取事实、匹配指标和已发布规则，系统校验 | 自动计分并入档；未配置计分时仅归档 |
| 教师提交，指标需审核 | AI形成事实摘要、规则依据及分值，管理者一次通过或退回 | 通过后系统计分入档，不再另发人工打分任务 |
| 管理者评价他人 | 录入已核实事实并确认提交 | 按指标开关直接生效或由另一名管理者一次审核后计分入档 |

字段不完整或匹配歧义先待补充；证据冲突或事实尚未核实先待核实；无规则不猜分。AI不从自述困难或未核实投诉直接推断扣分。正式师德等次与处分另按学校适用制度形成。

同一事实默认匹配一个主计分指标，可关联其他指标作为证据。确有多个独立事实时才分别按规则计分；各自遵守审核配置，不因一项免审全部自动通过。系统识别重复事件，申报、审核和归集不重复建档计分。

管理者按学校授权处理他人材料，兼任教师时本人申报仍按同一指标要求，不能自审需审材料。质量评价需预设明确量规，由AI提供逐项依据，在同一次审核中确认；不从单一奖证推断全部专业能力。

## 6 权重与评分方式

### 6.1 权重属于考核方案

长期指标库不绑定唯一永久权重。同一指标在专业发展、班主任专项、骨干申报等方案中可以承担不同作用；已有记录可复用，不要求重复上传。方案记录适用岗位、周期、指标版本、权重、证据来源、评分量规及缺失处理方式。

成长档案不必有总分。正式考核若需要综合分，应在学校确认方案后使用权重。师德保留独立的正式等次及底线约束，其他优秀成果不能抵消师德不合格。若当地正式考核规定还设置师德数值权重，按该规定配置，不能用本项目的示例替代。

以下只是一套任课教师专业发展试配方案，便于讨论，不是玉林现行制度，也不是论文检验过的最优比例：

| 维度 | 试配方式 | 取舍理由 |
| --- | --- | --- |
| 师德师风 | 独立等次与底线约束 | 保留正式评议，不能用成果抵消 |
| 专业能力 | 20% | 支持专业基础、持续学习和数字素养 |
| 教学能力 | 50% | 核心职责，含育人实践；建议该维度至少三分之一份额用于育人，具体比例由校方确定 |
| 教研能力 | 20% | 重实践问题、改进与成果转化 |
| 社会影响 | 10% | 按岗位评价协作、引领和服务，避免荣誉主导 |

师德之外的四项权重合计100%。班主任提高育人相关指标份额；骨干岗位增加带教与引领的适用要求；音体美、初高中和不同学科使用适配证据。所有变化在周期开始前形成适用方案，不能期末根据谁得分高再改权重。

### 6.2 计分方法与能力量规

事实类可按学校认可学时、任务完成情况、成果规则计算，但应设置适用目标和上限，避免“材料越多能力越高”。能力类采用带行为锚点的量规，例如“需改进、达到要求、表现良好、形成示范”四档；四档是本项目建议，不是直接等同于法定年度考核四等次。证据不足单列，不能自动当作零分或需改进。

例如C09“评价结果用于教学改进”：

| 等级 | 拟议行为锚点 |
| --- | --- |
| 需改进 | 已有充分观察证据表明评价问题没有转化为适当的教学调整 |
| 达到要求 | 能据具体学习问题调整教学，并提供实施证据 |
| 表现良好 | 连续追踪调整效果，能说明不同学生的变化并继续改进 |
| 形成示范 | 方法经多次验证，能解释适用条件，并支持同事实施与改进 |

没有提交材料或只有一张活动照片，不能直接选第一档。课堂能力宜由多次观测、多名受训观察者及学生学习证据综合判断，不要求每一次日常记录都走多名评委审批。

维度分须先根据已公布规则换算到统一尺度，再做加权。嵌套权重应逐级相乘，不能与原始分叠加。不适用项由岗位方案预先排除并明确权重安排；适用但证据缺失则按缺失规则处理，不能自动重新分配权重来提高分数。手机端展示总分前必须能追溯原始证据、评分依据和方案版本。

权重定稿建议采用标准逐条映射、校内教师及职责人员讨论、专家咨询与历史数据试算，检查不同岗位的结果和不合理激励。若采用层次分析法辅助权重选择，应检验专家判断一致性；数学计算不能代替学校对育人导向的决定。先试行一个学年，结合数据完整度、评分者一致性及教师反馈修订下一版本。

## 7 考核周期

| 周期 | 本项目建议 | 用途 |
| --- | --- | --- |
| 日常 | 事件发生后持续记录 | 伴随采集、及时归档与审核，不开展每日能力排名 |
| 学期 | 每学期计划和回顾，期末形成发展反馈 | 与玉林学期计划衔接，及时调整下一阶段行动 |
| 学年 | 校本专业发展主周期 | 覆盖一轮完整教学、育人和研修，形成阶段报告与学校已定稿的专业发展评价 |
| 年度人事考核 | 由主管部门及本校制度确定 | 与行政考核对接，不能直接用学年报告替代 |
| 多年项目或专项评选 | 按阶段或项目规定 | 课题、聘期、骨干申报等复用档案证据 |

主周期建议一个学年，学期用于形成性反馈。一个自然年和一个学年长度均约一年，但边界不同，应在方案中明确开始、结束及纳入规则。演示可以用“2026—2027学年”，日期遵循学校校历；不把9月1日至8月31日写成所有学校的强制边界。

国家《事业单位工作人员考核规定》第九条规定年度考核以年度为周期，一般在年末或次年年初开展，因此平台须保留人事年度与校本学年各自的方案及结果，实际如何衔接应核对成都高新区和玉林的制度。[人社部正式规定](https://www.mohrss.gov.cn/SYrlzyhshbzb/rencairenshi/zcwj/202302/t20230201_494142.html)。

四川师德正式考核每年一次，与年度考核同步或先行；不能因为本产品主周期设为学年，就自行改掉正式师德周期。学期汇总、学年发展报告和正式年度等次可以引用同一批有效证据。

周期开始时公布指标、适用人群、权重与规则；期末完成补充、审核、评议、结果确认和异议处理，再冻结该期正式结果。长期成长档案不清空，冻结后更正保留版本与原因。

归期依据必须配置。例如培训按实际完成日期、论文按正式发表日期、奖项按认定日期；这些是建议，不是玉林已经规定的规则。跨学年课题按当期已认定里程碑记录，不能每年重复取得同一立项分。转入教师、休假、岗位变化及团队成果按方案适用规则处理，不与完整履职学年的教师直接机械比较。

## 8 首版手机端演示范围

若选定玉林参考方案，预置其指标目录以支持识别和档案归属，重点演示专业阅读、教学反思免审入库；外部培训、赛课成果、课题立项需审；同一教师兼具提交与审核他人材料的权限；退回补充后重提。可信系统归集只呈现已注明来源的样例，不伪称已经接入学校系统。

每条材料展示匹配的三级指标及上级路径、所需字段、处理状态和通过依据。正式师德评议、全校测评和能力综合评分暂不在首版实现；由学校方案输入正式结果时，展示其来源及适用周期。没有学校认可的评分量规时，只呈现档案和过程事实，不填充随机能力分、优秀等级或排名。

需校方定稿的内容：五维业务指标的最终名称与增删；各指标适用岗位、证据要求及审核职责；成都高新区师德评价的具体要素与权重；校本学年与人事年度的衔接；计分量规、归期、去重和异议处理规则。以上目录、默认审核和试配权重可作为评审起稿，但不能标记为学校正式政策。
