# 教师成长记录竞品体验与方案取舍

体验日期：2026-10-14。来源：[教师成长记录](https://tchh5.jxgroup.cn)，演示学校提供的演示账号。本文只记录界面观察，不保存登录凭据及人员资料。

## 1. 结论

竞品围绕教师成果归集，提供分类填报、证书识别、时光轴、分类档案、职称看板和全校人员报表。值得沿用的是成果分类、级别、阶段、本人贡献和查询能力。

本项目采用“**AI录入 → 匹配学校指标和规则 → 按指标审核开关生效 → 档案与报表同步**”。教师不用先读分类说明、整理证书再逐表填报；管理者既能处理评价，也能从全校汇总查到具体教师与原始材料。指标方案仍待选型，不因竞品体验默认选定精简版。

## 3. 十六类入口及字段观察

除个人信息外，其余十五类都进入了列表和新增／已有材料表单。通用列表包含搜索、记录数、展开材料；已有成果示例显示“待确认”和分数占位。表单普遍提供保存草稿和提交。

| 分类 | 定义或特殊字段 | 本项目取舍 |
| --- | --- | --- |
| 个人信息 | 基本资料、任教学段学科、学历职称、日期等；编辑为多步骤，查看了首步 | 我的页简洁资料；组织及身份由学校提供，首版不复制完整人事档案流程 |
| 任职情况 | 按学年学期，任职学段、岗位、备注 | 岗位是教师档案属性，不是增加一种应用角色，也不因任职自动加分 |
| 资格证书 | 类别、名称、级别、颁证信息、证书 | 作为资格资料；有学校计分规则才计分 |
| 工作经历 | 开始／结束、单位、经历类别、岗位 | 保存履历；本期不单独制作经历维护模块 |
| 赛课获奖 | 正式赛课获奖；比赛类型、级别、等次／名次、颁证信息 | 保留类别；区别作品比赛及公开课 |
| 讲座献课 | 说课、微课、公开课、研讨展示、讲座分享等 | AI区分授课／主讲／参训，不让用户解释分类边界 |
| 专业荣誉 | 教学或科研方向的个人荣誉 | 通用名称统一；没有指标映射时仅归档 |
| 综合表彰 | 偏德育等综合荣誉 | 荣誉证明不是师德基础分的自由加分依据 |
| 技能比赛 | 教育教学技能比赛、等次及颁证信息 | 教案、课件、作业设计等比赛归此类别 |
| 学生获奖 | 获奖类别、等次、学生人数、名单或证书 | 必须识别教师指导贡献，不把学生获奖直接等同教师本人获奖 |
| 集体荣誉 | 名称、参与人数、归类、颁证信息 | 核对个人贡献，不能只凭参与人数给每人同分 |
| 集体获奖 | 类别、等次、参与人数、归类 | 集体奖与个人奖分开保存 |
| 论文专著 | 论文获奖／发表、参编出版、专著、案例评选；作者人数、出版物／出版社等 | 类别决定字段；区分发表与获奖、作者次序及本人贡献 |
| 课题研究 | 正式课题／小专题／微课题；立项、中期、结题、成果奖；名称、单位、参研人数 | 关联同一课题的不同阶段，学校规定阶段计分及升级补差 |
| 研修培训 | 类别、开始／结束日期、材料；说明包括主题教研、学习、培训等 | 映射研修学习；不强制所有日常学习具备级别、证书或最低学时 |
| 工作引领 | 工作室领衔、组长、带教、评委、兼职等 | 任职证明与完成引领任务区分，是否奖励由学校规则决定 |

多数成果表单含级别、类别、自动简称、单位、颁证日期、图片、备注，部分要求归类或人数。竞品允许补充名称；本项目保留稳定编号与别名，AI生成可读事件标题，避免“校级其他其他”一类空泛组合。

成果级别实际下拉有国家级、省级、市级、区县级、集团级、校级。我们保留集团级为可选校本字典项，不将集团与某行政级别强行排序或通用乘分。竞品表单要求只有年月的证书选择当月1日；我们保存日期精度，不虚构发生日。

## 4. 转化为本项目的AI能力

| 任务 | 本项目处理 | 用户只需做什么 |
| --- | --- | --- |
| 录入日常事件 | 文字／语音提取事件事实，匹配指标及学校规则 | 描述事情；信息缺失时补充具体一项 |
| 录入证书 | 图片识别名称、对象、类别、级别、日期、单位及贡献，按当前规则处理 | 拍照或选择材料；可查看原图与识别依据 |
| 多张材料 | 判断是一件事的多页证据还是多件成果，先归并再生成记录 | 对有歧义的材料确认归并或对象；不逐张填长表 |
| 防止重复 | 结合教师、证书编号、活动／课题、阶段、日期及材料进行核对 | 发现重复时补充到旧记录或放弃重复项 |
| 分类纠错 | 区分本人赛课、作品比赛、指导他人、公开课等；级别以认可证据判断 | 查看实际类别；有歧义时选择候选 |
| 自动计分 | AI匹配已发布规则，系统按基础分与上下限计算 | 免审项目提交后生效，不再点确认入档或等人工打分 |
| 审核 | 呈现对象、事实、证据位置、规则与建议分值 | 管理者一次通过或不通过；不通过写明原因，不重新读表填分 |
| 查询成果 | 周期、指标、类别、级别组合查询，关联证据 | 使用时光轴与筛选，不切换多个档案入口 |
| 阅读报表 | 同一统计口径提供分布、趋势及对应明细 | 从学校数据逐层点到教师及材料；可选摘要必须有数据依据 |

免审仍以证据和规则校验通过为前提。没有指标映射的材料只有在学校明确纯归档权限及审核策略后才进入正式档案；未配置时只保存个人待整理材料，不纳入学校报表。批量材料逐件处理：已生效、待审核明确分组；信息不足的项目原位提示，尚未提交，不增设待补充业务状态，一件失败不阻塞其他已满足条件的事件；重试不能重新奖励已生效项。未经核实的负面事实不能由AI定性扣分。

## 5. 页面取舍

保留四入口：记录、档案、报表、我的。档案以时光轴为主，按指标查看为同一档案的另一视图；成果级别和类别在更多筛选中。材料从事件详情预览，首版无需独立照片库、成长树和荣誉墙三个入口。

学校报表补充“成果类别分布、成果级别分布”的次级查询；保留全校教师目录，含未提交教师；记录页顶部“记录／审核（待办数）”区分任务，与报表的学校待审总数分清。职称申报要求、同龄比较、公开荣誉展示、全套人事履历及对话问报表留作后续，避免挤占本期AI录入与校本评价的核心流程。

细化后的页面及演示路径见[教师手机端页面结构方案](../教师手机端页面结构方案.md)，字段与级别规则见[成果级别与成长时光轴设计](../指标方案/成果级别与成长时光轴设计.md)。
