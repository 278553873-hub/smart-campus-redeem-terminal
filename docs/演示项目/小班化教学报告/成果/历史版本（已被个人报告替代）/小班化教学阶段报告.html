01 / 汇报摘要

首年的价值，正在于
支持开始变得更具体

现有材料已能支持有针对性的教育判断；教学效果仍需通过后续行动与连续观察检验。

本阶段可以向学校汇报的核心结论

学校已经积累了连接“日常表现—家庭认识—儿童声音”的材料基础。两位学生的差异提示：同样的课堂要求，需要不同的进入方式、练习机会和反馈。

1

孩子的优势与需要，能被同时看见

周智皓反复出现主动劳动、服务同伴的具体行为，也有课堂规则与同伴冲突方面的支持需要。劳动中的责任感可以成为合作练习的起点，不能用来抵消安全方面的提醒。

2

不同视角之间的差异，能改变教学判断

任芊语在访谈中回答简短，在课堂中却已有响亮回答和示范活动的记录。支持重点应放在“什么条件下更愿意表达、怎样迁移”，不宜概括为一直胆小或已经全面自信。

3

下一阶段，可以把认识转成可检查的行动

为周智皓设计“停手—说需要—轮流或求助”的合作练习；为任芊语设计“先画—对同伴讲—自选分享”的表达阶梯。每人先聚焦一个目标，再看提示能否减少、能力能否换场景使用。

建议学校先确定三件事

确定两位学生的支持负责人；安排四周小范围试行；用相同观察口径复盘，再决定是否扩大。

本报告不作的成效结论

没有改革前基线、对照班、实际班额与教学调整日志，不能证明“小班化导致某项能力提升”，也不能推断全班、全校成效。

04 / 阶段价值

小班化探索的作用，
先体现在教育判断的改变

现有材料呈现了个体发展的线索，也为更细致的教学回应提供了依据。

可呈现的阶段价值材料中的具体表现对教学的实际意义
持续看见一个优势周智皓9月主动清洗工具、认真拖地，10月记录出现带领同伴和清洁检查。可把劳动优势转为分工、轮流与说明步骤的练习机会；角色线索尚不能证明所有场景下的自我管理已改善。
用不同场景校正印象任芊语9月2日已有响亮回答；9月20日访谈仍被记录为害羞简短。不以一次访谈给学生定性；寻找任务熟悉度、准备方式、听众规模等可能影响表达的条件。
让学生愿望进入支持目标任芊语想在“悦群”上进步，提出“帮助他们”；后来有主动添汤的记录。把儿童愿望与具体服务行为联系起来，并继续问“帮助了谁、对方需要什么”，形成孩子能参与的目标。
把家庭反馈变成可讨论的问题周智皓家中能自理，校内部分环节仍需提醒；任芊语在家爱说，正式表达时会犹豫。家校不争论谁的描述更准确，而是共同核对场景、提示和任务要求。

从材料基础到学生获益，还需要完成后半程

建议实施课堂支持、家校配合、连续复盘

“由主动劳动延续到指导同伴”属于表现与角色的线索；“帮助他们”与添汤行为之间属于内容呼应，均没有证据证明由某次访谈或特定教学干预直接促成。

05 / 个案一 · 多维理解

周智皓：把服务集体的主动，
带进同伴合作与日常转换

已看到的优势：主动劳动、服务同伴、愿意表达。优先支持：遇到分歧时安全表达需要。

孩子的声音 · 9月17日访谈

“我今年7岁喜欢做手工。”
想拥有“尚美”，理由是“折手工”。

理解维度三类材料如何相互补充教育含义
兴趣与学习入口档案写到好奇、喜欢自然与机器；孩子喜欢手工，自评科学不错，认为跆拳道是强项。以动手、观察和运动情境设计任务。兴趣与自评不等于已经测定的学业或运动水平。
责任与实际行动多日劳动记录持续出现；9月14日清洗拖布并指导同伴，10月20日出现带领和检查。有承担具体责任的经验。可让孩子示范步骤，也练习等待与听取搭档意见。
自我管理与转换档案反馈可整理物品；9月有课前未整理提醒，10月也有课前准备、资料整理的肯定。“会做”不一定能在所有情境独立做到。先核对指令是否清楚、转换是否太快及提示多少。
交往与分歧处理档案称主动结交朋友，争用物品时不易退让；访谈既提到朋友，也说平时自己玩；10月仍有冲突记录。有交往资源，也需要协商方法。独自玩不等于被孤立，冲突记录也不能推出固定人格。
目标感与儿童参与孩子想在“乐健”上进步，却说不知道怎样做；对小学生活暂未说出期待。成人把抽象目标转成孩子能选的一个动作，再追问喜欢的具体校园活动，不解读为厌学。
待验证的教学假设

当任务具体、有动手机会、有明确角色时，周智皓可能更容易投入。把同伴协商嵌入这些优势场景，可能比反复笼统提醒更容易练成可用的方法。

以上是教学假设，不是心理诊断。先观察“什么条件有帮助”，不把责任感强或规则表现波动当成终身标签。

05 / 个案一 · 四周支持方案

先学会安全地说出需要

建议试行：2026年10月26日—11月20日，按校历调整。以下目标与频次是方案建议，尚非已实现成效。

一个核心目标

在共享材料或合作任务出现分歧时，先停止身体动作，再说需要，并尝试轮流或向成人求助。

阶段老师的具体动作保留什么证据
第1周
建立共同说法		班主任核对近期冲突的情境与经过；与孩子共同画“停—说—轮流/求助”提示卡。每周安排3次自然的两人合作观察；不人为制造争执。记录真实机会、是否需要示范、孩子用了哪一步。无分歧则记“无机会”，不计成功。安全支持从第一天提供。
第2周
在优势任务中练		每周2次、每次约5分钟，借折纸或清洁工具整理练习“你先还是我先”。提供一句话提示，及时肯定安全表达。从“成人代说”到“提示后自己说”是否出现变化；另保留一次孩子自己的复述。
第3周
换搭档与场景		经孩子同意轮换搭档，在美术材料共用或课间游戏中用同一套语言。遇到困难恢复提示，不用扣除劳动岗位作为惩罚。方法是否只在熟悉搭档身边有效；新场景中的提示级别与结果。
第4周
复盘并作决定		班主任与任课教师核对至少两个场景的样本，请孩子选出最有帮助的一步。和家长确定继续练习还是降低任务难度。建议目标：最近5个可比自然机会中至少4次安全表达，其中至少2次无需个别提示；机会不足则延长观察。

家长可配合的一件小事

每周2–3次，在共用画笔或玩具时练习“我想……，你先还是我先？”每次约3分钟。只反馈是否用上方法、需要何种提醒，不反复追问学校冲突。

老师反馈到动作

可说：“刚才你先停下，再告诉同伴想用什么，这让你们能继续一起做。”让成功来自具体方法，不以“乖不乖”作评价。

安全底线：出现推搡、打人等情况先制止并照顾受影响学生，待情绪稳定后分别了解经过、练习修复。安全事件单独记录，不以助人表现抵消。上述支持由班主任协调，任课教师使用一致语言。

方案依据：AZ34；Z78–79、Z130、Z158及劳动优势证据。方法和达成目标为本报告建议，需教师与儿童共同调整。

05 / 个案一 · 教学与家校转化

把手工兴趣变成合作练习

建议活动：“给班级设计一张收纳提示卡”。用真实任务连接手工兴趣和服务集体的经验。

建议每周一次 · 约15分钟 · 两人协作

我会整理，也能把方法讲给别人

孩子先选一个熟悉的整理场景，用折纸或图画表示步骤；与搭档商量材料分配，轮流讲解，最后把提示卡用在自己的整理中。

教学连接提供怎样的支持观察重点
语文：说清过程允许先操作，再用“先……再……最后……”说明；老师复述孩子的意思，请孩子确认。能否让听者听懂一个步骤，不以声音大或发言次数代替表达质量。
数学：整理与分类让孩子自行选“按用途”或“按大小”整理实际物品，数一数所需材料；难度由任课教师匹配当前学习内容。能否说出分类依据；不因家庭问卷中的计算自评直接安排超前任务。
美术 / 劳动：图示与协作提供图标或折叠范例；每人都拥有设计和使用材料的机会。角色轮换，避免始终负责收拾。有分歧时是否用核心目标中的步骤；能否听取搭档一个建议。

皓皓，试试把需要说出来

一起做手工时，我想用的东西在同伴手里：
① 我的手先停下来。
② 我说：“我也想用，可以商量吗？”
③ 我们轮流；商量不了就请老师帮忙。

做完后，我想告诉老师：今天哪一步帮到了我？

“我们看到了皓皓主动服务班级的能力。现在想借孩子喜欢的手工，练习遇到分歧先说需要。家里若出现类似机会，请告诉我们用了什么提醒、哪一步有帮助。”

“一起做什么最有意思？”“想用同一样东西时，可以怎么说？”“老师怎样提醒，你更容易做到？”用孩子的回答调整方案。

06 / 个案二 · 四周支持方案

从“愿意说”，
走向“能说清自己的发现”

建议试行：2026年10月26日—11月20日，按校历调整。分享大小由孩子参与选择，不以强迫公开发言推进。

一个核心目标

借助自己的画或观察物，在合适的听众面前说清一个发现，并逐渐减少个别提示。

阶段老师的具体动作保留什么证据
第1周
找到愿意说的入口		请孩子在画画、植物观察、熟悉故事中选一个。安排3次简短表达机会，允许指图、先对老师说或选择暂不说。记录选了什么内容、对谁表达、用了什么提示；问一句“怎样准备更有帮助”。
第2周
先对同伴说		每周2次、每次约5分钟，先画再讲。采用“我发现……，我看到……”句式，对熟悉搭档说明一个细节，搭档复述。是否说清对象与一个细节；是否由成人代说；孩子是否愿意再次尝试。
第3周
自选扩大听众		允许从一位同伴增加到小组，或自愿向全班分享。每次只增加一种难度；保留图画准备和等待时间。听众或内容改变后，原有表达是否仍能出现；拒绝一次不等于退步，先了解原因。
第4周
迁移与复盘		在另一门课中提供同样的准备支持，让孩子选择一件想解释的作品。家校共同比较具体表达样本。建议目标：最近5个可比机会中至少4次说清一个发现，其中至少2次无需个别提示，且覆盖两个场景；不足则继续支持。

家长可以这样配合

每周2–3次，请孩子选一幅画，先问“你想讲哪一部分？”等待孩子组织，再复述听到的内容。每次约3分钟；不急于纠错，不替孩子讲完。

反馈内容，而非只夸勇敢

可说：“你指出叶子的边缘，还说清了哪里不一样，我听懂了你的发现。”让孩子知道表达有效的具体原因。

班主任协调，语文、美术或科学任课教师各提供一个可比场景。不要只统计举手次数；提示水平、表达内容和儿童感受比声音大小更能说明方案是否适合。

方案依据：AR47、QR6–9、QR20、QR26；R2、R80、R118。方法和达成目标为建议，尚未在本资料中得到验证。

06 / 个案二 · 教学与家校转化

让一幅画，成为
一个发现的起点

建议活动：“我的植物发现卡”。把绘画兴趣、已有的植物观察经验与表达目标连接起来。

建议每周一次 · 约15分钟 · 可独立准备、同伴分享

画出一个细节，再讲给一个人听

选择校园中一株熟悉的植物，画出一个真实看到的细节；用箭头圈出想说的部分。先向熟悉同伴讲，再由孩子决定是否向小组分享。

教学连接提供怎样的支持观察重点
科学：观察与依据问“你实际看到了什么？”允许描画、比较；把“我猜”与“我看到”分开。能否指出一个可观察细节，是否需要老师先给答案。
美术：视觉表达让孩子选择颜色和表现方式，不以画得像不像决定能否分享。把图画当作表达工具。能否用图帮助听者理解；不凭“爱画画”的自评认定绘画水平。
语文：口述与倾听提供“我发现……”“我这样想是因为……”；搭档复述后，孩子补充或修正。能否说清一个发现；能否回应一个问题，而不只是重复老师的话。
同伴交往：帮助与征询孩子愿意帮助同伴时，先问“你需要我帮哪一步？”保留双方操作和表达的机会。帮助是否符合对方需要，能否让同伴完成自己的部分。

芊语，把你的发现讲给我们听

今天我想画：____________
我看到的一个小细节：____________
我想先讲给：老师 / 一位同伴 / 小组
我可以先画，再讲；想一想也没关系。

07 / 课堂实施

同一节课，不同的支持入口

以两人共同制作“班级整理提示卡”为例：共同学习目标保持一致，准备方式与反馈重点因人而异。

共同目标

观察一个真实问题，用图和一句话提出办法；与同伴协商完成作品。分组依据本次任务调整，不把孩子固定为某一类。

教学环节全体学生共同经历周智皓的支持重点任芊语的支持重点
观察
约3分钟		选一个需要整理的角落，说说想解决什么。允许先动手摆放，再说明理由；先确认任务步骤。允许先画或指认，再用一句话解释。
合作制作
约6分钟		两人商量分工，共用材料，做一张提示卡。用“停—说—轮流/求助”提示卡；老师留意一次真实协商机会。先在搭档面前讲图，老师留足等待时间，避免替说。
分享
约4分钟		每组选择作品中的一个办法解释给别人。关注是否先听完搭档、再说明自己的步骤。孩子选择由谁先讲；反馈对象和细节是否清楚。
自评
约2分钟		各说出一件做成的事和一个下次想试的办法。“我用了哪一步，帮助我们继续合作？”“什么准备让我更容易讲清楚？”

把更多关注用在关键时刻

课前 · 选目标

老师只带一个核心观察问题进入课堂，提前准备一句提示。

课中 · 留证据

记下一次真实机会与反馈；未观察到就标“未观察”，不补写推测。

课后 · 调方法

判断是任务太难、提示不足、场景不合适，还是需要继续练习。

不把个性化做成额外的一套课

把支持嵌入现有课堂、劳动与班级活动，轮换观察学生和场景。两位学生不是固定搭档，也不因某项表现被长期分到固定能力组。活动时长只是示例，由教师按课表安排。

日常融入

每名学生每周3次短观察，嵌入已有活动；每条仅记场景、机会、提示、表现。每次记录建议控制在1分钟内，先试测是否可行。

09 / 效果验证

用下一轮证据检验支持是否有效

将“记录了多少”与“学生是否受益”分开。先积累可比样本，再讨论变化。

验证对象怎样记怎样解释
周智皓：安全协商在真实分歧中，记录是否停手、说需要并轮流或求助；分别标记独立完成、提示后完成、未完成。看同类机会下独立完成是否更多、提示是否更少；安全事件单列，同一冲突不按多个指标重复计数。
任芊语：表达发现给定合适准备后，记录是否说清对象和一个具体细节；同时记录听众、准备方式与提示。看内容是否更完整、是否更自主、能否换一个场景使用；不把声音变大直接解释成自信提升。
教师：支持是否落地记录预定支持实际提供了几次，教师新增记录和复盘耗时。若支持未实施，不能把无变化归因于孩子；如负担高，先精简流程。

“最近5次达到4次”等仅是可协商的试行目标。即使达到，也需结合起点、支持落实与迁移判断；没有对照仍不作因果结论。

两位个案只能说明支持是否适合这两个孩子。全班层面应同时报告覆盖范围、未完成情况与不同起点的学生表现，不能从两个个案推出全班提升比例。
