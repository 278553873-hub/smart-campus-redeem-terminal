# 学校基本信息设置

更新日期：2026-11-14。

- 入口：学校PC端 → 学校管理后台 → 基础信息配置 → 学校基本信息。
- 学校对外展示名称：默认学校原名称，必填、最多40字；仅修改对外展示文案，不修改学校标识、归属或报告的数据范围。
- 学校Logo：选填，支持上传、预览、更换和移除。沿用PC图片上传规范，PNG/JPG/WebP、最大2MB；等比缩小到长边不超过512像素，保留透明背景及图片比例。
- 学校特色信息：一个多行文本框，选填、最多2000字，录入校训、校风、育人理念等信息，保留换行。
- 点击“保存”统一生效；“取消”恢复已保存内容。上传失败保留原Logo，存储失败保留草稿。切换后台菜单时提醒未保存修改，处理图片时防止中断；刷新或关闭浏览器提供离开提醒。
- 当前独立数据大屏 `?app=data-screen` 顶部主标题显示“学校对外展示名称＋学生成长全景驾驶舱”；左上角显示Logo，不重复显示校名，无Logo或加载失败时留空，不显示默认图标。长校名仅在主标题的校名部分省略，驾驶舱名称完整保留，并可查看完整主标题。
- 特色信息本轮仅保存，不自动作为AI报告输入或增加大屏展示区。学校PC留底大屏和学生成长大屏未改动；现有报告封面配置仍独立维护。

## 数据边界

- `shared/schoolBasicInfo.ts`维护字段、校验和规范化；`shared/schoolBasicInfoStore.ts`维护读写；界面通过`useSchoolBasicInfo`订阅变化。
- 演示按学校标识隔离保存在浏览器，同源标签页同步。尚未接入服务端，不支持不同设备、浏览器间同步。
- 正式接入时由当前登录学校提供学校标识，在存储层替换为服务端配置与图片资源地址；不能通过展示名称匹配学校。
- 当前不迁移或覆盖报告封面的历史校徽，不依赖个性化封面开关。
