## 留底内容

- 原标题「AI素养评价系统」、学校名称、双行数据日期、全屏能力。
- 暖橙金光纤与粒子背景、黑玻璃卡片、橙金概况数字、金属标题光轨及六色立体环图。
- 27／46／27三列，上下边界对齐。左上为四项概况和教师使用TOP10，左下为最新五条评价；中央上方为五育主图，下方为成长趋势和指标使用情况，按2:1并排；右上为年级记录数及学生覆盖率，右下为五条学生积分变化。
- 底部320像素、成长趋势绘图区至少190像素，图形按容器实际宽高排布。画布以1920×1080为最小空间，铺满窗口且保持图形比例。
- 六个一级指标来自学校目录：崇德、求知、向阳、尚美、躬行、乐创。名称、事件条数、正分总数与加分学生人数保持原口径。环图每3.6秒轮播、500毫秒连续缓动，外移13、外半径221至245，环外明细保持原样。
- 年级每页六个，记录数和覆盖率联动翻页；成长趋势为最近七周的被记录人数、获表扬人数。概况固定本学期，动态独立读取本周快照。
- 四项概况、教师前三及80%以上覆盖复用橙金色标；低覆盖米白；正负分为青绿与珊瑚红。
- 页面隐藏或减少动态效果时按原规则停止背景和轮播，保留键盘操作及辅助阅读。

## 数据与分层

- 评价次数：一次评价记一次，评价N人仍为一次；成长记录条数按学生生成N条。
- 各一级、各周期的加分学生人数按学生标识去重；扣分不撤销已经发生的获表扬事实。周趋势按北京时间周一分周，同一学生同周只计一人。
- 学生姓名只隐藏第二字，可见文案与辅助阅读一致。教师演示姓名完整保留。
- 共享报表仍为演示服务，历史周学生集合及学校指标分项在本目录独立模拟；不代表已连接真实历史明细。
- 完整复制旧Demo的18个源码、样式、许可和检查文件，样式、动画及图形标识转为 `school-pc-` 前缀。后续Demo改版不影响本目录。
- 模型、服务、Hook、图表、主图、背景及画布适配按原职责维护。未新增依赖或环境配置。
- 替换前两套源码备份：`.codex-output/screen-plan-2026-11-11/before-replacement.tar.gz`。该本地备份用于恢复原工作区，当前学校留底源码正常受版本管理。
