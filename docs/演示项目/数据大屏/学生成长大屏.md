# 学生荣誉榜

## 当前方案：课堂年级荣誉榜（2026-11-18）

学校PC顶部“学生荣誉榜”在新窗口打开`?app=student-honor-screen`，面向班主任在课堂一体机上给学生展示榜样。采用奶油浅色背景、金黄／丁香紫／薄荷绿的趣味领奖台及深色清晰文字，独立于学校驾驶舱主题。旧`?app=student-growth-screen`仍兼容进入德育管理全景。

- 全部年级同页同时展示，取消年级筛选及切换操作。6个年级采用三列两行、9个三列三行、12个四列三行，读取实际学校配置，不自动轮播、不滚动隐藏年级。
- 每个年级按本学期有效加减分净总分取前十。每张年级卡片左侧用头像、皇冠与阶梯领奖台突出前三名，右侧完整列出第4至10名的名次、姓名和总分；所属班级仅在姓名提示中辅助识别，没有班级统计或班级榜。
- 同分同名次，保留真实分值，不按百分制换算。领奖台数字用页面文字叠加，不能因站位改写名次；并列第一同样展示皇冠。少于十人按实际数量呈现，空榜不补造学生。
- 取消一级指标分类、单项之星、班级统计、成长动态和个人登录，仅保留全屏核心操作。名次统一`01`、`02`格式；各年级均有独立前三名样式，不缩减为仅展示前三人。
- 头像复用教师手机端`studentAvatarCatalog`及稳定分配规则，优先使用学生实际头像。皇冠、领奖台与背景使用内置`image_gen`生成，素材和完整提示词位于`public/assets/student-honor/`，见[素材说明](../../../public/assets/student-honor/README.md)。

新展示组件和样式位于`components/student-honor-screen/`；只读复用原学生看板的纯数据模型、排名和演示服务，不加载原八板块业务展示。数据仍为稳定生成的演示明细。

快速验证：`node components/student-honor-screen/studentHonorScreen.test.mjs`覆盖实际学校名册的分年级总分、并列、头像规则、前三名与其余七人、少于三人、空榜和6/9/12个年级的全部TOP10同页静态渲染；`npm run build`验证生产构建。不启动浏览器自动化。

## 历史留档：以下八板块方案不再由App加载

### 学生触屏八板块（2026-11-16）

独立地址：`?app=student-honor-screen`，学校PC顶部“学生荣誉榜”新窗口打开。页头使用校名＋学生荣誉榜，不进入驾驶舱页签。旧`?app=student-growth-screen`继续兼容德育管理全景。面向学生看榜样、看班级、看年级，按本学期统计，不显示日期、周期说明和轮播开关。

1920×1080同页呈现八个板块，顶部统一年级下拉，默认全部年级。选择年级后，全部八个板块（含成长动态）同步限定为该年级；卡片内只保留各自的指标切换：

| 板块 | 内容与交互 |
| --- | --- |
| 学生得分榜 | TOP10，名次、姓名全名、班级、积分；跟随全局年级，综合及一级指标横向切换，积分随所选指标更新 |
| 成长之星 | 对应学生得分榜筛选范围的前三人，品字型排列，仅展示名次、全名、班级；不另设筛选，不补写行为描述 |
| 单项之星 | 每个已配置一级指标的领先学生，按指标分格，突出姓名与班级；同页最多适配10项，跟随全局年级 |
| 班级积分榜 | 默认全校TOP10，人均净积分；跟随全局年级，卡片内切换指标 |
| 班级表扬榜 | 默认全校TOP10，“获表扬人数／全班人数”，按比例排名；跟随全局年级，卡片内切换指标 |
| 年级风采 | 全部年级按学校顺序显示获表扬人数／年级总人数与比例条；选定年级只显示该年级，支持指标切换 |
| 班级人均积分榜 | 名次、完整班级名称、积分；全部年级时所有班级按人均积分统一取TOP10，选定年级时仅该年级取TOP10；前10名直接完整展示，不提供列表滚动、滑动或翻页；支持独立指标切换，标题旁不增加“人均积分”提示 |
| 成长动态 | 所选年级（默认全校）的最新六条公开表扬记录；第一行时间、教师、学生与班级，第二行完整三级指标及加分；不设独立筛选，不受卡片指标选择影响 |

卡片位置保留两个布局区域：左侧三列上排是学生得分榜、班级积分榜、班级表扬榜，下排是单项之星、年级风采、班级人均积分榜；右侧一列上下排列成长之星、成长动态。左右宽度3:1，组间留白区分，不增加分组说明文字。第三列两张班级榜单均衡分配高度，直接完整展示十行，不设置列表滚动或翻页；前两列保持上方榜单、下方概况的布局。四张TOP10榜单沿用统一列对齐规则。5/6/10个指标以卡片内标签和单项之星聚合，6/9/12个年级以顶部统一选项和年级图聚合，不依赖逐年级轮播。较低分辨率优先保证触控区域，主区域允许纵向滚动；竖屏保留分组顺序单列展开。

样式保留学校全景的暖金背景与玻璃面板，统一字号、留白、表头和行距。年级下拉提升至页面顶部，保留原深色外观；卡片指标沿用原横向下划线标签，不增加额外筛选框及“年级／指标”标签。成长之星标明“随得分榜”。成长动态参考学校全景的信息结构和密度，六条紧凑记录按时间倒序排列，长指标自然换行，超出高度可滚动，不能用三行平分整张卡片造成大块留白。下拉框及其弹层保留局部深色样式，覆盖全局styles/pc-admin.css对白底和边框的!important规则，包含正常、悬停、聚焦状态，不修改后台控件。成长之星采用第一位居上、第二三位分列下方的品字型，保留真实并列名次；单项之星用指标色标签和细线分格。取消班级好表现及其控件，不增加占位卡片。

## 统计与公开口径

- 所有板块从同批学生日常评价明细计算，班级内容只是学生记录的聚合，不新增班级评价。
- 总积分及单项积分为有效加减分净值，先在完整所选名册排名再截取前十。非正积分学生不进入个人公开榜，同分同名次。年级并入班级，如“七年级2班”。
- 班级人均积分分母是全班在籍学生，包含没有记录与净积分为负的学生。保留一位小数，相同显示值按并列处理。积分榜与表扬榜默认全部年级，可筛选年级后重新排名；少于10个符合条件班级时显示实际数量，不补造班级。班级人均积分榜复用同一套排序与并列规则，全部年级统一取前10名，选定年级仅取该年级前10名，不按年级分组；直接显示“三年级4班”这样的完整名称。
- 获表扬人数按是否有过正向记录去重；同一学生多次表扬仅计一人，净积分为负但曾获表扬仍计入。没有公开摘要的正向记录仍计入表扬人数。
- 按最新要求，公开得分榜提供所选指标的个人净积分列；完整评价记录和个人详细资料仍需登录后仅查看本人。成长之星不补写行为说明，成长动态只用可公开的正向行为摘要，不读取完整私密评语。
- 学期边界由数据服务传入，排除学期外、未来记录、未知学生、未配置指标与无效数值。默认指标路径与教师目录共用，学校配置决定数量和顺序。

## 我的成长与登录

顶部设置“我的成长”入口。登录后只展示认证服务返回的本人积分、分项积分和评价记录。退出直接清理私人资料并返回大屏，不保留账号、密码或私人记录到浏览器存储。

当前项目旧终端登录只有演示动效，不验证身份，因此不能直接用于私人数据权限。本版已实现独立登录界面和认证适配接口`GrowthStudentAuthenticator`，未配置真实身份服务时提交提示暂不可登录，不接受任意密码解锁、不从公开名册选人冒充登录成功。学校真实认证及私人数据接口仍需接入。

## 轮播与闲置

两张全景保留60秒无人操作轮播。学生触摸、点击、键盘或滚动暂停切页，重复操作续时；90秒无操作重置全局年级及全部卡片指标、关闭顶部下拉与私人界面，再完整展示60秒后恢复轮播。隐藏时保留剩余计时，重新进入重置默认，减少动态效果时不自动切页。
