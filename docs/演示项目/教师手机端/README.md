## 人脸数据清除

「班级 → 更多 → 更新人脸」保留待录入／已录入两个标签及人数，复用货柜兑换明细的公共文字页签：白底两项等分，未选中与选中文字均为600字重，选中项使用品牌红文字与底部短线。已录入学生保留更新入口，旁边直接显示灰色垃圾桶与「清空」文字，点击进入清空确认。清空前复用公共确认弹窗，显示学生姓名、人脸识别将不可用且无法恢复的后果，以及再次采集前需征得家长同意的提醒；取消和关闭均不修改数据。

确认后显示「已清空人脸数据」，学生移入待录入，两侧人数同步更新，页面保持当前标签。共享人脸库同步移除该采集照，各页面还原学生独立头像或缺省形象；不删除学生资料和成长记录。返回页面不会重新预置已清除的人脸，仍允许之后重新录入。本轮不增加批量清除、第三个标签或拒绝采集状态。

当前为会话内演示数据，刷新网页会重置；尚未接入服务端人脸库或设备端清除接口。
