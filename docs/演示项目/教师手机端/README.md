## 学生初成像示例报告（2026-11-18）

- 入口：学生详情 → 成长报告 → 学生初成像（2026年10月30日），仅在2026年秋季学期展示。入口只显示报告名称和日期。演示中，所有学生的入口打开吴浩的示例。
- 独立页面 `StudentInitialImagingReportView.tsx` 嵌入工具四手机 H5，顶部复用返回、标题和手机壳的标准微信胶囊。返回后保留成长报告页签。
- 封面和七个报告板块各用一张卡片。每张卡有一个编辑入口，在同一弹窗修改本卡所有生成值。基础信息可按观察主题切换。封面仅姓名、日期可改，寄语仅修改填入内容。固定字段名称保持只读。报告底纹、标题样式及卡片纹理由独立的学校模板样式配置管理。
- 编辑保存在当前浏览器，按学校、学生、报告隔离；不上传服务器。发布构建自动打包同一份完整 H5，无需另行部署文档目录。
- H5 直接导入教师端 `teacherBrandCssVariables`，编辑按钮、输入框、保存与取消操作沿用设计令牌；编辑与日期选择分别复用 `MobileBottomSheet`、`MobileDatePickerSheet`。页面、弹窗与输入区统一隐藏滚动条，保留滑动与键盘滚动。样式更新不重置已有本地修改；保存失败保留编辑框中的内容并提示重试。

## 人脸数据清除

「班级 → 更多 → 更新人脸」保留待录入／已录入两个标签及人数，复用货柜管理的公共文字页签：白底两项等分，未选中与选中文字均为600字重，选中项使用品牌红文字与底部短线。已录入学生保留更新入口，旁边直接显示灰色垃圾桶与「清空」文字，点击进入清空确认。清空前复用公共确认弹窗，显示学生姓名、人脸识别将不可用且无法恢复的后果，以及再次采集前需征得家长同意的提醒；取消和关闭均不修改数据。

确认后显示「已清空人脸数据」，学生移入待录入，两侧人数同步更新，页面保持当前标签。共享人脸库同步移除该采集照，各页面还原学生独立头像或缺省形象；不删除学生资料和成长记录。返回页面不会重新预置已清除的人脸，仍允许之后重新录入。本轮不增加批量清除、第三个标签或拒绝采集状态。

当前为会话内演示数据，刷新网页会重置；尚未接入服务端人脸库或设备端清除接口。

## 统一扫码登录与学校关联

教师手机端完整版开启 `previewSchoolAccess` 时，点击「一键登录」即展开磨砂浮层。手机号验证码注册／登录及密码登录在表单校验通过后展开同一浮层。选择「已加入学校版」直接进入学校版，选择「未加入学校版」进入学校关联引导。「最近登录」直接进入该演示账号关联的学校版。关闭 `mobile-app/App.tsx` 中的该属性后，登录按演示账号的学校关联自动分流。

学校关联提醒复用班级报告图表解析的公共引用提示块：浅灰底、顶部指向和引用图标，突出“学校已统一使用？”，下方展示“请联系学校负责人添加账号，避免重新建班、导入学生。”，首屏提醒不再展示手机号；标题仅保留“暂未关联学校”，移除“切换账号”入口；版本介绍入口使用完整问句“个人版与学校版有什么不同？”。学校版使用 imagegen 生成的浅米金底图，边缘浅浮雕层叠，正文区域保持接近米白；边框、标题和“功能更全”实色标签统一金色。四项能力使用内置 imagegen 按用户「精准同步」参考图生成的橙黄渐变圆底、奶白浅浮雕图标，分别以智能对话、调节滑块、分析报告、问卷档案表达功能，每项配一句说明。图标显示为40像素，功能项间距24像素、图文间距16像素、卡片内距20像素；图标资源按192像素导出，底图使用压缩 JPEG，以兼顾清晰度与加载体积。两版卡片之外的最底部独立居中展示基于用户原图优化的1254×1254像素高清联系二维码，按192×192像素正方形呈现，配文「扫码咨询学校版」；收紧多余背景、保留均匀扫码留白，已校验处理前后识别内容一致。二维码不随版本切换移动，两张卡片结构及高度保持一致。

教师手机端完整版（`?app=admin`）统一从同一个产品入口登录。一键登录、验证码登录/注册和密码登录共用学校识别：已关联学校直接进入学校版；未关联且尚未主动选择个人版时，先展示学校关联指引、学校版亮点及按钮「个人版（免费试用）」。主按钮下方以浅红底、品牌色文字的次级按钮显示「学校版（登录）」，14像素字号、500字重、44像素触控高度，与主按钮间距8像素；主按钮保留实色品牌红、15像素字号、600字重及48像素高度，确保个人版试用优先；点击「个人版（免费试用）」后先进入完善信息页，填写姓名和学校名称后进入个人空间；学校名称由老师手动填写，点击「进入体验」只校验姓名和学校名称是否已填写；点击「学校版（登录）」后通过公共 MobileBottomSheet 显示「请先添加学校账号」，正文为「请联系学校负责人，将此账号（152****1332）添加至学校。添加完成后，重新登录即可使用学校版。」，脱敏号码随当前账号变化。关闭弹窗保留引导页；「退出登录」清理本次表单并返回登录首屏，不记录个人版选择。学校版四项功能依次为自定义评价指标、更全面的成长报告、更多育人工具、AI助理。更换手机号会重新识别账号，不沿用上一账号的学校关系。

首屏按账号状态、关联指引、个人版主操作排序；两个版本按钮恢复为内容宽度内两侧各留16像素的较宽尺寸并居中；保留48/44像素触控高度和实色主按钮、浅色次按钮层级，脱敏手机号只在「学校版（登录）」弹窗的添加账号提示中展示；学校登录指引通过「学校版（登录）」按需展开。版本介绍默认折叠在主操作下方，展开后直接使用横向滑动卡片展示学校版和个人版，不展示版本页签。默认学校版在前并强调功能更全；每张卡片宽度为滑动区域减40像素，卡片间距12像素，右侧露出约28像素的个人版卡片作为滑动提示。卡片不跟随手指逐像素移动，水平拖动达到可见区域宽度的10%（最多32像素）后，直接以260毫秒贝塞尔曲线（0.25、0.1、0.25、1）柔和起步并停靠至另一张卡片；支持手指、鼠标拖动及电脑触摸板横向滚动；触摸板小增量累计至相同阈值后切换，同向滚动及惯性尾段只切换一张；反向累计达到阈值即可立即切回，不等待滚动信号停歇；低于阈值的反向抖动不触发切换，横向输入在卡片区内承接，纵向手势仍滚动页面，双指缩放保持浏览器默认行为；键盘聚焦卡片组后可用左右方向键或Home/End切换，焦点仅通过版本标题的中性下划线提示，滑动容器不显示红色外环；减少动态效果设置下取消切换过渡。两张卡片始终保留在内容及读屏顺序中，默认不会产生整页横向溢出。学校版简介为「全校统一管理，班级、年级多维对比，让育人成效看得见。」。个人版与学校版按评价指标、成长报告、育人工具、AI助理四项顺序对应，每项均使用标题及小字说明。个人版为通用评价指标、期末综合报告、基础班级管理、AI班主任助理；AI语音与拍照记录归入基础班级管理说明，助理说明为「有限额度的AI对话，辅助班级管理与育人。」。个人版简介为「老师自主带班，记录日常表现，陪伴学生点滴成长。」；使用 imagegen 生成的银灰底图和同款灰度功能图标，学校版保留暖金底图与原彩图标。学校版外边框在原金色边框上混入24%的金色强调色，个人版边框降为原中性边框45%的透明度。两版统一20像素内距、40像素图标、16像素图文间距、24像素功能间距，简介及小字说明保留两行高度，保持切换时行位稳定；学校版强调 AI 助理不限额度，支持班主任助理、校长助理，并提供自定义指标、月度与学科报告、校级分析报告，以及问卷采集、档案设计等工具。个人版文案按有限额度展示，学校版强调不限额度；本次只调整介绍文案，具体额度及实际限制以后续业务接入为准。仅具体功能名称需要解释时保留副文案，不重复描述基础功能。字号、间距、圆角和操作色复用教师手机端令牌，宣传图标按用户要求采用独立配色与材质。学校统一使用的老师由管理员关联当前手机号，无需重复建班或导入；个人使用或体验直接进入现有个人版。个人版选择按账号保存在当前浏览器，再次登录不重复提示；登录时仍优先识别后来补录的学校关系。

关闭上述预览设置后，演示学校关联由 `mobile-app/data/teacherLoginAccounts.ts` 提供：一键登录的 `152****1332` 展示未关联指引，`199****8610` 与“最近登录”直达学校；手机号登录可输入 `15200001332` 体验指引、`19900008610` 体验学校直达，其余手机号默认未关联。正式接入须以登录接口返回的学校和协作权限替换演示关联，不根据手机号在前端授予真实权限。教师 Pad 与极速版保持原有登录流程。
