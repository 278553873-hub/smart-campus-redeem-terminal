# 教师手机端我的页面样式复刻开发交付说明

更新日期：2026-10-22。交付对象：线上版本前端开发与验收人员。

本说明对应教师手机端「我的」首页，包含个人信息区、待填写采集卡、管理工具卡、更多工具卡、全局底部导航及班级来源选择弹窗。以当前工作区实现为准，工具入口文字已统一为 **12px / 450 字重**。尺寸单位均为 CSS 逻辑像素，不是截图物理像素。

## 1 页面范围与尺寸基准

- 演示手机内部画布为 393 × 852px；外部浏览器会等比缩放手机画布，截图标注的 561 × 835 浏览器视口不是业务页面设计宽度。
- 线上以实际手机内容宽度 W 排版，不固定为 393px，不复制手机壳、灵动岛、模拟时间、电量、摄像按钮、环境切换面板及外部背景。
- 页面没有独立「我的」导航标题栏。背景铺满屏幕，个人信息区与卡片随内容整体纵向滚动，底部导航固定。
- 演示有壳模式顶部模拟状态区为 54px；线上读取实际系统状态栏和小程序环境信息，不固定套用 54px。
- 当前首页工具网格始终四列，没有按浏览器 561px 视口切换列数的断点。权限不足时过滤入口，剩余入口按原顺序左对齐，不均分放大。

## 2 整页布局与卡片尺寸

以下位置从业务滚动内容起点计算，不包含顶部系统状态栏。

| 区域 | 尺寸和布局 | 393px 宽基准 |
| --- | --- | --- |
| 个人信息外层 | 左右 20px，上方 20px | 可用宽 353px |
| 个人信息行 | 最小高度 132px，内容垂直居中 | 无内容增高时，下一块从 y=152px 开始 |
| 卡片列表 | 左右 20px，各卡间隔 12px，无额外顶部间距 | 卡片宽 353px |
| 工具卡 | 白底，无描边，圆角 12px，四边内边距 16px | 内部宽 321px |
| 标题行 | 红条 6 × 28px，红条与标题相距 12px | 行高由 28px 红条撑起 |
| 标题至入口网格 | 16px | 两张卡一致 |
| 四列网格 | 每列等宽，列间距 12px | 单列 71.25px |
| 管理工具入口 | 最小高 82px，上下内边距各 4px，行间距 16px | 5 项分两行 |
| 更多工具入口 | 最小高 72px，上下内边距各 4px，行间距 12px | 10 项分三行 |
| 网格底部额外间距 | 4px，加上卡片底内边距 16px | 合计 20px 布局留白 |
| 待填写采集卡 | 最小高 48px，左右内边距 16px，圆角 12px | 仅待办数大于 0 显示 |

卡片宽度 = W − 40；网格列宽 = (W − 108) ÷ 4。例：W=375 时卡片 335px、列宽 66.75px；W=393 时卡片 353px、列宽 71.25px；W=430 时卡片 390px、列宽 80.5px。

卡片高度按实际行数计算，不写死：

- 管理工具卡：80 + 82R + 16(R−1)；5 个入口、R=2 时为 **260px**。
- 更多工具卡：80 + 72R + 12(R−1)；10 个入口、R=3 时为 **320px**。
- R 为向上取整后的入口数 ÷ 4。80px 包含上下内边距 32、标题行 28、标题至网格 16、网格底部 4。
- 无待办且完整工具权限时：管理卡 y=152、高260；更多卡 y=424、高320，底部至 y=744。存在待办时两张工具卡整体下移至少 60px（48px 待办卡 + 12px 卡间距）。坐标是正常内容、未滚动时的推导值。
- 上述入口高度为最小值；系统放大文字或内容变化时允许增高，避免裁字。标签当前为单行、不换行，最大宽 72px。

首页使用系统无衬线字体，即 Tailwind 默认 font-sans 字体栈，不引入额外品牌字体。实现时优先延用目标平台系统字体。

**450 的实现要求：**工具文字读取 `--tm-font-weight-minimum: 450`；常规正文令牌仍是 `--tm-font-weight-regular: 500`，不能把全部正文改成450。450不是“常规”或“中等”预设名称，需写数值。只有字体支持相应字重或可变字重时才能准确呈现450；静态字体可能映射到相邻档位，验收应覆盖实际线上手机字体，不用透明度模拟变细。

## 8 全屏背景

背景固定于屏幕层，不跟每张卡重复绘制。按以下顺序叠加，第一层在最上方：

```css
background-color: #FFF1F1;
background-image:
  linear-gradient(180deg, transparent 52%, rgba(67,176,246,.05) 100%),
  radial-gradient(ellipse 84% 50% at -8% 24%, rgba(224,39,39,.16) 0%, transparent 72%),
  radial-gradient(ellipse 82% 52% at 108% 34%, rgba(67,176,246,.14) 0%, transparent 74%),
  radial-gradient(ellipse 44% 24% at 20% -2%, rgba(39,135,121,.04) 0%, transparent 70%),
  linear-gradient(180deg, #FFF1F1 0%, #FBFAF9 52%, #FFFFFF 82%);
```

页面和滚动内容容器背景透明，卡片保持纯白。不要将背景截成图片，以免不同长宽比下拉伸。

## 9 底部导航与安全区

- 记录、班级、我的三项等宽；当前“我的”选中。
- 导航主体高64px，横向铺满、底部定位，层级50，纯白、不透明，无描边、无背景模糊，只用导航阴影分层。
- 图标占位22 × 22px，图片object-fit: contain；选中100%，未选中90%。文字与图标间距4px，文字12px/500/16px；整体垂直居中。
- 图片资源位于 `mobile-app/assets/resources/teacher-bottom-navigation/`，使用 record-active/default、class-active/default、me-active/default 的PNG原图。
- 我的待办徽章在图标右上：right=−12px/top=−8px，高16px、最小宽16px、左右4px，9px/700/行高1；红底白字；超过9显示9+。此处与待办卡的完整数字展示规则不同。
- 当前滚动容器底部留白公式为 `66px + max(16px, env(safe-area-inset-bottom)) + 24px`，无系统底部安全区时合计106px；该公式来自现有全局滚动样式，与导航主体64px是两个不同参数。页面自身不再追加第二份底部留白。
- 演示壳定义的28px模拟底部安全区不直接代入上述滚动公式；线上按真实系统安全区处理，确保最后一行可完整滚动到导航上方。
- 设计规范要求图标按下缩至86%、减少动态效果时取消过渡；当前公共导航组件只显式实现选中100%和未选中90%，未显式设置按下86%。如线上实现按下态，应按全局规范补齐，不改变主体按钮尺寸。

| 弹窗内容 | 规格 |
| --- | --- |
| 选项列表 | 上下12px，项间12px |
| 选项 | 宽度占满，最小高72px，圆角12px，左右16px、上下12px；标签换行时自然增高 |
| 选中与普通选项 | 统一白底、无状态描边、无阴影；仅键盘聚焦时显示焦点轮廓 |
| 左侧图标 | 40 × 40px占位，内部20 × 20px，统一中性灰，无底板；品牌红仅用于版本标签和选中对勾 |
| 右侧信息 | 上方来源名称、下方版本及学校类型标签；图标至信息间距12px，两行间距4px |
| 来源名 | 14px/500/20px，主文字色，单行省略 |
| 版本标签 | 学校来源显示“学校版”，个人及协作来源显示“个人版”；沿用班级卡片“班主任”标签：11px/600、最小高20px、左右8px/上下2px内边距、4px圆角，浅品牌红底与品牌红字；通过共享MobileTag显式设置16px行高、弹性布局水平与垂直居中 |

## 11 交互与交付验收

1. 首页头像、来源、设置、待办和工具入口触摸按下不缩放、不改变透明度、不额外变色；保留键盘聚焦反馈。导航图标按全局导航规则处理。
2. 全部入口采用真实按钮，保留完整读屏名称；仅图形装饰隐藏于辅助阅读。来源按钮需要展开状态，当前来源选项需要选中状态。
3. 以393px宽、相同权限与相同待办数对齐首屏，再核对375px和430px。不能用整体缩放页面来弥补字号或间距不一致。
4. 验收重点：12px/450工具文字、12px卡片圆角、38px更多工具底座、19px线性图标、48px管理图占位及56px报表原图、卡间距12px、左右20px。
5. 保留资源透明边距，检查助理角标、长姓名、长学校名和权限过滤后的换行。字号放大后内容可滚动，不能被底栏永久遮挡。
6. 当前交付为源码参数与布局公式核对结果，未新增浏览器自动化或线上发布验证。发布时应在实际字体和小程序环境完成视觉验收。
