# 课堂大屏自适应设计规范

## 适用范围

本规范适用于教师端课堂大屏及其子页面、弹窗、抽屉和临时工作区，包括学生卡片、小组卡片、分组选学生、手动评价、评价项管理、随机点名和相关确认流程。

课堂大屏的真实观看条件不是单一的桌面显示器。常见设备包括 65、75、86、98 英寸一体机，以及投影到教室前方的幕布或白墙。常见输入分辨率包括 1280×800、1920×1080 和 3840×2160，但分辨率本身不能代表可读性：同样的 1920×1080，在近距离显示器和教室后排的观看效果完全不同。

## 核心决策

1. 使用“展示档位 + 内容区域自适应”，不使用整页 `transform: scale()`，也不使用连续 `vw` 字号缩放。
2. 展示档位分为“自动、标准、课堂、远距”。“自动”只根据浏览器可用视口做保守选择，无法推断真实观看距离；教室现场应允许老师直接选择“课堂”或“远距”。
3. 文字和操作热区使用离散档位放大，保证浏览器以清晰的整数像素渲染；卡片列数根据内容区域宽度重新计算，容器不足时允许滚动，不压缩到难以阅读。
4. 子页面和弹窗必须复用同一个展示配置，不得在业务组件内单独写一套“教室版尺寸”。
5. 信息关闭后，组件应同时收缩自身高度并保持剩余内容垂直居中。不能只隐藏字段而保留原占位高度。

## 档位基准

| 档位 | 主要场景 | 学生卡片宽度 | 学生头像 | 评价按钮字号 | 使用建议 |
| --- | --- | ---: | ---: | ---: | --- |
| 标准 | 台式机、近距离操作 | 136px | 68px | 15px | 保持较高班级信息密度 |
| 课堂 | 课堂一体机、前排到后排 | 160px | 80px | 17px | 默认推荐的教室现场档位 |
| 远距 | 投影、教室后排、光照较复杂 | 184px | 92px | 19px | 优先保证识别和点击，接受更多滚动 |

以上是基准，不是所有页面的固定高度。学生等级、表扬数据、待改进数据、学号姓名等可见内容决定卡片采用哪一档内容高度；全部关闭时继续使用更紧凑的高度。

## 页面接入规则

### 学生和小组列表

- 宠物底座第一期统一为低矮珍珠白云石图片，幼年期至究极体共用，初生蛋保留云朵鸟巢；底座为独立静止图层，不参与角色跳动或指针倾斜。幼年期保留柔软小跳，成长期为无旋转的轻快弹跳，成熟期为不变形的整体轻浮；完全体采用单层珠光闪卡与较轻指针跟随，究极体采用双层光环、沿宠物透明轮廓遮罩的一次流光和三颗短暂星点。动作不依赖宠物朝向；点击预览、键盘聚焦与悬停共用反馈，遵循系统减少动态效果偏好。底座仅在宠物内部画布定位，不改变卡片、姓名、标签或进度区的尺寸和位置。

- 在“学生 → 更多操作 → 学生卡片展示”中切换“宠物 / 学生信息”；顶部学生／小组导航保持原样。宠物卡片采用独立档位：172×256、212×304、280×376像素，姓名12／14／16像素，学号12／12／14像素，阶段标签11／11／13像素，辅助数字10／10／12像素，等级纯文字10／10／12像素，均严格小于姓名与学号；阶段标签主体高度18／20／22像素，与姓名行高度一致并垂直居中，水平内边距左8右6像素，折角另占4像素；等级无底色、无圆角、无内边距。白底无边框、顶部紧凑身份栏、中央完整宠物、右上方贴边阶段折角缎带标签，等级纯文字移至底部进度条上方左侧，与右侧经验分数同一行，阶段底色依次为#DCE3EC／#6FD16F／#5FA8FF／#B07BFF／#F4C14B／#FF6F6F，初生蛋使用#4B5563深灰字，其余阶段为白字，均无边框，标签正面使用小圆角纯色色面与极轻顶部反光，右侧伸出4像素并以右下4像素三角回折表现缎带质感，取消渐变和厚重底边；蛋阶段标签统一显示“初生蛋”，不添加外部发光或流动动画、底部珊瑚红到橙色的横向渐变进度条，叠加浅色静态斜纹，轨道使用浅暖色；评价弹窗与列表共用同一进度条配色和纹理，保留各自尺寸。悬停保持卡片白底，复用宠物原有阶段动作及光效，不隐藏光环、光晕和粒子；遵循系统减少动态效果偏好。阶段标签与总分数字字重为500，等级文字与经验分数字重均为600、文字色#475569；选中反馈采用不占布局空间的内描边，键盘焦点保持清晰可见。卡片上下内边距10像素、左右内边距8像素，学号和进度区采用统一对齐线，lv与进度分数分别对齐进度条两端；宠物画布独立计算，三档卡片外形尺寸与宠物体量不变；顶部身份区由40像素收紧为20／22／24像素，将额外20／18／16像素让给宠物。总分只显示数字，与进度同行；关闭总分不缩小宠物。宠物卡仅保留数值总分与含基础分总分设置，历史图标设置回显普通总分；学生信息模式不受影响。列表及随机点名复用同一宠物卡片配置，批量勾选标记不得遮挡右侧标签；成长采用lv1—lv10等级计算，进度条显示本级进度，只有lv10显示已满级；六阶段累计节点5／25／45／85／165不变，同阶段升级不更换形象，图像为已有演示素材。
- 宠物各阶段在上一版尺寸上统一放大10%，当前以预留画布为基准：蛋77%、幼年期88%、成长期94.6%、成熟期101.2%、完全体106.7%、究极体110%。100%指原预留画布，不是卡片尺寸，三档基准分别160／200／268像素；中档究极体约220像素。卡片和文字位置不变；所有阶段水平居中、底部对齐，较小形态保留上方留白，后期形态从共同底线向上展开。允许利用画布外围留白，完整展示，不裁切、不拉伸；缩放由独立容器控制，保留原有悬停动效。列表、随机点名与详情共用阶段比例。
- 点击任意快捷评价后，记录评价并更新积分，立即关闭弹窗，不显示“已表扬／已记录”等完成反馈文字或占位区域。左侧宠物预览为可键盘操作的互动按钮，点击与悬停播放同样的阶段动效和光效，支持连续点击重播，遵循系统减少动态效果偏好。
- 由内容区域宽度计算列数和卡片列宽，保持卡片宽度稳定。
- 学生卡片、分组详情中的学生卡片、随机点名中的学生卡片必须使用同一学生卡片布局配置。
- 小组卡片、随机点名中的小组卡片必须使用同一小组卡片布局配置。
- 学生卡片展示设置拆为`等级`与`表扬/待改进`两个独立设置组。等级组使用开关控制显示，开启后在组内渐进展示二选一的`等级形式：图标 / 总分`，两种形式不得叠加展示；关闭等级后隐藏但保留上次选择。等级始终按本学期统计并随学期清零，不提供历史范围选项。图标形式展示等级图标并保留头像进度环；面向用户统一命名为“总分”，计算口径仍为本学期加分减扣分，不计入一级指标基础分，不提供基础分配置。图标等级也按同一分数派生。总分形式在同一等级行只展示该数值、不显示“分”字，读屏文案保留完整单位（非负分使用浅蓝底配深蓝文字的圆角色片，负分切换为同规格的负向色片），不展示等级图标和头像进度环。
- 等级行始终在卡片顶部独立成行，等级行到卡片上边缘的留白与到圆形头像最高点的留白保持相等（三档分别为 8 / 8 / 9 像素），因此在“图标”和“总分”两种等级形式下切换时，等级内容的位置不跳动。两个留白由 `shared/classroomDisplay.ts` 的 `cardPaddingTop` 与 `levelAvatarGap` 共同决定：`cardPaddingTop + 卡片边框 2px = levelAvatarGap + 头像圆形内边距`，卡片三档高度按可见内容精确贴合，不再依赖纵向居中分配剩余空间。
- 表扬/待改进组使用`全部 / 表扬 / 待改进`三选一控制显示内容，固定按分值展示，不再提供`次数 / 分值`选择。表扬/待改进始终按本学期统计并随学期清零，不提供历史范围配置；分别累计正向分值和负向分值绝对值，不展示净得分。学生卡片视觉上只显示`+N / -N`，不重复显示“分”，读屏文案仍保留完整分值单位；小组卡片继续显示分值单位。
- 小组评价数据只汇总直接指向小组的评价事件，不累加成员个人评价；旧版次数开关兼容迁移，默认按分值展示。
- 不为了让所有学生一次性显示而把字号压缩到低于当前档位；优先保留可读性。

### 选人和编辑

- 分组选学生使用档位对应的头像尺寸、最小卡片高度和列宽。
- 搜索、仅看未分组、分组归属等高频操作保持原有位置，不因放大卡片而进入低频菜单。
- 选择卡片必须保留稳定的触控面积、选中状态和键盘焦点状态。

### 评价和随机点名

- 手动评价选项按钮根据档位调整列数、按钮高度和字号；标签过长时换行，不用缩小到难以阅读。
- 评价管理模式沿用评价弹窗的字号和按钮高度，避免进入管理模式后突然变小。
- 评价弹窗和随机点名弹窗使用档位宽度，同时受视口边距和视口高度限制；小屏幕上允许内部滚动。
- 分组抽屉和相关表单使用档位宽度，但必须保留 `16px` 以上的视口边距。

## 新功能检查清单

- 是否明确了近距离操作还是教室远距观看场景？
- 是否从 `shared/classroomDisplay.ts` 读取档位配置，而不是在组件内新增固定宽度、字号或高度？
- 学生卡片、小组卡片、选人卡片、评价按钮、弹窗和抽屉是否在标准、课堂、远距三档下都可读？
- 关闭部分展示项后，容器是否同步收缩并让剩余内容保持居中？
- 1280×720、1366×768、1920×1080 视口下是否存在文字溢出、按钮被遮挡或弹窗超出屏幕？
- 是否保留了滚动和焦点状态，而不是通过整体缩放规避布局问题？

## 配置归属

所有课堂大屏展示档位和跨页面尺寸基准统一维护在 `shared/classroomDisplay.ts`。业务页面只负责选择档位和传入可见内容状态；基础组件负责依据配置渲染，禁止在业务页面复制档位判断。


## 主页面控件尺寸固定

- 切换“自动 / 小 / 标准 / 大”时，班级筛选、学生／小组切换、搜索、分组方案与更多操作所在行，以及底部的显示大小、批量评价、随机点名和点评记录，始终复用“小”档（内部 `standard`）的字号、图标和控件尺寸。
- 以上主页面控件通过独立的 `pageControls` 引用公共档位配置，保留原有布局和操作路径；批量选择与重新计数时的底部操作也采用同一固定尺寸。
- 学生与小组卡片、评价弹窗、随机点名弹窗及抽屉仍跟随所选展示档位，不受主页面控件固定尺寸影响。

- 在固定“小”档基础上，主页面通过 `CLASSROOM_PAGE_CONTROLS` 统一压缩纵向空间：筛选行上方留白与下方间距均为12像素；内容底部与网格底部留白各16像素，取消原有40与80像素叠加占位。
- 班级按钮高度40像素，学生／小组按钮高度36像素（含分段控件外层约46像素），搜索和底部主要按钮高度基准44像素；原有文字、图标、横向布局与操作路径保持不变。
- 底栏上下内边距各12像素，主要按钮上下内边距由14收紧为8像素；点评记录保持上下排列，缩减图标容器至24像素，整体点击高度不低于44像素。


## 操作控件圆角

- 小学与初中共用克制形态，参照教师手机端：普通按钮8像素，分段轨道8像素、选中块与按钮4像素，班级／分组下拉面板、底部操作组底板与随机人数浮层12像素。小／标准／大三档圆角一致。
- 顶部筛选、底部操作、定位面板中的全部／首字母／姓氏筛选、评价项及其编辑、弹窗／抽屉操作按钮统一引用 `components/classroom/classroomControls.css` 的语义形态类。组件库按钮通过显式类名接入，不全局覆盖基础组件。
- 男／女图标筛选、点评记录图标底板、悬浮工具、头像、开关与状态圆点保持圆形；定位面板的收起按钮仅左侧8像素圆角。
- 学生／小组卡片、弹窗外壳、随机点名卡槽保持原有圆角；按钮尺寸、间距与操作逻辑不因圆角调整而改变。
- 公共滑动分段组件由课堂大屏调用处接入轨道类，局部调整其滑动底块为4像素，不改变其他页面的默认形态。


## 页签与切换反馈

- PC工作区最顶部“首页 / 课堂大屏”等应用页签采用8像素圆角，同级页签保持一致。
- 学生／小组切换与自动／小／标准／大切换复用公共滑动分段轨道，选中底块以200毫秒平移到目标项；视图切换仍使用蓝底白字，尺寸切换使用白底蓝字，尺寸、留白及操作行为不变。
- 通过 `aria-pressed` 暴露选中状态，沿用系统减少动态效果偏好；底部操作栏上下留白分别由8增加至12像素，按钮本身高度不变。


## 宠物模式展示密度

- 宠物与学生信息模式分别维护卡片宽度；用户可见“小 / 标准 / 大”三档的宠物卡片尺寸分别为172×256、212×304、280×376像素，间距继续采用12 / 16 / 20像素。
- 浏览器可用宽度约1920像素、未打开定位面板时，宠物模式每排分别展示10 / 8 / 6张。列数由实际内容宽度计算，窄屏自动减少，不把10 / 8 / 6硬编码为所有设备的固定列数。
- 姓名、学号、阶段、等级与总分保留原有字号和紧凑排版，增量空间主要给宠物；阶段相对比例、底部对齐、完整展示与动效沿用原规则。
- 学生信息卡、小组卡、分组选学生和顶部／底部控件配置保持不变。宠物卡本身及网格统一读取 `studentCard.pet.width`，避免卡片宽度与列宽不一致。
- 随机点名复用相同宠物卡片尺寸，槽位宽高同步容纳卡片，列数受弹窗实际可用宽度限制，空间不足时减少列数并保留纵向滚动。

### 宠物形象生成等待态

- 效果在 `/demos/pet-growth-prd.html?view=brief#report-evolution` 的“进化中，陪伴不中断”区域评审；当前预览独立实现文字球体，参考 Orbital Type 的公开演示，不是官方组件源码。
- 预览复用真实课堂卡片和评价弹窗，生成等待态使用透明底色，透出卡片和弹窗原背景，不增加独立底块，宠物图片保持不透明，缩至当前展示尺寸的60%，保留阶段比例与原阶段标签；文字球根据整张图片展示区域定位，不依赖头部或身体识别。禁用宠物图片自身的悬停动效，仅保留文字球交互。
- 文字为“进化中”，字重500、11条纬线文字带，正面低饱和蓝灰色（#64788F）、背面浅蓝灰色（#94A3B8）且透明度0.15，倾斜24度；字大小保持原15圈版高度，横向间距系数增至1.4，球体直径为画布短边的88%。前后两层画布分别位于宠物前后，沿球面进行文字透视投影，支持悬停、拖动和点击脉冲。列表卡片默认静态呈现文字球，鼠标悬停时仅当前卡片播放，移出即停止；评价弹窗保持完整动画。播放期间跟随浏览器屏幕刷新，不使用低帧率定时器；缓存字形、球面坐标和切向量，按行复用旋转计算并限制像素密度。离开视口、页面隐藏或系统减少动态效果时停止刷新任务，恢复可见后再继续。预览与课堂大屏复用同一文字球组件；演示中每20个学号的第04、08、11号模拟生成任务，评价与随机点名使用同一等待态。真实生成服务尚未接入，正式批量使用前仍需评估目标设备的多卡片性能。
