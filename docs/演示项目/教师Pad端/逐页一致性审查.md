# 教师 Pad 与教师手机端逐页一致性审查

更新日期：2026-11-03。基线：本地教师手机端、星河实验学校、刘飞老师。范围：当前 Pad 全部页面、相关弹层和首期迁移边界。

## 首期精简（2026-11-04）

按最新范围，Pad 不展示管理工具区块、值周安排及班级排行榜入口；更多工具保留建议反馈。下方相关页面检查为此前演示验证，不代表首期入口仍开放。教师手机端保留原功能。

## 修正结果

此前差异最大的记录、班级、我的三个一级页面已完成修正。记录使用手机端原顶部与录入控件；班级共用原筛选和资料卡片；我的直接使用完整 MeView，并接通手机端个人资料、学校来源、设置页面。Pad 只增加容器排版和设备预览，不维护另一套视觉基础值。

本次沿用 frontend-design-review 的专业评审与教师手机端规范，入口名称、含义、学校权限和资料源均以现有手机端为准。首期学生业务仍暂缓迁移，不能视为全量功能验收完成。

## 尚未移植的范围

- 学生记录、学生列表与详情、学生资料/档案/体检/采集/成长币明细、班级报告、学期报告。
- 班级资料管理、创建/加入、学生新增/批量管理、社团与团队及其资料/报告。
- 奖励兑换及记录、颁发奖章、人脸/兑换密码、作业录入/批量导入。
- 文件、科目/部门管理、成长币发放、问卷、档案设计、报告配置、家长端展示、AI宠物。
- 学生评价报表、校长助理及周/月/学期报告与历史、班主任学生侧行动建议与评价复盘及历史。
- 个人空间和只开通学生评价的学校尚未进入 Pad 首期可用来源。

后续迁移继续接入同一手机端页面和菜单回调，不改名替代原功能，不新增独立评分或权限规则。班主任助理学生侧开启前，须先接通对应详情路由。

## 追加修正（2026-11-03）

已将渐变背景和弹窗遮罩扩展到完整设备屏幕，年级弹窗取消手机最大宽度；手机单一记录对象隐藏切换和标题，Pad 班级页移除单项分类。演示环境切换的教师 Pad 入口补齐平板图标并与手机入口统一文字和选中样式。

本次追加验证：Pad 竖屏年级弹窗与设备等宽，遮罩与设备边界一致；横屏渐变背景与设备边界一致；手机端星河双对象显示切换，七中仅班级与青禾仅学生均隐藏切换和标题。生产构建与记录交互专项检查通过，新增单对象渲染场景通过。

底部导航追加修复：取消导航整体上移20像素，将底部安全区改为导航内部留白，背景贴齐屏幕底边。浏览器测量横屏/竖屏、有壳/无壳四种状态，导航底边与屏幕底边间距均为0，主内容与导航没有重叠。生产构建通过。

我的工具追加：管理工具与更多工具改为104像素固定列宽、24像素列间距的紧凑网格，手机默认四列不变；更多工具接入建议反馈及手机端共用表单，沿用演示图片和模拟提交，未接入生产服务。

本次工具区验证：横竖屏两组网格均为104像素列宽、24像素列间距；建议反馈空内容禁用提交，演示图片添加/删除、填写提交、提交后提示并返回我的已通过浏览器验证。构建及我的页专项检查通过，渲染巡检仍仅有既有学校后台名称问题。
