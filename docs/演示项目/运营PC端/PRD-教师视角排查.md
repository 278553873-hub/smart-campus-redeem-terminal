# 教师视角排查 1.0

## 运营电脑端

「系统管理」按现有后台菜单展示「角色配置」「权限配置」「管理员管理」「排查授权管理」「小程序链接」「协议管理」「数据迁移」「小程序工具排序」「系统配置」。

「排查授权管理」标题下说明授权人员可在教师小程序按手机号切换账号排查问题。列表显示教师姓名、手机号及所有关联学校，可按姓名或手机号查询。点「新增」后输入完整手机号并检索，显示匹配的教师和学校，点「确认」添加授权。同一账号只出现一行。操作列点「移除」后，二次确认即可撤销授权。

## 教师小程序

在教师手机端完整版，获授权的账号登录后，在「我的 → 设置 → 账号安全」按住「登录账号」1 秒打开「问题排查」。输入目标手机号后点「切换并登录」。已注册的账号直接进入首页，有学校时进入默认学校，个人账号进入个人空间。未注册时在弹窗内提示「该手机号未注册，请核对后重试」，保留输入和当前登录。后续操作按目标账号自身的授权判断。

## 演示路径

1. 从「运营-PC端 → 系统管理 → 排查授权管理」点「新增」。弹窗右侧的「演示账号」卡片列出体验步骤。输入 `19000000000`（刘飞），检索结果显示关联的三所学校，点「确认」完成授权。
2. 在同一浏览器的「教师-手机端」用「最近登录」进入刘飞账号。
3. 打开「我的 → 设置 → 账号安全」并按住「登录账号」1 秒，输入 `19900008610` 切换到陈雨，或输入 `15200001332` 切换到周宁的个人空间。
   在桌面 Demo 中，弹窗打开后，可在手机预览右下方切换「已注册 / 未注册」，再输入显示的演示手机号。预览卡片与弹窗底边对齐。未注册使用 `19000000001`。
4. 在「我的」核对目标姓名和学校关系。长按「登录账号」只对获授权的账号打开排查弹窗。

Demo 使用预置教师账号以及浏览器本地授权数据。同源页面和标签页读取同一份演示授权。
