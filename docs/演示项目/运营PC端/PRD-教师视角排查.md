# 教师视角排查 1.0

## 运营电脑端

「系统管理」按现有后台菜单展示「角色配置」「权限配置」「管理员管理」「排查授权管理」「小程序链接」「协议管理」「数据迁移」「小程序工具排序」「系统配置」。

「排查授权管理」列表显示教师姓名、手机号及所有关联学校，可按姓名或手机号查询。点「新增」后输入完整手机号并检索，在结果卡片核对教师和学校，并在卡片下设置安全码。新设置的安全码至少 8 位，仅限数字和英文字母，两种都须包含。点「确认」添加授权，同一账号只出现一行。通过操作列「重置安全码」可设置新码，排查人员下次使用时重新验证。原有未设置安全码的授权可在此补设。点「移除」后二次确认即可撤销授权。

## 教师小程序

在教师手机端完整版，获授权的账号登录后，在「我的 → 设置 → 账号安全」按住「登录账号」1 秒打开「问题排查」。输入目标手机号后点「切换并登录」。目标已注册且当前排查人员尚未验证时，弹窗显示安全码输入框，通过后进入目标首页。每个排查人员在当前浏览器对同一次授权只需验证一次。目标有学校时进入默认学校，个人账号进入个人空间。未注册时在弹窗内提示「该手机号未注册，请核对后重试」，保留输入和当前登录。

同一浏览器登录过多个可切换账号后，设置页在「退出登录」上方显示「切换账号」。弹窗按登录时间展示最近 10 个账号，每个账号一行，展示教师姓名、脱敏手机号和上次使用的学校或个人空间。关联多校时补充学校数量。点「切换」后恢复该账号上次使用的空间；上次学校不可用时进入默认学校，无学校时进入个人空间。进入临时排查账号后，可从这里切回原账号。原排查人员的授权与安全码验证仍有效时，也可从列表再次进入排查目标。

## 演示路径

1. 从「运营-PC端 → 系统管理 → 排查授权管理」点「新增」。输入 `19000000000`（刘飞），检索并核对关联学校，设置符合要求的安全码，再点「确认」完成授权。
2. 在同一浏览器的「教师-手机端」用「最近登录」进入刘飞账号。
3. 打开「我的 → 设置 → 账号安全」并按住「登录账号」1 秒，输入 `19900008610` 或 `15200001332`，首次校验通过后进入陈雨的默认学校或周宁的个人空间。
4. 桌面预览右侧可用「当前账号是排查人员」的「是 / 否」模拟不同身份。打开弹窗后，右侧预览区底部显示「输入的手机号是否注册」。通过「是 / 否」模拟注册结果，输入任意格式正确的手机号即可。选「是」后显示「是否输入过安全码」滑块，选「否」时在同一张卡片下显示预览安全码 `Preview2026`。滑块只模拟本次排查，运营授权和验证记录继续按实际操作保存。
5. 在「当前设备已登录多个账号」选择「是」，点设置页的「切换账号」可预览 10 条示例账号的满列表。选择「否」隐藏该入口。示例切换只更新预览选中项。
