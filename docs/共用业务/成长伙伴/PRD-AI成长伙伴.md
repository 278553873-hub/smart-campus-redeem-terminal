# AI 成长伙伴

## 1. 教师手机端配置与初始生成

### 入口、权限与产品定位

对外功能名称统一为 **AI宠物**，强调根据真实评价生成个性化成长形象。教师手机端入口为“我的 → 更多工具 → AI宠物”，位于家长端展示之后；页面标题和主开关分别为“AI宠物”“开启AI宠物”。仅学校管理员、校级负责人等学校管理层可见和配置，与家长端展示管理权限一致；普通教师、班主任不显示学校配置入口。配置按学校隔离，全校统一使用。

AI宠物未来规划独立付费；本期不展示价格、购买入口或虚构已开通权益。

### 页面结构与默认值

主开关默认关闭。关闭时隐藏基础设置与高级设置，重新开启保留已保存配置。开启后依次显示以下两张卡片，不显示“个性化宠物”板块，也不显示学生自定义初始蛋、控制进化方向开关或“即将开放”占位。

| 卡片 | 配置项 | 选项／操作 | 默认值 |
|---|---|---|---|
| 基础设置 | 领取方式 | 班主任领取／学生领取 | 班主任领取 |
| 基础设置 | 扣分处理 | 不扣经验／扣经验 | 不扣经验 |
| 高级设置 | 升级经验 | 打开阶段与等级累计经验配置抽屉 | 使用第6节默认门槛 |

基础设置采用左侧配置项、右侧滑块的行布局，参考成长币发放的预算设置。两行滑块统一190像素宽、等分选项、相同字号与滑动效果，右侧对齐；窄屏不超出可用宽度。主开关和基础设置切换立即保存，保存失败保留原值并提示重试。

“班主任领取”表示由班主任统一领取，“学生领取”表示由学生领取。领取主体的选择不等同于自定义初始蛋或进化方向，不开放身份重抽。具体领取操作入口及流程另行设计，本次实现学校配置页面。

### 升级经验配置

通过公共底部抽屉编辑“达到每一级所需的累计经验”，不是逐次升级经验。按六阶段分组，以灰、绿、蓝、紫、金、红色条分别标识初生蛋、幼年期、成长期、成熟期、完全体、究极体；同时保留阶段名称、等级和经验文字，不仅凭颜色识别。同阶段内两级并列展示，手机端各阶段纵向排列。

1级固定0经验，2—10级共9个输入项；默认累计经验为5、15、25、35、45、65、85、125、165。必须为递增正整数，每一级严格高于前一级；10级标注满级，不设置11级。点击保存后统一生效，取消不保存草稿。关闭宠物再开启时保留原配置。

### 当前交付范围

学校配置页面已实现，沿用现有演示项目按学校保存到当前浏览器的方式；尚不代表已完成服务端跨设备同步。实际领取流程、经验扣减、阶段保留、生图复用和课堂大屏读取学校门槛仍须接入成长流程，不把页面配置完成视为完整业务已上线。

首期不提供学生自定义蛋或基础信息选择，蛋款由系统分配；每次进化的方向输入暂不开放。元素、类别、性别、期望特性由系统随机确定，进化形象根据真实评价自动生成。

每名学生从蛋开始培养。不提供预设成品宠物供学生挑选，也不提供重新生成。

| 信息 | 确定方式 | 作用 |
|---|---|---|
| 元素 | 系统随机 | 提供材质与造型灵感，不限定后期色表 |
| 类别 | 系统随机 | 提供初始造型灵感，不锁定现实物种骨架 |
| 性别 | 系统随机 | 只影响少量外观细节，与学生本人性别无关 |
| 期望特性 | 系统随机确定 | 影响设计主题、纹章和角色气质，不视为真实行为 |
| 日常评价 | 使用学生真实行为记录 | 形成个性化装饰、装备与成长说明 |
| 本次进化意愿（后续规划） | 当前不提供输入 | 后续开放时仅影响固定身份与阶段规则内的本次造型 |

随机的是伙伴身份，不是直接抽取一张成品图。AI 在身份规则内，结合评价与可选意愿创作形象。

没有足够评价时也可获得蛋，不虚构经历。元素与类别随机确定后固定；性别随机确定后固定，本期不随进化更换。

**首期只有普通蛋，没有学生自定义蛋、勋章蛋或稀有蛋。**

- 首期使用紫色星纹蛋和橙色条纹蛋。大块、稀疏花纹配合温润釉面，不透露随机元素、族类、性别或特性。
- 两款蛋共用云朵藤蔓鸟巢：上层柔软云朵，下层淡米色编织藤蔓，少量淡绿色叶片。蛋和巢独立保存，前缘完整遮挡蛋底，不用渐变透明混合。
- 禁止密集斑点、孔洞感、鳞片、蛇皮联想、复杂交织或高度相似的卷曲花纹。品质来自材质与层次，不来自装饰堆叠。
- 使用公共美术素材，按学生标识稳定分配，刷新不换款，不逐人调用生图。验收同时查看白底实际卡片与96像素小图；首期不为勋章预留专门空白区域。

## 2. 伙伴属性

### 元素

第一期采用金、木、水、火、土五种，无优劣、稀有度或属性克制。

| 元素 | 形象表现 |
|---|---|
| 金 | 金属、护片、连接结构 |
| 木 | 枝芽、叶片、藤蔓、木质纹理 |
| 水 | 水滴、鳍、波纹、流线结构 |
| 火 | 暖色核心、火苗轮廓、焰纹 |
| 土 | 岩层、陶土、厚实外壳 |

### 类别

采用学生能理解的名称，覆盖现实、神话和虚拟生命。动物形态优先采用毛茸茸的小兽，其他类别保留幻想多样性。

| 类别 | 可生成的形象方向 |
|---|---|
| 小兽 | 优先猫、狗；扩充狐狸、兔子、小熊、松鼠、水獭、小熊猫等毛茸茸的原创兽形 |
| 飞鸟 | 鸟形、幻想翼鸟 |
| 昆虫（扩展保留） | 蝶翼、蜻蜓翼等可作局部灵感；首期不纳入默认随机主类别，不采用甲虫主体路线 |
| 游鱼 | 鱼、鳐及幻想游体 |
| 植物 | 种荚、花、树、藤等 |
| 神兽 | 原创龙、凤凰、麒麟等神话意象 |
| 机械 | 机关兽、积木生命、机械伙伴 |
| 精灵 | 云团、凝胶、能量体、数字生命 |

新伙伴的随机分配优先采用小兽，其中猫、狗为优先方向；元素独立随机，水元素也可以生成毛茸茸的小猫，不要求变成水生动物。种族与学生的评价高低、性别无绑定关系，个性化仍由真实行为形成的主题、纹章与装备体现。

每只伙伴确定一个主类别和初始设计方向，不在每次进化时重新抽取。类别是灵感来源，不是解剖约束：允许足、蹄、触角、翅等重构为兽掌、冠饰、足甲、翼盾。昆虫不要求始终六足，直立神兽不要求保留蹄形手。飞行、游动等作为形象设计的一部分，不另设一套学生需要选择的属性。

### 性别

- 首期由系统随机确定男／女，确定后保持不变。
- 只体现一两处微弱差异，如眼形、睫毛、面部曲线、耳尾末端。
- 不决定体型级别、装备、强弱或精美程度。任何性别都可以拥有铠甲、武器、书本等。
- 小图首先看出伙伴身份与阶段，性别细节不能盖过整体形象。

## 3. 基础信息与进化方向输入

### 基础信息

首期不向学生提问或提供选择；元素、类别、性别与伙伴特性由系统随机确定。特性可为勇气、友情、爱心、知识、纯真、诚实、希望、光明，不视为学生人格，也不决定元素或类别。蛋只展示中性线条款式。

### 每次进化的方向输入（后续规划）

当前学校配置不提供控制进化方向开关，孵化及进化依据已有身份和真实评价自动生成。以下仅为后续能力边界，不属于当前交付：

- 可支持录入“这次希望伙伴怎样成长？”，在生成前提交意愿；不提供重新抽取身份或重生成。
- 意愿可影响姿态、装备、纹样等，不改变固定元素、类别、性别或阶段。
- 审美偏好不能被写成真实行为；例如希望出现书本，没有阅读记录时不能解释为“因为你爱读书”。
- 具体输入主体、入口、异常恢复和是否付费，待后续方案确认。

## 4. 六阶段进化

| 阶段 | 形态要求 |
|---|---|
| 初生蛋 | 精致中性线条、封闭蛋形，不提供自定义或勋章 |
| 幼年期 | 软糯团子，头身一体，饱满脸颊与短小肢体；兽形优先蓬松短绒毛，保持想亲近、想抱的质感，不是缩小的成年形象 |
| 成长期 | 头身开始分开，出现明确的足、鳍、翅芽等物种结构 |
| 成熟期 | 完整的生物或构造体，主要器官和轮廓清晰 |
| 完全体 | 主体结构明显跃迁，五官开始成熟、神态自信；局部能量光与少量粒子突出力量 |
| 究极体 | 结构演化连续，五官成熟从容；有组织的粒子、光带和轮廓光呼应专属称号与使命 |

**阶段决定形态跃迁，评价决定个性化主题。** 相邻生命阶段必须改变姿势，并至少改变两项主体设计：比例、支撑方式、主要器官构成、外轮廓。仅换动作、放大身体或增加挂件均不算进化。究极体可以重构完全体的结构，不必沿用同一站姿。

**一致性只锁定两至三项识别特征**，如眼睛、额头纹章、水滴形冠饰；特征可随进化转译，不机械放大幼年器官。普通蛋不是未来配色依据。参考图用于识别角色，不锁死骨架。

**幼年期优先可爱与触感：**突出饱满体块、细密短绒、蓬松脸颊、小脚垫和自然好奇的表情。毛发有轻柔起伏而非尖刺或逐根杂乱长毛；少用硬壳、金边和装备遮住柔软主体。水、凝胶或机械等灵感不强制全身长毛，可用柔软圆润材质保留同等亲和力。

**动物形态统一偏向细腻毛绒质感的三维童话风：**柔和体积光、细密短绒、蓬松脸颊与胸颈毛、圆润爪掌，脸与轮廓清楚。毛发顺着身体结构生长，有疏密和柔软起伏，避免杂乱长毛、尖刺毛束、塑料亮面及廉价玩偶感。幼年突出可抱的软团；后期保留毛绒主体和耳、尾、爪掌的识别感，以体态、成熟五官和少量精致装备体现帅气与力量，不能用全身硬甲盖住毛发。蛋沿用温润釉面；鱼、植物、机械等形态采用各自合适的材质，不强行全身长毛。

**五官随阶段成熟：**保留眼色、瞳孔特征、纹章和面部轮廓线索，不锁定幼年眼睛大小与婴儿比例。成长期、成熟期逐步收敛脸颊和眼睛占比；完全体形成清楚的眉眼、鼻口与下颌关系，表情自信；究极体进一步舒展面部比例，眼神坚定、从容，有称号对应的气度。仍是友善幻想伙伴，不真人化、不凶恶化、不把性别作为成熟度依据。

**光效随阶段递进：**蛋与幼年以材质柔光为主；成长期少量亮点；成熟期在角、纹章或护具出现局部能量光；完全体加入稀疏粒子与短轨迹；究极体允许更丰富的粒子、局部光带和轮廓光。效果围绕一个主焦点、有明确来源与运动方向，呼应伙伴形象及使命，不能满屏散点、遮脸、盖住行为装饰或替代结构进化。常驻卡片克制，揭晓与详情可更突出；光效属于阶段美术设计，不冒充某条加分记录带来的奖励，不改变主元素。

**结构连续：**动作与骨架分开设计。完全体若已明确为双臂双腿结构，究极体腾跃时仍需能辨认肩、肘、手掌、髋与双腿，不能因横向姿势重新读成四足兽。若需要再次重构骨架，必须在阶段设计中明确，不由生成结果偶然决定。

**颜色随阶段丰富：**幼年简单柔和；成长期、成熟期增加辅助色；完全体、究极体允许新强调色、金属、玉石、晶体或局部虹彩。保留初始记忆色的联系，不固定色表；大面积色、小面积强调色分工清楚，避免全身同等鲜艳。外观金属或叶纹不自动改变主元素。

**美感优先：**初期软糯，后期更帅气、优雅、完整。禁止写实口器、密集节肢、长软触手等不适细节；四足阶段的小蹄可爱，直立后允许兽掌与足甲。只设一个主要视觉焦点，脸部及关节连接清楚；不强制所有种族人形化、穿甲或长翅。采用枝角、护甲等结构时保持舒展和整体感，不堆树冠架、叶片、金边和挂件。

## 5. 评价如何体现在形象上

AI 分析真实行为，在每次进化时提炼少量主要经历，通过装饰、装备和纹样表达。

| 真实行为 | 可采用的艺术表达 |
|---|---|
| 关心同学、主动帮助 | 守护铠甲、护肩、盾形纹章 |
| 积极发言、讲解、展示 | 共鸣法杖、声波形幻想武器、表达纹章 |
| 阅读、提问、探索知识 | 书本、卷轴、记录册、观察镜 |
| 坚持练习、修改后重试 | 连续纹样、腰带、逐步完整的徽记 |
| 合作完成任务 | 连接纹、成对配饰、相扣护片 |
| 照料植物、观察自然 | 叶纹、种子饰物、枝叶护具 |
| 整理物品、承担值日 | 收纳袋、有序纹样 |
| 绘画、制作、运动参与 | 创作器具、彩色嵌片、护腕、流线纹等 |

- 同一行为可以有不同表达，需匹配伙伴的元素、类别和阶段，不是一条评价兑换一件装备。
- 每阶段归纳一个主主题、最多一个辅助主题；多条同类行为合并表达。幼年只用小纹样，后期最多一件主体装备和一处辅助细节。旧装饰可整合或替换，不逐阶段累加。
- 新阶段优先使用近期记录，同时延续已有主题；记录不足时正常进化，不编造新故事。
- 学校指标保留原意，结合具体事件分析，不按最高分指标固定分配物种。
- 负面评价不生成丑陋、残缺或低等形象；分数高低不决定精美程度。
- 可展示一句对应说明，例如：“你主动帮助同学，伙伴长出了守护护肩。”说明必须有真实记录依据。

### 进化完成后的成长说明

- 揭晓时展示新形象、属性标签和一句成长文案；可查看最多三项“具体评价事件 → 图中实际出现的变化”，之后在伙伴详情保留。
- 先确定并保存记录编号／原文、主题、目标部位及解释，再生图；出图后核对。未实际画出的特征不能写入学生可见说明。
- 标签区分身份（主元素、族类、性别、期望特性）与本次形象特征；新增配色、材质不表示获得第二主元素。未公开身份的蛋只显示阶段。
- 行为、学生意愿、阶段美术设计分别说明来源。默认一句话突出一个主要主题，不把姿势、身体长大或每种颜色都归因于加分。
- 同类行为合并表达；共同记录保留共同参与含义；历史印记注明延续。证据不足不虚构，也不降低形象质量。
- 演示用的模拟偏好必须标明；六阶段展示用于审美评审，不据此声称学生已经达到成长门槛。

### 究极体专属称号

- 伙伴首次进化为究极体时，揭晓一个专属称号和一句使命宣言；“究极体”仍是阶段，称号是伙伴的荣誉身份。
- 结合本只伙伴培养期间的主要正向经历、实际形象和既有主题生成，不只看最后一次加分，也不只按元素套固定称号。优先选择有多条记录支持的主题；依据不足时采用形象主题，不虚构经历。
- 称号建议4至8字，学生易懂，有角色感；使命宣言一句话，描述伙伴愿意探索、守护或创造什么。称号不代表学生人格、班级职务、排名或新增任务，无高低稀有度，不承诺全校不重名。
- 展示顺序：究极体标识、专属称号、形象、使命宣言、成长依据。默认展示一句来源说明，详细依据沿用成长印记展开查看。
- 称号、宣言及所依据的记录随本次进化保存；揭晓后稳定保留，不随刷新或领养下一只而变化。称号由界面文字展示，不烧录进图片，不增加生图次数。

## 6. 成长与多伙伴

- 有效正向加分按分值增加经验，不按评价次数计数、不计基础分；达到学校配置的累计经验门槛后升级或进化，不要求额外任务或手动确认。默认六阶段累计节点为5、25、45、85、165经验，可由学校修改各等级门槛。
- 后期阶段持续更久，中间用进度条反馈，不为每次加分生成新图。
- 经验与兑换积分独立，兑换商品不扣经验。普通扣分按学校选择处理：默认不扣经验；选择扣经验时等量扣除，最低为0。错误加分撤销需要修正经验。任何经验减少均不得回退已解锁阶段或回收已展示形象；重新达到已有阶段时复用原图，不重复生图，只有首次进入新阶段才生成新形象。阶段解锁状态须与当前经验分开保存。扣分后的等级、进度展示需在成长流程接入时明确，不得据此擅自降阶段。
- 正常进化不要求额外任务，当前不录入进化意愿，不增加另一道教师审批。
- 固定六阶段，不设置超究极体。只有达到究极体后，才能领养下一只。
- 可拥有多个伙伴，同时只培养一只；旧伙伴与阶段图片保留，可切换查看。
- 新伙伴从蛋开始，重新随机身份；旧伙伴成长值不转移、不重复使用。

### 进化生成等待态（已确认）

- 达到进化门槛并实际启动生成任务后进入等待态；保留最近可用形象和原阶段标签，等级与经验按实时有效正向加分继续累计，评价操作照常可用。不显示虚构的生成百分比。

## 7. 生图与互动

### 阶段生图

- 普通蛋使用两款公共素材；孵化至究极体共五张阶段图，按阶段生成，不提前出全套。日常互动复用已有图片，不增加生图次数，不生成视频或逐帧图片。
- 提示词使用中文，分为：基础规范、身份与保持一致性、评价记录分析、学生意愿、阶段形态与姿势、美感与出图检查。所有学生共用[中文分组提示词](中文分组提示词.md)。调用时填入当前伙伴身份、目标阶段、已有参考图、有效评价和已提交意愿；分析结果随本次数据生成，不写死学生案例或复用其他学生的配色、纹章及称号。历史生图记录单独保留，不作为公共规则或生产输入。
- 每次进化参考身份标志和已有阶段图；先检查美感与亲和力，再检查姿势、结构和小图区分度，最后核对身份及评价依据。检查大图与96像素小图，提示词不能代替验收。
- 图片保留透明背景和完整轮廓。阶段图可带静态光效，已有强光效时减少页面叠加，保护五官及行为装饰。
- 生图在后台完成，等待期间旧形象继续可用；新图准备好后提示揭晓，不阻断点评。
- 学生不能重抽。后台仅对错阶段、结构异常等质量问题有限纠错，不因个人审美偏好重做。

### 分阶段回应

宠物始终是卡片的视觉主体。鼠标移入后动作播放一次，停留时不反复跳动；键盘聚焦也可触发。卡片、随机点名与详情采用同一套阶段规则，详情可适当增强细节。

| 阶段 | 回应动作 | 材质与环境反馈 |
|---|---|---|
| 初生蛋 | 小幅左右轻晃，鸟巢不动 | 温润蛋壳与云朵藤蔓鸟巢 |
| 幼年期 | 轻微挤压后软弹回位 | 保留毛茸茸、软糯触感，不叠加镭射 |
| 成长期 | 轻跃一次，落下缓冲 | 水纹、叶片等承托细节轻微回应 |
| 成熟期 | 小幅前倾后恢复 | 克制的属性微光，保持主体稳定 |
| 完全体 | 稍稍舒展 | 单圈虹彩光环、轻微视差、少量短暂闪点 |
| 究极体 | 轻微浮起后回位 | 双圈虹彩光环、更清楚的前后层次、少量短暂闪点 |

- 软弹适用于幼年软团；后期护甲、角和肢体保持完整，使用整体平移、倾斜和舒展，不明显拉伸变形。
- 静态单图用于整体动作与图层效果；眨眼、转头、挥手等需要额外表情或身体分层，不作为首期承诺。
- 日常界面不增加喂食、打卡或重复点击任务，卡片点击仍进入评价／详情。

### 承托装饰

角色、承托、背后光效独立分层。承托保持低矮、中间留空、两侧点缀，位于角色后方，不遮脚、不抢脸部焦点、不额外挤占卡片高度。按主元素复用公共素材，不随每名学生重新生图，也不表示额外获得一种属性。

| 形态／元素 | 承托方向 | 当前落地情况 |
|---|---|---|
| 普通蛋 | 柔软云朵、淡色藤蔓编织鸟巢、少量叶片 | 已演示；不暗示未来主元素 |
| 水 | 浅水纹、低矮波纹与淡影 | 已演示 |
| 木 | 少量叶片、柔和苔面色与淡影 | 已演示 |
| 金 | 简洁金属弧线、少量嵌片与淡影 | 真实开发时细化 |
| 火 | 温暖微光、少量余烬色亮点 | 真实开发时细化；避免大面积烈焰 |
| 土 | 平滑浅石面、少量苔石与淡影 | 真实开发时细化 |

### 镭射与视差

借鉴镭射闪卡的角度反光、图层视差和稀疏闪点，采用轻量网页图层实现。首期作用于角色背后、轮廓和承托，不覆盖五官、毛发及评价形成的装备细节。

- 完全体单圈、究极体双圈；属性色为主，少量虹彩辅助，不改变伙伴主元素。停留期间光泽方向随指针位置变化，离开后淡出、复位。
- 角色与背后光环产生小幅相对位移；姓名、学号、总分和成长进度不跟随倾斜，保持阅读及点击稳定。
- 当前演示最大倾斜约4度、角色偏移约3像素、短暂闪点3枚。参数作为效果起点，真实开发按图片留白、阶段、显示尺寸及设备性能校准，不固定为最终验收数值。
- 仅激活当前交互的伙伴，不让全班同时循环闪动。无需为每只伙伴制作三维模型；真实开发需验证整班展示、低性能课堂设备、连续移入移出及离屏状态的资源占用。
- 系统开启减少动态效果时关闭位移、软弹及动态光效；不支持效果时回退为清晰静态形象。无鼠标悬停时，卡片点击仍进入评价；弹窗内的宠物预览支持点击或触摸播放同一阶段动效。
- 局部铠甲、晶体、翅翼反光作为后续优化：需提供对应部位的效果蒙版，验收后再接入，不能仅凭单张图承诺准确识别材质。
- 双图光栅翻转不作为日常悬停交互，避免把形象切换误读为已经进化；首期不增加镭射强度、角度等学生操作控件。

### 进化揭晓

使用聚光、短暂遮挡、旧新形象切换及收束光效；可跳过。随后展示成长说明，究极体同步揭晓专属称号与使命。动效不替代结构进化，也不把通用光效解释为某条评价带来的奖励。

## 8. 后续扩展

学生选择性别、特性及勋章蛋留作后续探索，不属于首期。后续可在进化节点开放更换元素或类别，并要求完成匹配的教育行动。例如希望转向木元素，可以通过植物观察、照料等经历满足条件。

行动应帮助学生探索想要的方向，可复用已有评价，不成为兑换宠物的额外作业；未完成仍可沿原路线正常进化。

进化方向文案输入属于后续规划，当前不开放。开放后仍不得更改固定元素或类别，也不增加对应教育任务。独立付费、生成成本限制、领取流程和异常恢复另行补充。

## 9. 当前配置验收要点

- 学校管理层可见AI宠物入口，普通教师和班主任不可见；不同学校配置互不影响。
- 首次主开关关闭，开启后仅展示基础设置、高级设置；关闭再开启保留原配置。
- 领取方式文案为“班主任领取／学生领取”，默认前者；扣分处理为“不扣经验／扣经验”，默认前者。两行滑块宽度、字号、等分与右对齐一致。
- 升级经验按六阶段及其颜色展示全部10级，1级固定0，10级满级；9项累计门槛允许编辑，非整数、不递增或超出安全整数范围时不能保存。
- 实际成长流程接入后，扣经验不得退阶段，补回经验不得重复生成已有阶段图片；此项尚不能仅通过配置页面验收。
- 不展示已取消的个性化宠物设置，也不把未来独立付费能力呈现为当前已上线。

### 教师手机端：班级领取初始蛋（2026-11-03）

学校开启AI宠物后，班级学生列表的“学生卡片展示”新增“展示内容：学生／宠物”。学校配置为教师领取时，可进入本班学生列表的教师首次切换到宠物，先关闭设置抽屉，再通过公共确认弹层介绍玩法：AI结合学生画像、评价记录生成专属宠物；确认后为本班所有学生领取初始蛋，从领取时起新增评价影响成长与进化。按钮为“暂不使用／领取初始蛋”。取消保持学生信息，不领取；无学生时提示无法领取。

领取使用班级完整名册，不受当前搜索、多选或分组影响。初始蛋仅使用原紫色星纹与橙色条纹两款，按学生标识稳定分配，1级0经验，不使用期望蛋美术对比素材。学校、班级分别保存领取时间、领取学生名单与展示偏好；重复确认不重领、不重置经验。已领取班级切换展示不再弹确认。关闭学校功能时隐藏宠物展示，保留领取状态。学生领取模式不允许教师代领，暂提示学生先领取。

手机端演示记录识别完成后，按记录学生对象计入领取后经验；编辑分值与删除同步修正，不重复累计。扣分按学校配置执行，保留最高解锁阶段。经验门槛读取学校高级设置。领取后的新入班学生不自动加入本次领取，展示“尚未领取”，补领流程另行设计。

当前实现边界：领取与经验明细存于当前浏览器，供教师手机端演示。新增记录仍沿用项目的模拟识别结果；进化形象复用大屏现有演示素材，尚未接入真实AI生成、服务端领取或跨设备共享；同一浏览器内的大屏领取状态已同步。课堂大屏现已接入下述共享领取流程，不再将美术对比素材和预设成长值作为实际班级宠物。

教师领取权限与学校配置权限、班主任卡片管理权限分离：学校管理层配置全校开关；教师通过本班学生列表确认领取，不再复用 `canConfigureCardDisplay` 拦截。领取失败的原因须在确认弹层内展示，保留确认入口供重试，不使用被弹层遮挡的页面提示。

教师手机端宠物卡片展示与大屏保持信息层级一致：顶部为学号和姓名，右侧彩色阶段缎带，中部为伙伴及云巢，底部为等级、本级进度数值和进度条。小卡片不展示“经验”字样，不重复显示阶段正文；当前/目标值按学校配置计算，满级显示“已满级”。完整经验语义保留在无障碍名称中。初生蛋只使用两款默认素材，不影响大屏美术预览。

手机端卡片布局修订：移除固定164像素高度及图片区剩余空间居中。图片以卡片宽度形成方形画布，复用大屏阶段比例与底部基线，等级与进度组成紧邻图片的整体；进度数字12像素，阶段标签11像素且使用深色字，避免浅色底白字难辨认。未领取与新增学生卡片跟随同一网格行高度。

### 课堂大屏与教师手机端共享领取（2026-11-03）

大屏读取同一份学校AI宠物配置、班级领取时间、学生宠物与成长记录。学校关闭时展示学生、不提供宠物切换；开启且未领取时默认展示学生，教师切换宠物后弹玩法说明，按钮为“暂不使用／领取初始蛋”。取消不领取，确认一次性领取全班名册；搜索、多选不缩小领取范围。学生领取模式不允许教师代领。

两端通过同一班级ID与学生ID对应，屏幕显示名称不作存储主键。大屏演示名册已复用教师手机端的稳定演示名册，支持全部演示班级；不再随机生成另一份学生。默认演示学校为school-star，嵌入大屏时可传入schoolId指定学校。离班学生不显示在大屏，但领取批次仍保留完整名册。

已领取时，两端按同一学生ID展示紫色星纹与橙色条纹两款默认蛋。大屏的列表、伙伴详情、随机点名使用同一份实际成长状态，不使用混排演示阶段或预设进化动画。高级设置经验门槛与扣分处理直接读取学校配置，扣经验及撤销评价保留已解锁阶段。大屏手动/语音新增学生评价与撤销同步写入同一宠物记录；领取前的演示历史点评不补计。

当前同步是同一浏览器中的共享本地数据；同源其他标签页依靠storage事件刷新，同一页面依靠共享业务事件刷新。它不等同于跨设备、跨浏览器或不同网站地址间的同步，后者需要服务端。真实AI生成仍未接入，进化沿用已有演示形象。新入班未在领取批次的学生展示“尚未领取”，不伪造蛋与进度。
