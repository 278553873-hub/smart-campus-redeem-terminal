# 成长伙伴汇报使用说明

1. 打开 demo/index.html，展示顶部六阶段形象；开启96像素小图检查，比较轮廓变化。
2. 点击成长期，选择“直接预览下一阶段”，观看滑翔形态揭晓；点击伙伴体验轻量回应。
3. 切换“个性化依据”，展示两个虚构学生的具体经历与不同形态。注意：这是人工提炼记录后真实生图，尚未接自动分析后台；两案例不是控制变量实验。
4. 切换“学校模式”，选择意愿参与、不填写答案，点击模拟达标，说明无回复不阻塞。再选择自动生成对比。
5. 结合PRD讨论正式门槛、模型成本、试点学校与小图辨识效果。

文件为本地离线演示，打开不会调用生图或视频接口。7张图片均为imagegen真实生成，记录均为虚构。旧小芽谱系已被此版替换。

素材限制：部分图片留白不充分；最终形态辨识、透明边缘与批量一致性尚需正式验收。接口延迟、费用与真实学生满意度未验证，不应作为已完成产品能力承诺。
