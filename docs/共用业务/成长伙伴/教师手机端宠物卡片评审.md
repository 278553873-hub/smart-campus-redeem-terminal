# 教师手机端宠物卡片评审

2026-11-03。范围：教师班级学生列表宠物卡片；参照课堂大屏，不调整大屏布局或成长规则。
采用 refactor-ui 十项检查及 frontend-design-review，依据实际组件、教师端规范和已有图片素材；未启动浏览器自动化，不能视为已完成真机视觉验收。

评审结论：需要改进。主要问题是固定卡高与自适应图片宽度脱节，图片居中留下上下空白；等级与图片关系弱；数字过小；浅色标签白字对比不足。

| 检查项 | 原问题／结论 | 本次处理 |
| --- | --- | --- |
| 视觉层级 | 图片小且外围空白大，阶段与数字分散 | 全宽画布，保留身份、阶段、图片、进度层级 |
| 字号体系 | 10像素进度数字偏小 | 12像素数字、11像素标签，复用已有字号 |
| 调色板 | 原系统已具备完整中性与阶段色 | 保留阶段背景，不增加调色方案 |
| 间距 | 固定164像素卡高配合flex-1居中 | 内容决定高度，方形图片底对齐，4像素组间距 |
| 按钮层级 | 整张卡片一个入口，无内嵌冲突按钮 | 保留单入口、键盘焦点及选择语义 |
| 视觉杂乱 | 原有大段文字已去除 | 不重复经验、阶段正文；图片、等级和进度聚合 |
| 缺省态 | 未领取不应出现伪造进度 | 保留未领取状态，不添加尚未实现的补领入口 |
| 阴影 | 现有公共轻阴影可保留 | 不新增装饰层或厚阴影 |
| 颜色对比 | 多款阶段色上的白字未达小字要求 | 手机标签使用深色字，六背景逐项校验4.5:1 |
| 相关分组 | 图片与等级被可伸缩留白隔开 | 图片底基线与等级紧邻，数值与进度条独立成组 |

项目规范取舍：保留紧凑、清晰的教师管理端视觉，不套用面向宣传页的大字号、装饰背景或扩展色盘。标签只调整手机端字色，公共阶段背景与大屏保持一致。固定卡高令牌已由组件间距令牌替代，并同步教师端规范。

验证包含六阶段实际组件静态渲染、默认蛋、自定义经验门槛、满级、多选、长姓名、未领取以及阶段小字对比度；另运行领取事件回归、教师手机端页面渲染检查和构建。静态渲染不测量浏览器实际像素布局。
