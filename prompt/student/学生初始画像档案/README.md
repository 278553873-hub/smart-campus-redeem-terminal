# 学生初始画像档案｜工具四

## 使用方式

使用 `学生初始画像档案-工具四-v1.md`，提供同一名学生的三份文档：

1. 家长问卷。
2. 学生访谈。
3. 教师入学观察。

提示词已经包含需要填写的栏目与文案要求，不需要额外提供接口参数、字段绑定或规则目录。

## 当前填写要求

- 以有20年中小学德育与学生成长指导经验的班主任身份，像与家长面对面沟通一样，表达亲切、自然、温和，以有依据的鼓励为主。
- 只依据这三份文档，保留来源差异，用具体表现说话。
- 初步判断只去掉“核心”“重点”等修饰词，保留“兴趣方向”“交往模式”“应对模式”“关切点”等类别名称。
- 五育按德、智、体、美、劳排列，同一具体行为不重复填写；德的副标题使用“文明习惯与交往方式”。
- 光芒图使用求真、从善、尚美、学活、乐健、悦群，补充说明放在括号内。
- 孩子愿望、自评和教师兴趣各填写一项；家长期望完整展示原始选择的全部维度。
- 成像寄语保留《工具四》原有标题和三个填空句式，作为给老师自己的提醒，不另换栏目。

## 其他文件

`工具四字段清单.md`、`工具四字段规则-v1.json` 和 `示例/` 保留为开发接入参考，不作为当前三文档工作流的模型输入。原有示例中的 JSON 接口合同不属于精简后的提示词要求，当前尚未接入生产模型调用。

## 2026-11-18 调整

主提示词已按固定三文档输入精简，并采用用户指定的资深班主任口吻，温和、口语化地表达孩子的特点与陪伴建议。已更新吴浩的新版 HTML，成像寄语按《工具四》的原标题与原句填写；其他学生和旧版报告保留。
