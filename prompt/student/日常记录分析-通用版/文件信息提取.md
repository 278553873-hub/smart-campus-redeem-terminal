## 1. 事件类型判断（必填字段逻辑）

你必须根据图片内容判断事件类型，字段：`event_type`
可选枚举：

* **competition\_event**（比赛事件）
* **general\_event**（一般事件）

以下四个字段为 **必填字段**：

* `participants`
* `competition_name`
* `comment`
* `project_name`

如果在图片中 **任意一个必填字段无法获取**（为空、缺失、无法识别），
则你必须将事件判定为：

➡️ **general\_event（一般事件）**
➡️ 并且所有字段一律设置为空字符串或空数组（即所有值为空）。

只有当图片中清晰存在所有必填字段时，才可判断为 **competition\_event**。

## 2. 当 event\_type = "competition\_event" 时的字段要求

* **仅提取图片中明确可见的信息**
* 不确定、模糊、缺失 → 必填字段不允许为空 → 判为 general\_event
* 非必填字段如果缺失 → 用空字符串

## 当图片中出现奖状、证书、获奖证明、表彰文件、荣誉证书等场景时，必须严格遵循以下规则，否则跳过以下规则：

1️⃣ 学生姓名识别规则（强制）

* **participants 字段仅允许填写学生姓名**
* **必须能在奖状中清晰识别到至少一名学生姓名**
* 若无法明确区分或识别学生姓名（例如仅出现“指导教师”“班主任”“颁奖单位”等）
  ➡️ **视为 participants 必填字段缺失**
  ➡️ **event\_type 必须判定为 `general_event`**
  ➡️ **所有字段置空**

2️⃣ 教师姓名排除规则（强制禁止）

* 以下角色姓名 **严禁** 写入 `participants`：
  * 指导老师 / 指导教师
  * 班主任
  * 任课教师
  * 评委
  * 颁奖人
  * 签发人
* 即使教师姓名在奖状中字体更大、更清晰：
  * **也不得当作参赛人员**
  * **也不得补充或推测学生姓名**

3️⃣ 人名混合场景的处理原则

* 若奖状中 **同时出现学生姓名与教师姓名**：
  * **仅提取学生姓名**
  * 教师姓名一律忽略
* 若奖状中 **只出现教师姓名 / 单位名称 / 公章 / 职务**：
  * ➡️ **participants 判定为无法获取**
  * ➡️ **event\_type = general\_event**

4️⃣ 禁止推断与补全

* 不允许根据：
  * 合影人数
  * 校服
  * 班级信息
  * 背景板
  * 常见格式
    推断学生姓名
* **只能使用图片中明确可见、可读的学生姓名文本**

## 3. 当 event\_type = "general\_event" 时的规则

* 当无法完整识别 **participants / competition\_name / comment / project\_name**
  → 不论是否有奖状、舞台、背景板，只要必填字段缺失， 一律认为`event_type = "general_event"
* 你需要识别图片中有文字，有对事件的描述如果有的话，则排除干扰只提取图片中的内容事件填充到comment字段中，例如comment可能为：“王力红在上课的时候睡懒觉”
* 如果图片中没有文字则在comment中评论为：“仅凭图片无法找到对应的学生，请老师上传图片后再添加对图片的描述”
* 例如：

```json
{
  "event_type": "general_event",
  "competition_name": "",
  "participants": [],
  "award_level": "",
  "comment": "",
  "project_name": "",
  "award_time": "",
  "competition_level": "",
  "competition_type": ""
}
```
